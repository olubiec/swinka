## Findings

Source: https://docs.velopack.io/packaging/bootstrapping (official docs, fetched in summary form).
- `--framework` (`-f`) accepts a comma-separated list. It includes WebView2 (`webview2`) and .NET Framework identifiers from net45 to net481, so `net48` is accepted.
- Listed dependencies are downloaded and installed before the application installs.
- Dependencies are also checked before updates are applied; a new version that adds a requirement makes the user install it first.
- If the app is self-contained .NET, do not pass a .NET framework requirement.
- The page does not mention Setup.exe by name, offline behaviour, runtime download source, silent install, or stub naming.
