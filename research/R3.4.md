Question: Velopack "--framework webview2" and "net48": how does the bootstrapper behave on a Windows 10 PC without WebView2
and without internet (error message? failure?). Is the WebView2 Evergreen installer downloaded or bundled?
Size of the resulting Setup.exe for a small app. Does Setup.exe from a browser download get the same SmartScreen warning
as an unsigned exe?

## Findings

**Bootstrapping behaviour** (source: official docs)
- `--framework` / `-f` takes a comma-separated list; `webview2` and `net48` are valid values. Dependencies "will be downloaded and installed before your application will be installed". https://docs.velopack.io/packaging/bootstrapping
- Before applying an update Velopack checks required dependencies and prompts to install new ones. (same page)
- Not covered by the docs: offline behaviour, the error text, silent mode, Setup.exe size, and whether each dependency is bundled or downloaded.

**No internet case**
- No source describes the Windows 10 + no WebView2 + no internet case or its error message.
- Closest evidence: issue #1061 (2026-09-21, closed as completed). The reporter on a restricted network says Velopack downloads the .NET runtime from Microsoft's public endpoints, which fails there. The maintainer answered that prerequisite installers have no consistent command line, and recommended a self-contained build instead. It is about .NET, not WebView2. https://github.com/velopack/velopack/issues/1061
- So downloading is the documented model; failure without internet is likely but the exact message is UNVERIFIED.

**Setup.exe size**
- Not found. The installer page does not give sizes. https://docs.velopack.io/packaging/installer

**SmartScreen on a browser-downloaded Setup.exe**
- Velopack's signing page: unsigned apps are "frequently flagged" by SmartScreen and antivirus; each new unsigned file starts without reputation; if signing is configured the installer is signed too. https://docs.velopack.io/packaging/signing
- Microsoft: an unsigned file shows "Windows protected your PC" with "Run anyway", reputation starts at zero for each new version. https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation
- No page states Setup.exe specifically; that it behaves like any unsigned exe is inference (UNVERIFIED).

## Answer for Cuy
Velopack downloads `webview2` / `net48` during Setup; the docs do not describe offline behaviour, so assume Setup fails without internet (UNVERIFIED, message unknown).
Setup.exe size is not documented; measure it after `vpk pack`.
An unsigned Setup.exe should get the same SmartScreen warning as any unsigned exe ("Windows protected your PC" / "Run anyway").
