Question: ZzFX (Frank Force, npm package "zzfx"). Give: repo URL, latest version, licence, which file to include in a plain
<script> page (no bundler), the API (zzfx(...params), master volume variable), and the URL of the official sound designer
tool that generates parameter arrays. Is there a CC0/MIT preset list of common game sounds (coin, pop, click, jump)?

## Findings

- Repo: https://github.com/KilledByAPixel/ZzFX (npm "repository" field, https://registry.npmjs.org/zzfx; also in the header of ZzFX.js).
- Latest version: 1.4.0, published 2026-10-01 (npm registry; earlier versions 1.3.2 on 2025-09-17, 1.3.0 on 2024-07-01). Package page: https://www.npmjs.com/package/zzfx. Note: an earlier draft of this file said 1.3.0, which is outdated.
- Licence: MIT (npm field; ZzFX.js header "ZzFX MIT License"; package ships LICENSE, 1089 bytes).
- Files in the 1.4.0 npm tarball (measured): ZzFX.js 10,301 bytes (ES module, `export function zzfx`, `export const ZZFX`), ZzFXMicro.js 5,715, ZzFXMicro.min.js 1,226 bytes, wav.js 2,362.
- Plain `<script>` (no bundler): use ZzFXMicro.min.js (or paste its code, as the README says). It starts with `'use strict'; let zzfxV=.3, zzfxX=new AudioContext, zzfx=(...)=>{...}`, so it defines globals `zzfx`, `zzfxV`, `zzfxX`. ZzFX.js is a module and needs `import {ZZFX, zzfx} from './ZzFX.js'`.
- API: `zzfx(...[,,,,.1,,,,9])`, 20 controllable parameters (README at https://www.npmjs.com/package/zzfx).
- Master volume: `zzfxV` (default .3) in the Micro build; `ZZFX.volume` (default .3, comment "master volume scale") in the module build. Source: the files in the npm tarball.
- Autoplay catch: the Micro build creates `new AudioContext` when the script loads. Chrome starts such a context "suspended" until a user gesture (see R2.4), so the first sound may need a click first.
- Official sound designer: https://killedbyapixel.github.io/ZzFX (linked from the README). Soundboard demo: https://codepen.io/KilledByAPixel/full/BaowKzv (README link).
- Presets: the README shows four sample parameter arrays (Game Over, Heart, Piano, Drum). The designer has "Random Sound Generation: Create sounds from presets" (README). A ready CC0/MIT list of coin/pop/click/jump sounds was not found.

## Answer for Cuy
ZzFX 1.4.0 (MIT, 2026-10-01), repo github.com/KilledByAPixel/ZzFX; for a plain script use ZzFXMicro.min.js (1,226 bytes), call `zzfx(...params)`, volume is `zzfxV` (module build: `ZZFX.volume`), default .3.
Design sounds at https://killedbyapixel.github.io/ZzFX and paste the arrays into sound.js.
No ready coin/pop/click/jump preset list was found; make our own. The AudioContext starts suspended until the first click.
