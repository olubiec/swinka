Question: Which NES.css components exist for: checkbox/toggle, radio, range slider, select/dropdown, text input,
dialog, progress bar, speech balloon, container with title, icons? For each give the class name and a doc/demo link.
List open GitHub issues about rendering in Chromium/Edge (WebView2 is Chromium-based) and about range inputs.

## Findings

Method: class names were read from the CSS in the nes.css 2.3.0 npm tarball (https://www.npmjs.com/package/nes.css); the README gives the docs/demo site https://nostalgic-css.github.io/NES.css/ (not opened from this session, so per-component demo anchors are not given).

| Need | Class in NES.css 2.3.0 | In core-only build (nes-core.css)? |
| --- | --- | --- |
| checkbox | `.nes-checkbox` | yes |
| toggle/switch | none (no "toggle" or "switch" selector in the CSS) | - |
| radio | `.nes-radio` | yes |
| range slider | none (the string "range" does not occur in the CSS) | - |
| select/dropdown | `.nes-select` | yes |
| text input | `.nes-input`, `.nes-textarea`, wrapper `.nes-field` | yes |
| dialog | `.nes-dialog` | yes |
| progress bar | `.nes-progress` | yes |
| speech balloon | `.nes-balloon` | yes |
| container with title | `.nes-container` with modifier `.with-title` (also `.is-rounded`, `.is-centered`, `.is-dark`) | yes |
| icons | `.nes-icon` | no (only in the full nes.css) |
| buttons, lists, tables, badges | `.nes-btn`, `.nes-list`, `.nes-table`, `.nes-badge` | yes (btn) |

- Other classes in the full CSS: `.nes-avatar`, `.nes-pointer`, `.nes-text`, and character sprites such as `.nes-mario`, `.nes-kirby`, `.nes-pokeball`, `.nes-bulbasaur`, `.nes-charmander`, `.nes-squirtle`, `.nes-ash`. The sprites are characters from other companies' games and are not in nes-core.css (measured: 0 matches there). Whether they are licensed for reuse is UNVERIFIED; using nes-core avoids them.
- The package has storybook templates for avatars, badge, balloons, buttons, containers, dialogs, icons, inputs, lists, progress, select, table, text, textarea. No range or toggle story exists.
- Open GitHub issues about Chromium/Edge rendering or range inputs: not found. GitHub was not reachable; an aggregator (https://www.goodfirstissue.org/nostalgic-css) shows only 3 "good first" issues without titles. The README only says Edge is untested.
- Range slider: you would need your own CSS (or another kit; RPGUI has `.rpgui-slider`, see R1.3).

## Answer for Cuy
NES.css has checkbox, radio, select, input, dialog, progress, balloon, container `.with-title` and icons, but no range slider and no toggle.
Use nes-core.min.css (52,579 bytes) to skip the icon and the Mario/Pokemon-style character sprites; the full file is 288,523 bytes.
No Chromium/Edge issues could be listed because the repo was not reachable.
