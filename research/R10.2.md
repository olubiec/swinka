Question: Open-source Phaser 3 memory / card-matching games with an explicit permissive LICENSE file: repo URL, LICENSE link,
Phaser version, how the card flip is done (scaleX tween or other), and how input is blocked while two cards are checked.

## Findings

Candidates (all from GitHub repo pages and raw files; GitHub tree/API pages were blocked, so source details are partial):

1. **ourcade/memory-match-template-phaser3** - https://github.com/ourcade/memory-match-template-phaser3
   - LICENSE: https://raw.githubusercontent.com/ourcade/memory-match-template-phaser3/master/LICENSE , MIT, "Copyright (c) 2019 ourcade" (opened).
   - Phaser: `^3.24.1` in package.json (opened).

Reveal is a tween of the item sprite (`y: '-=50'`, `alpha`, `scale`, 500 ms), no scaleX flip. `checkForMatch` runs from the open-tween `onComplete` when `selectedBoxes.length >= 2`, mismatch hides after a 1000 ms delay. There is no dedicated input lock; only `opened`/`activeBox` checks (per `src/scenes/Game.js`, tool-generated reading, UNVERIFIED in detail). Not a good pattern for this question.
2. **rogeralmeida/phaser3-memory-game** - https://github.com/rogeralmeida/phaser3-memory-game - GitHub shows a LICENSE file, MIT. Phaser 3, exact version not found. Flip and input blocking: not found (source not opened).
3. **Re0niDo/Marshmallow-Kingdom-Memory-Game** - https://github.com/Re0niDo/Marshmallow-Kingdom-Memory-Game - LICENSE file, MIT per GitHub. Says it is based on the Phaser 3 "Memory Card Game" example (links v3.85.0 examples). Flip and input blocking: not found (source not opened).
4. Official Phaser example **Card Memory Game** (Francisco Pereira / Gammafp), https://phaser.io/examples-show/208 (page text, official site). Described there:
   - Flip: a tween of a hidden rotation value 0 -> 180 (or back) over 500 ms; on each update it sets the card's `rotateY` and swaps front/back texture by angle (not a scaleX tween); `isFlipping` flag ignores flip requests during the animation; a small scale bounce plays.
   - Input block: pointer handler runs only when `canMove && cards.length`; `canMove = false` right after a valid click and set back to `true` in the flip callbacks; also false on win/loss. Match: both cards destroyed; mismatch: both flipped back.
   - Licence: the example page states none. The phaserjs/examples README says the *source code* is MIT but assets are not covered (no commercial or advertising use) ([repo](https://github.com/phaserjs/examples)); no LICENSE file was visible in the listing. Treat as pattern only.
   - Caution: `rotateY` suggests a Plane/Mesh-type object (UNVERIFIED), which v4 removed (see R9.2) and which does not suit a pixel-art 2D look.

## Answer for Cuy
No repo found with verified MIT licence AND a verified card-flip + input-lock implementation; rogeralmeida and Marshmallow-Kingdom are MIT but their code was not read.
Take only the pattern from the official example: a `canMove`/`isFlipping` lock set false on click, restored in the flip-complete callback, compare names after the second flip.
For a 2D flip use a two-step scaleX tween (1 -> 0, swap frame, 0 -> 1): general technique, not from a source (UNVERIFIED).
