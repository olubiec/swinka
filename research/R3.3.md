Question: Velopack uninstall: what does it delete (install folder, shortcuts, registry)? Does it touch %AppData%\<app> user data?
Are there hooks (VelopackApp.Build().OnBeforeUninstallFastCallback or similar) to clean up an autostart Run key?
Give the exact hook names from the docs.

## Findings

**What uninstall deletes on Windows** (source: official docs)
- Shortcuts that point into the install directory.
- The install directory `%LocalAppData%\{packId}` (app, `current`, packages, `Update.exe`).
- The app's temporary working directory.
- The uninstall entry in the Windows registry.
- https://docs.velopack.io/integrating/uninstalling

**User data**
- Data outside the install directory is not removed: settings in `%AppData%\{packId}` survive. Anything stored inside the `{packId}` install folder is deleted. (same page)

**Autostart Run key**
- The docs list only the uninstall registry entry as removed. An HKCU Run value is not mentioned, so it should be assumed to stay unless your app removes it. (inference, UNVERIFIED)

**Hooks, exact names**
- Class method list (VelopackApp): `OnFirstRun`, `OnRestarted`, `OnAfterInstallFastCallback`, `OnAfterUpdateFastCallback`, `OnBeforeUpdateFastCallback`, `OnBeforeUninstallFastCallback`, plus `Run()`. https://docs.velopack.io/reference/cs/Velopack/VelopackApp
- Uninstall hook: `OnBeforeUninstallFastCallback`, command-line argument `--veloapp-uninstall {version}`. https://docs.velopack.io/integrating/hooks
- Timeouts: install and uninstall 30 s, update hooks 15 s. Must exit in time (the process is killed otherwise), must show no UI, cannot cancel the uninstall. (same page)
- The uninstall hook runs first, before anything is deleted. Windows only; no uninstall hook on macOS/Linux. https://docs.velopack.io/integrating/uninstalling
- Older naming: the reference page for assembly 0.0.626 documents `WithBeforeUninstallFastCallback(VelopackHook hook)` (runs before uninstall, then `Exit(int)`, 30 s limit). The current class page lists only `OnBeforeUninstallFastCallback`. https://docs.velopack.io/reference/cs/Velopack/VelopackApp/methods/WithBeforeUninstallFastCallback
- Signature example (current): `public VelopackApp OnAfterUpdateFastCallback(VelopackHook hook);` https://docs.velopack.io/reference/cs/Velopack/VelopackApp/methods/OnAfterUpdateFastCallback

## Answer for Cuy
Uninstall removes `%LocalAppData%\{packId}`, shortcuts into it, the temp dir and the Windows uninstall entry; `%AppData%\{packId}` stays.
The Run key is not listed as removed, so delete it yourself in `VelopackApp.Build().OnBeforeUninstallFastCallback(v => ...)` (30 s, no UI).
Use `OnBeforeUninstallFastCallback`, not the older `WithBeforeUninstallFastCallback`.
