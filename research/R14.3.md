Question: How do Shimeji-ee and VPet-Simulator implement interaction between two pets (Shimeji "Breed", "ScanMove", "Interact"
behaviours, affordances; VPet multiplayer/visits)? Summarise the pattern in 10 lines with links and licences (code reuse only if permissive).

## Findings

Method note: pages and files were read through a summarising fetch tool, not by hand. Only the chaoskagami fork of Shimeji-ee was inspected; the Kilkakon edition (which may differ) was not found.

### Shimeji-ee (Java), fork https://github.com/chaoskagami/shimeji-ee
- Licence: README says the source is under the New BSD licence and follows zlib/libpng; bundled JNA is LGPL, AbsoluteLayout from NetBeans (readme, GitHub). Original licence text file: `originallicense.txt` (not opened).
- Config: `conf/actions.xml` and `conf/behaviors.xml`. Actions and behaviours can be sequences of other ones.
- `Breed` (Java class `com.group_finity.mascot.action.Breed`) is used in `actions.xml` as two embedded actions: `PullUpShimeji1` (`BornX="-32" BornY="96" BornBehavior="PullUp"`) and `Divide1` (`BornX="-16" BornY="0" BornBehavior="Divided"`).
  Breed creates a new mascot at an offset and gives it a starting behaviour (`BornBehavior`).
- `behaviors.xml` gates breeding by a global count: `Condition="#{mascot.totalCount < 50}"` on `PullUpShimeji` and `SplitIntoTwo`, so the swarm stays limited.
- Action classes present in this fork (`src/com/group_finity/mascot/action/`): Animate, Breed, Dragged, Fall, FallWithIE, Jump, Look, Move, Offset, Regist, Select, Sequence, Stay, ThrowIE, WalkWithIE (and bases). No `ScanMove`, `Interact` or "Affordance" file or XML entry found.
  So the "ScanMove / Interact / Affordance" pattern was NOT found in this fork. UNVERIFIED whether another edition has it.
- Pattern from what was found: spawn via Breed + BornBehavior; limit via `mascot.totalCount`; no direct pet-to-pet scan in this fork.

### VPet-Simulator https://github.com/LorisYounger/VPet
- Licence: Apache-2.0 (repo nav and LICENSE file); bundled animation assets have separate copyright terms.
- Structure: `VPet-Simulator.Core` (embeddable WPF), `VPet-Simulator.Windows`, plugins/mod maker (VPet.Plugin.Demo, VPet.ModMaker).
- README and file list mention no multi-pet, visit or multiplayer feature; interaction described is user-to-pet (feeding, touching). Steam/store pages found in search did not show such a feature either.

### For comparison (see R14.2)
eSheep (MIT) already has pet-to-pet interaction by window title and position.

## Answer for Cuy
In the Shimeji-ee fork checked, two-mascot "interaction" is only Breed (spawn with BornBehavior, capped by `mascot.totalCount`); no Scan/Interact/affordance code found. VPet (Apache-2.0) has no documented pet-to-pet or visit feature.
Reusable ideas: spawn-with-start-behaviour and a global count cap. The only real pet-to-pet code found is in eSheep (R14.2).
