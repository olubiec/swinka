## Answer for Cuy
NES.css 2.3.0 (MIT) is from 2019-12-17; an aggregator shows the last commit as 2020-10-01, so treat it as unmaintained but stable.
Minified: 288,523 bytes full, 52,579 bytes core-only (npm tarball). It needs no font file; "Press Start 2P" is only the default and can be replaced with a font-family override.
README tests Chrome/Firefox/Safari only; Edge is "untested".
