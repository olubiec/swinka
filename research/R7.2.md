Question: A .NET Framework 4.8 WinForms app uses WebView2 (Microsoft.Web.WebView2 NuGet). What exception is thrown when the
WebView2 Runtime is missing, how to detect the runtime first (CoreWebView2Environment.GetAvailableBrowserVersionString),
and the official Evergreen bootstrapper/standalone installer URLs. Is the runtime preinstalled on all supported Windows 10
and Windows 11 versions in 2026?

## Findings

- Exception: `WebView2RuntimeNotFoundException` (namespace Microsoft.Web.WebView2.Core, base System.Exception, [Serializable]); Microsoft describes it as thrown when the runtime installation is missing. Source: [Learn, class page](https://learn.microsoft.com/en-us/dotnet/api/microsoft.web.webview2.core.webview2runtimenotfoundexception) (official docs). The page does not say which calls throw it besides the method below.
- Detection: `public static string GetAvailableBrowserVersionString(string browserExecutableFolder = default)` (and an overload with `CoreWebView2EnvironmentOptions`) returns the version string and "throws WebView2RuntimeNotFoundException when the runtime is missing"; it also fails if no non-stable Edge is found. Source: [Learn, method page](https://learn.microsoft.com/en-us/dotnet/api/microsoft.web.webview2.core.corewebview2environment.getavailablebrowserversionstring) (official docs). Channel name is added only for Beta/Dev/Canary.
- Alternative detection by registry (value `pv`, must be > 0.0.0.0): per-machine `HKLM\SOFTWARE\WOW6432Node\Microsoft\EdgeUpdate\Clients\{F3017226-FE2A-4295-8BDF-00C3A9A7E4C5}` (64-bit Windows) or per-user `HKCU\Software\Microsoft\EdgeUpdate\Clients\{F3017226-...}`. Source: [Learn, distribution](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/distribution) (official docs).
- Installers (same page): Evergreen Bootstrapper (~2 MB, downloads the runtime for the device architecture; silent: `MicrosoftEdgeWebview2Setup.exe /silent /install`) and Evergreen Standalone Installer (offline, `MicrosoftEdgeWebView2RuntimeInstaller{X64|X86|ARM64}.exe /silent /install`). The page gives no direct file URLs, only landing pages: developers https://developer.microsoft.com/microsoft-edge/webview2#download-the-webview2-runtime and end users https://developer.microsoft.com/microsoft-edge/webview2/consumer/ (use the "Get the link" button on the first page for a stable bootstrapper link).
- Preinstall: [Learn, distribution](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/distribution) says the Evergreen runtime is included in Windows 11; on Windows 10 "the vast majority" of devices have it, "a small number" do not, and recommends checking and deploying it with the app.

## Answer for Cuy
Missing runtime = `WebView2RuntimeNotFoundException`. Check first with `CoreWebView2Environment.GetAvailableBrowserVersionString()` inside try/catch (works on .NET Framework 4.8).
If missing, run the Evergreen bootstrapper (or standalone offline installer) silently with `/silent /install`, or show a message with the download link.
Not guaranteed preinstalled: Windows 11 yes, Windows 10 mostly but not all, so keep the check.
