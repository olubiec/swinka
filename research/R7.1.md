Question: List every CoreWebView2Settings property useful to lock down an embedded app page (dev tools, browser accelerator keys,
zoom, default context menus, status bar, autofill, password autosave, swipe navigation, pinch zoom, script dialogs).
For each: name, default value, minimum WebView2 SDK and runtime version. Microsoft Learn links only.

## Findings

Sources: all Microsoft Learn (official docs). Defaults: [.NET/WinRT-style settings reference](https://learn.microsoft.com/en-us/microsoft-edge/webview2/reference/winrt/microsoft_web_webview2_core/corewebview2settings) and the Win32 interface pages below. The .NET class page ([CoreWebView2Settings](https://learn.microsoft.com/en-us/dotnet/api/microsoft.web.webview2.core.corewebview2settings)) gives no per-property default or version, so "Introduced" comes from the Win32 interface pages ("Applies to" table; those pages say the Win32 reference is no longer maintained). Versions are SDK numbers; .NET NuGet uses the same build numbers (inference, UNVERIFIED for NuGet specifically).

Minimum runtime rule ([versioning](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/versioning)): an API works with a runtime whose build number (3rd part) is >= the SDK build number in which the API was introduced. So "min runtime" below = runtime build >= the SDK build.

Behaviour notes (from the pages above):
- Most settings apply from the next top-level navigation; IsGeneralAutofillEnabled and IsPasswordAutosaveEnabled apply immediately and are shared per profile.
- AreBrowserAcceleratorKeysEnabled = false disables Ctrl+F, Ctrl+P, F5, F12 etc.; editing keys (Ctrl+C/V/A) stay on.
- AreDevToolsEnabled only blocks opening via context menu / shortcuts (per property description); OpenDevToolsWindow() from code is a separate call (not verified here).
- IsZoomControlEnabled = false does not stop ZoomFactor set from code. IsPinchZoomEnabled only affects page-scale zoom.
- With AreDefaultScriptDialogsEnabled = false the host can draw its own UI via ScriptDialogOpening.

## Answer for Cuy
Set false: AreDevToolsEnabled, AreBrowserAcceleratorKeysEnabled, AreDefaultContextMenusEnabled, IsZoomControlEnabled, IsPinchZoomEnabled, IsSwipeNavigationEnabled, IsStatusBarEnabled, IsGeneralAutofillEnabled (password autosave is already false by default).
Settings before the first navigation. The newest needed one is IsSwipeNavigationEnabled (SDK 1.0.992.28); the rest are <= 1.0.902.49 or in the original interface.
Wrap newer setters in try/catch (old runtimes throw "No such interface supported", per the versioning page).
