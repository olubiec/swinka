Question: Phaser changelog from 3.80.1 to 3.90.0: list breaking changes and deprecations that affect Arcade physics,
spritesheet loading, animations, tweens, input (pointer, keyboard), Text and Graphics. Official changelog/release notes links.

## Findings

Releases between 3.80.1 (27 Feb 2024) and 3.90.0 (stable only, per [Phaser archive](https://editor.phaser.io/download/archive)): 3.85.0 and 3.85.1 (5 Sep 2024), 3.85.2 (17 Sep 2024), 3.86.0 (11 Oct 2024), 3.87.0 (14 Nov 2024), 3.88.0 (11 Feb 2025), 3.88.1 (12 Feb), 3.88.2 (13 Feb), 3.90.0 (23 May 2025). No stable 3.81-3.84 or 3.89 listed. Source for every item below: the official GitHub release page of that version (release notes), linked per row. 3.80.x -> 3.85 notes were not read separately (3.85.0 is the first release after 3.80.1 in the archive).

| Version | Area | Change (breaking or behaviour change) |
|---|---|---|
| [3.85.0](https://github.com/phaserjs/phaser/releases/tag/v3.85.0) | Game config | `roundPixels` default now `false` (was `true`); `uRoundPixels` uniform and `BaseCamera.preRender` removed |
| 3.85.0 | Arcade | `collisionMask` default now 2147483647 (matches any category); Group-vs-Group fix; `setPushable(false)` works for circles |
| 3.85.0 | Spritesheet | `Texture.getFrameBounds` includes base texture, so margin/spacing of `load.spritesheet` tilesets are honoured; loader retries failed files 2 times by default |
| 3.85.0 | Input | Process methods (down/up/over/out/move/wheel) rewritten; propagation continues through remaining objects unless the event is cancelled; `pointer.*ButtonReleased` true when multiple buttons pressed; `disableInteractive`/`removeInteractive` got optional cursor-reset params |
| 3.85.0 | Tweens | `Timeline.clear/destroy` now destroy the tweens the timeline created; `pause/resume` affect them |
| 3.85.0 | Text | `TextStyle.setStyle` no longer mutates the passed style object; BitmapText with an invalid key throws instead of warning |
| 3.85.0 | Deprecations announced for the next release | `Phaser.Struct.Map/Set`, `Geom.Point`, the `Create` namespace (`GenerateTexture`, palettes), `phaser-ie9.js` entry, Spine 3/4 plugins; build moves Webpack -> ESBuild |
| [3.85.1](https://github.com/phaserjs/phaser/releases/tag/v3.85.1), [3.85.2](https://github.com/phaserjs/phaser/releases/tag/v3.85.2) | - | 3.85.1 repeats the 3.85.0 notes; 3.85.2 only WebGL extension query fix and `TransformMatrix.setQuad` no longer rounds quad size (roundPixels cameras) |
| [3.86.0](https://github.com/phaserjs/phaser/releases/tag/v3.86.0) | Text | `setLetterSpacing` end-cut fix; `Container#tempTransformMatrix` (internal) removed. Nothing for Arcade/tweens/input/animations/Graphics |
| [3.87.0](https://github.com/phaserjs/phaser/releases/tag/v3.87.0) | Tweens | Custom `ease` callback: final value is now always passed through it (end values can differ from before) |
| [3.88.0](https://github.com/phaserjs/phaser/releases/tag/v3.88.0) | Arcade | `Body/StaticBody.setGameObject` now return early without a valid object, set `body` always, new `enable` param; circle-circle and circle-rect separation moves both bodies when possible |
| 3.88.0 | Textures | `DynamicTexture`/`RenderTexture` `forceEven` default `true` (sizes rounded up to even; release calls it potentially breaking, set `false` for odd sizes) |
| 3.88.0 | Animations | `AnimationState.play` prefers `frameRate` from `PlayAnimationConfig` over the value from loaded animation data |
| 3.88.0 | Tweens | Number tweens apply the final start/end value (not the eased one) on completion, reversing 3.87; duration clamped to min 0.01 ms; `persist` + `completeDelay` tweens are not destroyed |
| 3.88.0 | Input | `InputPlugin.processDragUpEvent` returns world-space x/y |
| 3.88.0 | Text | New `letterSpacing` in `TextStyle`; wrapping now accounts for it (line breaks can move) |
| [3.88.1](https://github.com/phaserjs/phaser/releases/tag/v3.88.1), [3.88.2](https://github.com/phaserjs/phaser/releases/tag/v3.88.2) | - | Bug fixes only (NumberTweenBuilder ReferenceError, `Array.Utils.GetFirst`, Scale Manager revert) |
| [3.90.0](https://github.com/phaserjs/phaser/releases/tag/v3.90.0) | Arcade | `World#separate` checks `collisionMask`/`collisionCategory`; immovable circles no longer pushed by polygons |
| 3.90.0 | Animations / Tweens | `AnimationFrame` uses the frame duration when set; chained tweens persist after `stop` |
| 3.90.0 | Other | `createFromTiles` handles multiple tilesets; ImageCollection default Tileset values `null` -> `undefined`; DOM object throws on bad game config; Text sets `ltr` explicitly |

Graphics: no Graphics-specific breaking change or deprecation in any of these releases (only Shape.Ellipse and Grid fixes). Keyboard input: nothing listed. Official release announcement for 3.90.0 says it "should be a drop-in replacement for any v3.88 game" and "likely the last version in the v3 tree" ([phaser.io news](https://phaser.io/news/2025/05/phaser-v390-released)). The deprecated items announced in 3.85 were not removed in 3.90 (not listed in its notes); the v4 migration guide lists them as removed in v4.

## Answer for Cuy
Upgrading 3.80.1 -> 3.90.0 looks low risk for a small Arcade game; no Graphics or keyboard breaking changes were found.
Check these: `roundPixels` now defaults to false (pixel art: set `pixelArt: true` / `roundPixels: true` explicitly), Arcade default `collisionMask`, `AnimationState.play` frameRate precedence, Timeline destroy behaviour, `forceEven` on RenderTexture, and the input processing rewrite (hover/click on stacked objects).
Run each minigame once after replacing `phaser.min.js`.
