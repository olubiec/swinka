## Findings

**SmartScreen** (source: Microsoft Learn)
- Unsigned or self-signed file: reputation starts at zero for each new version; the user sees "Windows protected your PC" and must choose "Run anyway" (can be blocked by enterprise policy). Reputation needs several weeks and hundreds of clean installs; no exact threshold. https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation
- SmartScreen checks a blocklist and a list of well-known frequently downloaded files; unknown files get a warning. https://learn.microsoft.com/en-us/windows/security/operating-system-security/virus-and-threat-protection/microsoft-defender-smartscreen/

**Mark of the Web**
- The two Microsoft pages above do not explain Mark of the Web. General knowledge (UNVERIFIED here): browsers add a Zone.Identifier stream (ZoneId=3) to downloaded files and SmartScreen uses it to decide whether to check the file.

**Smart App Control (SAC)**
- Enforcement mode blocks unsigned code unless Microsoft's app intelligence recognizes it as likely safe or it is signed by a CA in the Microsoft Trusted Root Program; modes On / Evaluation / Off under Windows Security > App and browser control. https://learn.microsoft.com/en-us/windows/apps/develop/smart-app-control/overview
- A launch from Explorer is blocked; from a command prompt the error mentions a "Device Guard policy". SAC checks all loaded code (DLLs too) and disables SmartScreen Application Reputation while on. Source: Microsoft security engineer's blog, https://textslashplain.com/2026/04/28/smart-app-control/
- Microsoft's Windows 11 note: SAC may block unsigned executables without positive reputation, for all executables, not only downloaded. (smartscreen-reputation page)

**Does Unblock help with SAC**
- No source shows that it does. The textslashplain article never mentions Unblock; it only says removing Mark of the Web or turning SAC off can help for the "dangerous file types" block (scripts, .lnk), not for exe/DLL. A Microsoft Q&A volunteer answer says Unblock is "worth trying" for MotW but does not show it fixes SAC. https://learn.microsoft.com/en-us/answers/a/12726336 (not official guidance)
- Same Q&A answer claims SAC cannot be turned back on after turning it off without a Windows reset (unofficial, UNVERIFIED).
- SAC can block even signed apps lacking cloud reputation (Q&A 2026-02-27, no accepted answer); diagnosis: Event Viewer > Applications and Services Logs > Microsoft > Windows > CodeIntegrity > Operational, event 3076 (audit) / 3077 (enforce). https://learn.microsoft.com/en-us/answers/questions/5791210/application-signed-and-blocked-by-smart-app-contro

**False-positive submission (WDSI)**
- URL: https://www.microsoft.com/en-us/wdsi/filesubmission
- Steps: choose submitter type (Home customer / Enterprise customer / Software developer); fill the required fields: Microsoft security product that scanned the file, company name, affected organization, number of affected devices, the file (max 50 MB; password-protect ZIP/RAR with "infected"; submit only the file, not an installer or large archive), "Incorrectly detected as malware/malicious" (or PUA), detection name, extra information (English, up to 1,900 characters). Then review, human verification, Submit, accept terms; sign-in optional.
- Caveat: for SmartScreen reputation Microsoft says there is no consumer submission process and reputation builds with downloads; submission is optional for enterprises. (smartscreen-reputation page)

## Answer for Cuy
Unsigned exe: SmartScreen shows "Windows protected your PC" with "Run anyway"; with Smart App Control On the exe can be blocked outright (no "Run anyway").
Unblock is not shown to help against SAC; only a trusted signature, Microsoft recognizing the file, or turning SAC off.
False positives: https://www.microsoft.com/en-us/wdsi/filesubmission (software developer, file up to 50 MB).
