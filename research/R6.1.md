## Findings

I read the repo's `tracery.js` and `readme.md` (cloned main, last commit 2024-11-03, licence Apache-2.0: https://github.com/galaxykate/tracery/blob/master/LICENSE.MD). I could not open the tracery.io tutorial body (the fetch returned only a title), so POP details come from a secondary page.

**Actions in the repo (main branch `tracery.js`)**
- Readme example: `"origin": ["#[hero:#name#][heroPet:#animal#]story#"]`. Actions sit in square brackets inside a `#...#` tag, before the symbol to expand. Source: https://github.com/galaxykate/tracery/blob/master/readme.md
- In `tracery.js` an action is split on ":" into `symbol:rules`; the rules part is split on "," into several rules; any other form throws "Unknown action". The pushed rules are popped automatically when the node is deactivated. Source: `tracery.js` lines ~468-519 (action activate/deactivate).
- `[key:POP]` does not appear anywhere in the main-branch repo (search for "POP" in non-minified files found nothing). So `[key:POP]` is not documented in main; in main, pops happen automatically at the end of the node. A secondary page (aibolem.github.io/tracery, a docs copy of the newer Tracery 2) documents `[key:#rule#]` as push and `[key:POP]` as pop. Source: https://aibolem.github.io/tracery/ (secondary; UNVERIFIED against the official tutorial).

**Modifiers**
- Main branch `tracery.js` defines these in `universalModifiers` (the name `baseEngModifiers` does not occur in the main-branch files): `capitalizeAll`, `capitalize`, `inQuotes`, `comma`, `beeSpeak`, `a`, `s`, `ed`. Source: `tracery.js` lines 550-660.
- Syntax: `#animal.capitalize#`; modifiers can be chained (`#symbol.mod1.mod2#`, per the parser splitting on "."). Source: readme and `tracery.js` parseTag.
- The name `baseEngModifiers` and a `mods-eng-basic.js` file appear on the Tracery 2 docs copy, along with a `replace(a,b)` modifier with parameters; that page does not list the full set. Source: https://aibolem.github.io/tracery/ (secondary). The official tutorial's list was not retrievable.

**Online editors / visualisers**
- Classic editor: https://tracery.io/archival/brightspiral/tracery/
- Newer version: https://artbot.club
- Examples: https://tracery.io/archival/crystalcodepalace/tracery.html
- Interactive tutorial: https://tracery.io/archival/crystalcodepalace/tracerytut.html
All four are linked from the repo readme. I did not test pasting a grammar into them.

## Answer for Cuy
Main-branch syntax: `#[key:value1,value2]symbol#`, with a comma-separated rule list; pops happen automatically.
`[key:POP]` is documented only for Tracery 2 (secondary source), not in main.
Main-branch modifiers: capitalizeAll, capitalize, inQuotes, comma, beeSpeak, a, s, ed (the Tracery 2 docs add replace(a,b)).
Editors: brightspiral classic editor and artbot.club.
