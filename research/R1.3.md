Question: Compare pixel/retro CSS kits as alternatives to NES.css for a cute pixel-art pet game UI inside a 400x620 window:
98.css, XP.css, RPGUI, pixel-borders (or similar "pixel border" CSS/SCSS mixins), any other maintained kit you find.
For each: URL, licence, minified size, last release, which UI controls it styles, and how "cute game" vs "OS look" it is.

## Findings

Data come from the npm packages (registry and tarballs measured in this session); GitHub pages were mostly not reachable.

| Kit | URL | Licence | Size (measured in npm tarball) | Last npm release | Controls styled |
| --- | --- | --- | --- | --- | --- |
| NES.css 2.3.0 | https://github.com/nostalgic-css/NES.css | MIT | nes.min.css 288,523 B; nes-core.min.css 52,579 B | 2019-12-17 | checkbox, radio, select, input, dialog, progress, balloon, container, button, icons (no range, no toggle) |
| 98.css 0.1.21 | https://github.com/jdan/98.css | MIT | dist/98.css 26,848 B (minification not checked) | 2025-04-28 | window/title-bar, button, checkbox, radio, range slider, select, progress, text input (selectors present in the CSS) |
| XP.css 0.2.6 | https://github.com/botoxparty/XP.css | MIT | dist/XP.css 256,202 B; dist/98.css 22,982 B | 2022-10-25 | same family as 98.css (extension of it) |
| RPGUI 1.0.3 | https://github.com/RonenNess/RPGUI | zlib (npm field; LICENSE.txt says "zlib-license") | rpgui.min.css 16,011 B + rpgui.min.js 9,378 B; README adds about 1.5 MB of image resources | 2016-01-20 | containers with frames, sliders, progress bars, checkboxes, radio, buttons, dropdown (select), listbox, icons, cursors |

- 98.css and XP.css: the README describes both as "a design system for building faithful recreations of old UIs" (Windows 98 / Windows XP). Look: OS look, not game look. Source: README via npm (https://www.npmjs.com/package/98.css, https://www.npmjs.com/package/xp.css).
- RPGUI: README says "Lightweight framework for old-school RPG GUI in web", needs its JavaScript file as well as CSS ("css+js framework"), default theme uses public-domain graphics by Buch (OpenGameArt). Look: RPG game look, but not specifically cute. Source: README (https://www.npmjs.com/package/rpgui). Last release is 2016.
- NES.css: game look, most complete control set but no range slider.
- "Cute game vs OS look" is my judgement from the README descriptions and not a measured fact: NES.css and RPGUI = game look, 98.css/XP.css = OS look (UNVERIFIED without seeing screenshots).
- pixel-borders and other "pixel border" kits: not searched in detail, no data. Only a roundup article was found, not opened: https://codeburst.io/10-amazing-and-retro-css-kits-24612169f550.
- Repo activity (last commit, open issues) for 98.css, XP.css and RPGUI: not obtained (GitHub not reachable); the npm dates above are the only evidence.

## Answer for Cuy
Only RPGUI (zlib) and NES.css (MIT) have a game look; 98.css and XP.css (both MIT) look like old Windows and do not fit a cute pet game.
Smallest option: RPGUI at about 25 KB of CSS+JS but old (2016) and with 1.5 MB of images; 98.css is also small (26,848 B) and has a range slider, but wrong style.
For a custom cute look the likely choice is own CSS from web/home/style.css, borrowing pieces; pixel-border kits were not checked.
