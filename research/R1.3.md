Question: Compare pixel/retro CSS kits as alternatives to NES.css for a cute pixel-art pet game UI inside a 400x620 window: 98.css, XP.css, RPGUI, pixel-borders (or similar "pixel border" CSS/SCSS mixins), any other maintained kit you find. For each: URL, licence, minified size, last release, which UI controls it styles, and how "cute game" vs "OS look" it is.

## Findings

- 98.css (Windows 98 look): https://github.com/jdan/98.css. Licence MIT (GitHub page). Description: "A design system for building faithful recreations of old UIs." Shows window/title-bar/window-body classes; the page does not list checkbox, radio, range, select, dialog or progress-bar styling, and does not show a release date. Look: OS-style, not cute.
- XP.css (Windows XP look): https://github.com/botoxparty/xp.css. Licence MIT (GitHub page). Description: "A CSS framework for building faithful recreations of operating system GUIs." No release date shown. Look: OS-style, not cute.
- Both kits are "OS look", so they fit poorly with a cute pet game.
- RPGUI, pixel-borders and other kits: NOT VERIFIED. Search returned only roundup articles (https://codeburst.io/10-amazing-and-retro-css-kits-24612169f550), which I did not open.
- Minified sizes and last release dates for all kits: NOT VERIFIED.

## Answer for Cuy
98.css and XP.css are MIT and maintained as design systems, but both look like old Windows, not like a cute pet game.
For a cute pixel UI they are weak fits; a custom pixel-border approach may suit better.
RPGUI and pixel-borders were not checked; their licences, sizes and release dates are unknown.
