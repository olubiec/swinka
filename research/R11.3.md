Question: Which assemblies does the NAudio 2.2.1 NuGet package bring into a .NET Framework 4.8 app (NAudio.Core, NAudio.Wasapi,
NAudio.WinMM, NAudio.Asio, NAudio.Midi, NAudio.WinForms...) and which of them are needed for WaveOutEvent playback plus
WASAPI session peak meters? Total size of those DLLs.

## Findings

**What `NAudio` 2.2.1 pulls in** (NuGet page, official: https://www.nuget.org/packages/NAudio/2.2.1): the package itself is 36.14 KB and is a thin umbrella.
The page lists a .NET Framework 4.7.2 dependency group of NAudio.Asio, NAudio.Core, NAudio.Midi, NAudio.Wasapi, NAudio.WinForms, NAudio.WinMM (all >= 2.2.1).
net48 has no group of its own ("computed"), so NuGet uses the net472 group. The csproj confirms it:
`TargetFrameworks net472;netcoreapp3.1;net6.0-windows;net6.0`, references to all six projects
([NAudio.csproj at v2.2.1](https://github.com/naudio/NAudio/blob/v2.2.1/NAudio/NAudio.csproj)).

**Per package (NuGet pages, size = .nupkg download, not DLL size):**
- NAudio.Core 135.17 KB, netstandard2.0, no dependencies - https://www.nuget.org/packages/NAudio.Core/2.2.1
- NAudio.Wasapi 270.72 KB, netstandard2.0 + uap10.0.18362, depends on NAudio.Core - https://www.nuget.org/packages/NAudio.Wasapi/2.2.1
- NAudio.WinMM 53.58 KB, netstandard2.0, depends on NAudio.Core and Microsoft.Win32.Registry >= 4.7.0 - https://www.nuget.org/packages/NAudio.WinMM/2.2.1
- NAudio.Asio, NAudio.Midi, NAudio.WinForms: project files at v2.2.1 are netstandard2.0 (Asio, Midi; Asio also needs Microsoft.Win32.Registry 4.7.0) and net472/netcoreapp3.1 (WinForms, needs WinMM). Package pages not opened, sizes not found.

**Which type lives where (v2.2.1 source):**
- `WaveOutEvent` -> NAudio.WinMM ([file](https://github.com/naudio/NAudio/blob/v2.2.1/NAudio.WinMM/WaveOutEvent.cs))
- `WaveFileReader`, `SampleChannel`, `VolumeSampleProvider`, `SmbPitchShiftingSampleProvider` -> NAudio.Core
- `AudioFileReader` -> umbrella NAudio.dll ([file](https://github.com/naudio/NAudio/blob/v2.2.1/NAudio/AudioFileReader.cs))
- `MMDeviceEnumerator`, `MMDevice`, `AudioSessionManager`, `AudioSessionControl`, `AudioMeterInformation` -> NAudio.Wasapi (CoreAudioApi folder)

**Minimum set for WaveOutEvent + WASAPI session peak meters:** NAudio.Core + NAudio.WinMM + NAudio.Wasapi
(+ Microsoft.Win32.Registry 4.7.0 transitively from WinMM). Referencing just `NAudio.WinMM` and `NAudio.Wasapi` is enough, because Core comes transitively.
Add the umbrella `NAudio` package only if you use `AudioFileReader` (or want WinForms/Asio/Midi too).
Combined .nupkg size of the minimum set = 135.17 + 270.72 + 53.58 = about 459 KB (compressed packages, not DLLs).

## Answer for Cuy
Use NAudio.WinMM + NAudio.Wasapi (Core arrives automatically); that covers `WaveOutEvent`, `WaveFileReader`, `SampleChannel`, `VolumeSampleProvider`, `SmbPitchShiftingSampleProvider` and all session peak-meter classes.
`AudioFileReader` needs the full `NAudio` package (adds Asio, Midi, WinForms DLLs, which Cuy does not need).
Packages are about 459 KB compressed for the minimum set; real DLL sizes not found (see below).
For `tools/package.ps1`: copy NAudio.Core.dll, NAudio.WinMM.dll, NAudio.Wasapi.dll (+ Microsoft.Win32.Registry.dll if it is not already in the output) - UNVERIFIED on the exact copy list, check the build output.
