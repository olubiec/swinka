# W1-09: Care data loader (Core): care.json reaches the game
Goal: `assets/data/care.json` is parsed into `CareDataRoot` with every field filled (snake_case keys included) and a test proves it.
Depends on: nothing (wave start). Facts: `care.json` uses snake_case (`every_days`, `weight_log`, `weight_alert`, `drop_grams`, `drop_percent`, `snooze_minutes`), but `CareDataRoot`, `CareTaskDefinition` and `WeightAlertSettings` (`src/Cuy.Core/Care/CareTaskDefinition.cs`) have no `[JsonProperty]`, so a plain `JsonConvert.DeserializeObject` would silently leave `EveryDays`, `WeightLog` and the alert thresholds empty. Today nothing in the app loads this file (`Pet.SetCareTasks` is called only by tests); W2-01 wires the result into the desktop.
Pattern: see AGENTS.md, "Data tables" (`Current`, `Load(string)`, `LoadDefault()`).
Change: new `src/Cuy.Core/Care/CareData.cs`, new `tests/Cuy.Core.Tests/CareDataTests.cs`
Do not touch: `CareTaskDefinition.cs` (no attributes: use a naming strategy), `Pet.Care.cs`, everything else; in particular `AGENTS.md`, `docs/PLAN.md`, `tasks/*`.
Steps:
1. `public static class CareData` in namespace `Cuy.Core.Care`: `static CareDataRoot Current` (lazy `LoadDefault()`), `static CareDataRoot Load(string json)`, `static CareDataRoot LoadDefault()` (file `assets/data/care.json`, same candidate paths as `EconomyConfig.LoadDefault`; when missing: an empty task list plus the defaults below and one `ItemCatalog.ErrorLogger` message; do not copy the task list into code).
2. `Load` deserializes with `new JsonSerializerSettings { ContractResolver = new DefaultContractResolver { NamingStrategy = new SnakeCaseNamingStrategy() } }`. Afterwards it fills safe defaults: null `Tasks` -> empty list; null `WeightAlert` -> `DropGrams 50`, `DropPercent 5`; null or empty `SnoozeMinutes` -> `[15, 60, 180]`. It drops (and logs through `ItemCatalog.ErrorLogger`) every task with an empty `Id` or a `Schedule` other than `daily`, `weekly`, `every_n_days`. Broken JSON never throws: log and return the defaults with no tasks.
3. Tests (`RepoFile` helper from AGENTS.md; use `CareData.Load(File.ReadAllText(RepoFile("assets/data/care.json")))`, never assign `Current`): 9 tasks with ids veggies, water, hay, spot_clean, weigh, full_clean, brush, nails, vet_check; `nails.EveryDays == 28`, `vet_check.EveryDays == 365`; `weigh.WeightLog == true` and `weigh.Weekday == 0`; `full_clean.Weekday == 6`; alert 50 g and 5 %; snooze `[15, 60, 180]`; every task has a non-empty `Title` and `Text` and a `Time` matching `HH:mm`; broken JSON returns the defaults without throwing; a task with an unknown schedule is dropped; every loaded task works with `CareSchedule` (call `CareSchedule.NextDueLocal` for each with a `ManualClock`, no exception, `every_n_days` tasks have `EveryDays > 0`).
Verify: `dotnet test tests/Cuy.Core.Tests/Cuy.Core.Tests.csproj -c Release` passes.
Prohibited: changing or deleting existing test assertions, new dependencies, touching files outside "Change".
PR: what was done, decisions and why, how to check by hand; screenshot if the change is visual.
