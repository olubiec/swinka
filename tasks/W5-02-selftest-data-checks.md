Goal: `Cuy.exe --selftest` catches broken data and missing files in the package before a player does.
Depends on: W4-02 (`SpriteSheetLoader`), W4-07 (`achievements.json`), W3-08 (`tricks.json`), W3-06 (`games.json`) merged.
Facts: `Check(name, action)` writes `PASS name` or `FAIL name: reason`; existing checks in order: assets folder, actions.json, items.json, actions animations, sprite sheets, icons.json, icons_16.png, sounds, WebView2, mouse shake detector, behaviors, spritesheet, save folder writable. Data files: `assets/music/tracks.json` (array of `{id, file, title, author, license, url, use}`, `file` relative to `assets/`), `assets/coloring/index.json` (`{version, packs:[{id, title, price, count, thumb}]}`) with one `assets/coloring/<packId>.json` per pack (`{id, title, pictures:[{id, title, w, h, palette, cells}]}`, `cells` is a string of `w*h` characters), `assets/icons/icons.json` (`{size:16, icons:{id:index}}`) with `assets/icons/icons_16.png`.
Steps:
1. Add hand-written checks (no library) in the same PASS/FAIL format, placed after `Check("sounds", ...)`: `data json` (every `assets/data/*.json` parses with `JToken.Parse`); `item ids` (ids unique across `items.json`, `items_shop.json`, `items_decor.json`); `core data tables` (care, economy, health, bond, hay, tricks, achievements, diary load through the Core code that reads them: find it with `grep -rn "care.json" src`); `music` (every `file` in `tracks.json` exists under `assets/` and is larger than 10 KB); `coloring` (every pack of `index.json` has its file, `pictures.Count == count`, every picture has `cells.Length == w * h`); `features` (every folder in `web/home/features` has a `feature.js` and the ids in `web/home/features/index.json` equal the folder names); `games` (every file named in `web/home/minigames/games.json` exists); `icon indexes` (every index in `icons.json` is below columns*rows of `icons_16.png`).
2. `stage sheets`: all five stages (`baby`, `junior`, `adult`, `senior`, `legend`) load through `SpriteSheetLoader` with the same frame count and 64x64 frames, and the frames of the stage sheet that matches the embedded sheet are pixel-identical to the embedded sprites (this proves the loader slices in the same order as `Xml`).
3. The `WebView2` check becomes a WARN: catch `WebView2RuntimeNotFoundException` and an empty version, print `WARN WebView2: runtime not installed (Home will not open)`. WARN does not set the failed flag and does not change the exit code. Keep printing `     version <x>` when the runtime exists.
