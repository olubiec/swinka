Goal: Every pig profile can carry its own birth moment, origin, own legend threshold and memorial flag, and a pure helper turns them into that pig's age and life stage.
Depends on: nothing (wave start).
Facts: Today the whole roster shares one life (`GameState.BirthDateUtc`, `Pet.Age`, `Pet.Stage`). `PigAge.FromBirth(birthUtc, nowUtc, pigDaysPerRealDay)` and `LifeStages.FromPigDays` exist in `LifeStage.cs`; 1 real day = `Balance.PigDaysPerRealDay` (21) pig days. Save rule (AGENTS.md): never delete or rename save fields, add new ones with safe defaults; old saves must load. `PigProfile` is serialized with Newtonsoft, so new properties with defaults need no migration.
Steps:
1. `PigProfile`: add `string NamedId { get; set; }` (null = adopted or random pig), `DateTime? BornAtUtc { get; set; }` (null = use the game's `BirthDateUtc`), `DateTime? ArrivedAtUtc { get; set; }`, `double? LegendAtYears { get; set; }` (null = the game default of 8 years), `bool Memorial { get; set; }` (false; any pig can be switched to memorial mode by the player). Keep every existing member and the `CreateRandom` behavior unchanged.
2. New static class `Cuy.Core.Pigs.PigLife`: `static DateTime BornAtFor(DateTime arrivalUtc, double startAgeYears, double pigDaysPerRealDay)` = arrival minus `startAgeYears * LifeStages.DaysPerYear / pigDaysPerRealDay` real days; `static PigAge AgeOf(PigProfile pig, DateTime nowUtc, double pigDaysPerRealDay, DateTime fallbackBirthUtc)` (uses `BornAtUtc ?? fallbackBirthUtc`); `static LifeStage StageOf(PigProfile pig, DateTime nowUtc, double pigDaysPerRealDay, DateTime fallbackBirthUtc)` (a memorial pig is always `LifeStage.Legend`; otherwise: when `LegendAtYears` is set, the stage is `Legend` once the age in years reaches it and never above `Senior` before that; when it is null the usual `LifeStages.FromPigDays` applies). Null profile: return age of the fallback.
3. Tests (`PigLifeTests.cs`): a pig born by `BornAtFor(now, 2.0, 21)` is 2 years old (`Years == 2`) and `Adult`; with start age 1.2 it is `Adult`; at 0 it is `Baby`, and exactly 1 real day later `Junior`; 4.0 years gives `Senior`, 8.0 gives `Legend` when `LegendAtYears` is null; with `LegendAtYears = 6.0` the age 5.9 is `Senior` and 6.0 is `Legend`; with `LegendAtYears = 9.5` the age 8.5 is still `Senior`; a pig without `BornAtUtc` uses the fallback; a memorial pig is `Legend` at age 0; JSON round trip of a profile keeps the five new fields; JSON of an old profile (only `Id`, `Name`, `Breed`, `PaletteId`, `Traits`) loads with `NamedId == null`, `BornAtUtc == null`, `ArrivedAtUtc == null`, `LegendAtYears == null`, `Memorial == false`.
