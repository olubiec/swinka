Goal: Core loads the five named pigs (look, start age, legend range, adoption offer, traits, modifiers, welcome pack) from `assets/data/pigs_named.json` through a data table with the usual `Current`/`Load`/`LoadDefault` pattern.
Depends on: nothing (wave start). Design and numbers: `docs/NAMED_PIGS.md`; the data file already exists and is the single source of the numbers.
Facts: Pattern: AGENTS.md "Data tables" (`EconomyConfig`; errors go through `ItemCatalog.ErrorLogger`). The file has `welcome`, `modifier_limits`, `modifier_keys` and `pigs[]` (`id`, `name`, `look{breed,palette_id,pattern,palette}`, `start_age_years`, optional `legend_years` `{min,max}`, `offer` = `{group?, after_days, cost}`, `traits`, `blurb`, `weight_g` (may be null), `modifiers` (eight numbers)) plus top-level `legend_years_default` `{min,max}` and `offer_groups` `[{id,label,pigs[]}]`. Pigs are not born automatically: the player adopts them from offers (docs/NAMED_PIGS.md section 2). Memorial mode is a per-player flag, not data. Unknown fields must be ignored (the art track may add `sprite_set` later). Do not use `PigModifiers` (it arrives in the same wave): keep modifiers as `IReadOnlyDictionary<string,double>`.
Steps:
1. `NamedPigDefinition` (sealed): `Id`, `Name`, `Breed`, `PaletteId`, `Pattern`, `Palette`, `StartAgeYears`, `LegendYearsMin` and `LegendYearsMax` (the defaults when the pig has no own range), `OfferGroup` (string or null), `OfferAfterDays` (int), `OfferCost` (int), `Traits` (IReadOnlyList<string>), `Blurb`, `WeightG` (int?), `Modifiers` (IReadOnlyDictionary<string,double>).
2. `NamedPigCatalog` (sealed): `static Current` (lazy `LoadDefault()`), `static Load(string json)`, `static LoadDefault()` (same file candidates as `EconomyConfig.LoadDefault`, then code defaults = the five pigs with id, name, breed, palette id, start age and arrival only, neutral modifiers, comment that they are used only when the file is missing). Members: `IReadOnlyList<NamedPigDefinition> Pigs` (file order), `IReadOnlyList<NamedPigDefinition> OfferGroup(string groupId)`, `NamedPigDefinition Find(string id)` (null when unknown), `WelcomeClovers`, `IReadOnlyDictionary<string,int> WelcomeItems`, `ModifierMin`, `ModifierMax`, `IReadOnlyList<OfferGroupDefinition> Groups` (`Id`, `Label`, `PigIds`).
3. Load rules: bad JSON gives the code defaults (logged); a duplicate id keeps the first; a legend range with min >= max or min below 4.5 years falls back to the default range (logged); a negative `after_days` or `cost` becomes 0 (logged); an offer group naming an unknown pig drops that pig from the group (logged); a modifier value that is not finite or <= 0 becomes 1.0 and is logged; values outside `modifier_limits` are clamped to them; a missing modifier key means 1.0.
4. Tests (`NamedPigCatalogTests.cs`; use `RepoFile` and `NamedPigCatalog.Load(File.ReadAllText(RepoFile("assets/data/pigs_named.json")))`, never assign `Current`): order is kuki, ned, james, glen, racuch; group `starter` holds kuki and ned (after_days 0, cost 0); james after_days 90 cost 100, glen 105 cost 100, racuch 130 cost 100; start ages 0.1, 0.0, 0.0, 1.2, 0.0; kuki legend range 6.0-7.5, ned 7.0-9.5, the others use the default 6.5-9.5; every pig has the eight modifier keys inside the limits; welcome is 0 clovers plus 2 `bell_pepper` and 2 `parsley`; every look `breed` exists as a key in `assets/sprites/breeds.json` and every `palette_id` exists in `assets/sprites/palettes.json` `palettes`; broken JSON gives defaults; a legend range with min >= max falls back to the default; a group naming an unknown pig drops it; a duplicate id is ignored; unknown extra fields do not break loading; an out-of-range modifier is clamped; every pig id has the five baked sheets `assets/sprites/pigs/<id>/<stage>/spritesheet.png` (stages baby, junior, adult, senior, legend) and an entry in `assets/sprites/pigs/pigs.json`.
