# W11-01: Named pig catalog (loader for pigs_named.json)
Zmieniaj: src/Cuy.Core/Pigs/NamedPigCatalog.cs, tests/Cuy.Core.Tests/NamedPigCatalogTests.cs
Wymagane: src/Cuy.Core/Pigs/NamedPigCatalog.cs, tests/Cuy.Core.Tests/NamedPigCatalogTests.cs

Nie ruszaj: src/Cuy/*, AGENTS.md, docs/*, tasks/*, assets/data/pigs_named.json
Goal: Core loads the five named pigs (look, start age, arrival rule, traits, modifiers, welcome pack) from `assets/data/pigs_named.json` through a data table with the usual `Current`/`Load`/`LoadDefault` pattern.
Depends on: nothing (wave start). Design and numbers: `docs/NAMED_PIGS.md`; the data file already exists and is the single source of the numbers.
Facts: Pattern: AGENTS.md "Data tables" (`EconomyConfig`; errors go through `ItemCatalog.ErrorLogger`). The file has `welcome`, `modifier_limits`, `modifier_keys` and `pigs[]` (`id`, `name`, `look{breed,palette_id,pattern,palette}`, `start_age_years`, `arrival` = `{at_start:true}` or `{after:<pig id>, source_age_years:<n>}`, `traits`, `blurb`, `weight_g` (may be null), `modifiers` (eight numbers), `memorial`). Unknown fields must be ignored (the art track may add `sprite_set` later). Do not use `PigModifiers` (it arrives in the same wave): keep modifiers as `IReadOnlyDictionary<string,double>`.
Steps:
1. `NamedPigDefinition` (sealed): `Id`, `Name`, `Breed`, `PaletteId`, `Pattern`, `Palette`, `StartAgeYears`, `AtStart` (bool), `AfterId` (string, null for start pigs), `SourceAgeYears`, `Traits` (IReadOnlyList<string>), `Blurb`, `WeightG` (int?), `Modifiers` (IReadOnlyDictionary<string,double>), `Memorial` (bool).
2. `NamedPigCatalog` (sealed): `static Current` (lazy `LoadDefault()`), `static Load(string json)`, `static LoadDefault()` (same file candidates as `EconomyConfig.LoadDefault`, then code defaults = the five pigs with id, name, breed, palette id, start age and arrival only, neutral modifiers, comment that they are used only when the file is missing). Members: `IReadOnlyList<NamedPigDefinition> Pigs` (file order), `IReadOnlyList<NamedPigDefinition> StartPigs`, `NamedPigDefinition Find(string id)` (null when unknown), `WelcomeClovers`, `IReadOnlyDictionary<string,int> WelcomeItems`, `ModifierMin`, `ModifierMax`.
3. Load rules: bad JSON gives the code defaults (logged); a duplicate id keeps the first; a pig whose `after` id is not defined earlier in the list is skipped and logged; a modifier value that is not finite or <= 0 becomes 1.0 and is logged; values outside `modifier_limits` are clamped to them; a missing modifier key means 1.0.
4. Tests (`NamedPigCatalogTests.cs`; use `RepoFile` and `NamedPigCatalog.Load(File.ReadAllText(RepoFile("assets/data/pigs_named.json")))`, never assign `Current`): order is kuki, ned, james, glen, racuch; start pigs are kuki and ned; james is after kuki at 7.5, glen after james at 0.5, racuch after ned at 7.5; start ages 2.0, 0.0, 0.0, 1.2, 0.0; every pig has the eight modifier keys inside the limits; welcome is 50 clovers plus 2 `bell_pepper` and 2 `parsley`; every look `breed` exists as a key in `assets/sprites/breeds.json` and every `palette_id` exists in `assets/sprites/palettes.json` `palettes`; broken JSON gives defaults; a pig with an unknown `after` is skipped; a duplicate id is ignored; unknown extra fields do not break loading; an out-of-range modifier is clamped; every pig id has the five baked sheets `assets/sprites/pigs/<id>/<stage>/spritesheet.png` (stages baby, junior, adult, senior, legend) and an entry in `assets/sprites/pigs/pigs.json`.
