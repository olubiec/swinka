## `orkiestra/config.py`
```python
CONFIG_FILENAME = "orkiestra.toml"
DEFAULT_CONFIG_TOML: str  # exact same text as orkiestra.toml.example

def load_config(repo_root: Path, path: Path | None = None) -> Config: ...
def worktree_root(config: Config) -> Path: ...   # (repo_root / run.worktree_dir).resolve()
def state_dir(config: Config) -> Path: ...       # (repo_root / run.state_dir).resolve()
```
`load_config`:
- `repo_root = repo_root.resolve()`. Default path `repo_root / CONFIG_FILENAME`.
  If `path` is None and the default file is missing → return `Config(repo_root=repo_root)` (all defaults).
  If `path` was given explicitly and is missing → `ConfigError`.
- Parse with `tomllib`. Allowed sections: `project`, `agent`, `run`; allowed keys = the dataclass field
  names of `ProjectConfig`, `AgentConfig`, `RunConfig` (use `dataclasses.fields`). Unknown section/key →
  `ConfigError` naming it (in Polish, e.g. `Nieznany klucz [agent].modle`).
- Type checks with clear `ConfigError` messages. Conversions:
  `agent.cmd`: str → `(str,)`, list[str] → tuple, must be non-empty; `agent.extra_args`: list[str] → tuple;
  `agent.model` and `project.test_command`: empty string → `None`.
- Value checks: `project.merge_mode` in {"github","local"}; `agent.output_format` in {"json","text"};
  `agent.timeout_minutes`, `run.max_parallel`, `run.max_attempts`, `run.quota_wait_minutes`,
  `run.ci_timeout_minutes` are ints >= 1 (reject bool).

## `orkiestra.toml.example` (and `DEFAULT_CONFIG_TOML`)
Same content in both (in `config.py` as a triple-quoted string). Every key from the three dataclasses, with
default values, each with a short Polish comment. Use exactly these values:
```
[project] base_branch="main", remote="origin", test_command="pytest -q", merge_mode="github"
[agent]   cmd=["agy"], model="", timeout_minutes=20, skip_permissions=true, add_dir=true,

```
Comment for `model`: `# slug z "agy models", np. model Flash; puste = domyślny model agy`.

## `orkiestra/state.py`
```python
class StateStore:
    def __init__(self, state_dir: Path) -> None: ...
    @property
    def path(self) -> Path: ...                       # state_dir / "state.json"
    def load(self) -> RunState | None: ...
    def save(self, state: RunState) -> None: ...
    def init_or_merge(self, plan: Plan, plan_hash: str) -> RunState: ...
    def update(self, state: RunState, task_id: str, **changes: object) -> TaskState: ...
    def log_path(self, task_id: str, attempt: int) -> Path: ...
```
- JSON on disk: `{"plan_hash", "current_wave", "quota_paused_until", "tasks": {id: {all TaskState fields}}}`;
  `status` stored as its string value; unknown fields in JSON are ignored on load.
- `save`: create `state_dir`, write to `state.json.tmp` then `os.replace` (atomic), `indent=2`,
  `ensure_ascii=False`.
- One `threading.Lock` per store. `update` holds the lock, applies `setattr` for each change (unknown field →
  `AttributeError`), sets `updated_at = datetime.now(timezone.utc).isoformat(timespec="seconds")`, saves the
  whole state, returns the TaskState. `save` also takes the lock (use `threading.RLock`).
- `init_or_merge`: load existing (or new `RunState(plan_hash=...)`); for each task in the plan, keep the
  existing `TaskState` (update its `wave_id`) or create a new PENDING one; drop states of tasks no longer in
  the plan; any task in `RUNNING` becomes `PENDING` (interrupted run); set `plan_hash`; save; return.
- `log_path`: `state_dir / "logs" / f"{task_id}-a{attempt}.log"`, creating the `logs` dir.

## Tests
`tests/test_config.py`: defaults when file missing; explicit missing path → ConfigError; the example file
(`Path(__file__).parent.parent / "orkiestra.toml.example"`) loads and equals defaults except
`test_command == "pytest -q"`; `DEFAULT_CONFIG_TOML` equals the example file text; cmd str → tuple;
empty model → None; unknown key and bad merge_mode → ConfigError; `max_parallel = true` rejected;
`worktree_root` resolves relative to repo_root.
`tests/test_state.py`: save/load round trip with enum; atomic file exists, no `.tmp` left; init_or_merge keeps
existing status, adds new tasks, drops removed ones, resets RUNNING → PENDING; `update` sets updated_at and
persists; 8 threads × 50 updates on different tasks → final file is valid JSON with all counts correct;
`log_path` creates the directory.
