## Public API of `orkiestra/gitops.py`
```python
def run_git(args: list[str], cwd: Path, check: bool = True) -> subprocess.CompletedProcess[str]: ...
def base_ref(project: ProjectConfig) -> str: ...
def fetch(repo_root: Path, remote: str) -> None: ...
def current_branch(repo_root: Path) -> str: ...
def is_clean(repo_root: Path) -> bool: ...
def create_worktree(repo_root: Path, path: Path, branch: str, base: str) -> Path: ...
def remove_worktree(repo_root: Path, path: Path, branch: str | None = None) -> None: ...
def changed_files(worktree: Path, base: str) -> list[str]: ...
def commit_all(worktree: Path, message: str) -> bool: ...
def rebase_onto(worktree: Path, base: str) -> bool: ...
def push_branch(worktree: Path, remote: str, branch: str) -> None: ...
def delete_remote_branch(repo_root: Path, remote: str, branch: str) -> None: ...
def merge_local(repo_root: Path, branch: str, base_branch: str) -> None: ...
```
Behaviour:
- `run_git`: `subprocess.run(["git", *args], cwd=cwd, capture_output=True, text=True, check=False)`. If
  `check` and returncode != 0 → `GitError(f"git {' '.join(args)} nie powiodło się", stderr=proc.stderr)`.
- `base_ref`: `f"{remote}/{base_branch}"` when `merge_mode == "github"`, else `base_branch`.
- `fetch`: `git fetch <remote> --prune`.
- `current_branch`: `git rev-parse --abbrev-ref HEAD`, stripped. `is_clean`: `git status --porcelain` is empty.
- `create_worktree`: idempotent. `path = path.resolve()`.
  1. If `path` exists and `git -C path rev-parse --abbrev-ref HEAD` == `branch` → return path (reuse, keeps
     previous agent work for a retry/resume).
  2. If `path` exists otherwise → `GitError` (refuse to clobber).
  3. Create `path.parent`. If the branch already exists (`git rev-parse --verify --quiet refs/heads/<branch>`
     returns 0) → `git worktree add <path> <branch>`; else `git worktree add -b <branch> <path> <base>`.
- `remove_worktree`: if path exists → `git worktree remove --force <path>` (check=False); always
  `git worktree prune`; if `branch` → `git branch -D <branch>` (check=False).
- `changed_files`: union of
  (a) `git diff --name-only <base>...HEAD` (committed on the branch since base) and
  (b) paths from `git status --porcelain --untracked-files=all` (uncommitted; for `R  old -> new` take `new`;
      strip the 3-char status prefix; unquote paths wrapped in `"`).
  Return sorted unique list, excluding `RESULT_FILE`.
- `commit_all`: `git add -A`; `git reset -q -- <RESULT_FILE>` (check=False); if
  `git diff --cached --quiet` returns 0 → return False; else `git commit -m <message>` → True.
- `rebase_onto`: `git rebase <base>`; on failure run `git rebase --abort` (check=False) and return False.
- `push_branch`: `git push --force-with-lease -u <remote> <branch>`.
- `delete_remote_branch`: `git push <remote> --delete <branch>` with check=False (best effort).
- `merge_local`: if `current_branch(repo_root) != base_branch` → `GitError` ("repozytorium główne musi być na
  gałęzi <base>"); if not `is_clean` → `GitError`; `git merge --no-ff --no-edit <branch>`; on failure
  `git merge --abort` (check=False) and re-raise.

## `tests/test_gitops.py`
Cover with real git (fixtures): create worktree from `main`, reuse on second call, refuse foreign existing dir;
existing branch without worktree is re-attached; `changed_files` sees committed + modified + untracked + renamed
files and ignores RESULT_FILE; `commit_all` returns False when nothing to commit and never commits RESULT_FILE;
`rebase_onto` succeeds on disjoint changes and returns False (and leaves no rebase in progress) on a conflict;
`merge_local` merges into main and errors when main repo is on another branch or dirty;
with `git_repo_with_remote`: `fetch`, `base_ref` for github mode = `origin/main`, worktree from `origin/main`,
`push_branch` creates the branch in the bare repo, `delete_remote_branch` removes it; `remove_worktree` deletes the
directory and the local branch.
