# T3.2 — Antigravity agent runner (Wave 3, parallel with T3.1, T3.3)

## Context
Read `orkiestra/models.py` and `orkiestra/errors.py` first. This module runs ONE headless Antigravity CLI call:
`agy -p "<prompt>" ...` with cwd = the task's worktree, captures output to a log file, and reports success,
timeout or exhausted quota. Official headless facts you can rely on:
- `--output-format json` prints one JSON object: `{"status": "SUCCESS"|"ERROR"|"CANCELED"|..., "response": str,
  "error": str, "usage": {...}}`. `text` prints only the response.
- `--print-timeout 20m` = agy's own max wait; `--model <slug>`; `--dangerously-skip-permissions` auto-approves
  tools (without it headless agy silently refuses edits and still exits 0); `--add-dir <dir>` adds a workspace dir.
- Old agy (< 1.2.11) printed NOTHING when stdout was not a TTY → optional pseudo-terminal mode.

## Public API of `orkiestra/agent.py`
```python
QUOTA_RE: re.Pattern[str]
def parse_reset_seconds(text: str) -> int | None: ...
def detect_quota(exit_code: int, text: str) -> tuple[bool, int | None]: ...
def build_agy_args(config: AgentConfig, prompt: str, worktree: Path, *, model: str | None,
                   timeout_minutes: int) -> list[str]: ...
def parse_output(stdout: str, output_format: str) -> tuple[bool, str, str]: ...  # (ok, response, error)
def run_agent(prompt: str, worktree: Path, config: AgentConfig, *, model: str | None,
              timeout_minutes: int, log_path: Path) -> AgentResult: ...
```
- `QUOTA_RE`: case-insensitive `quota|rate[ _-]?limit|RESOURCE_EXHAUSTED|(?<!\d)429(?!\d)|too many requests`.
- `parse_reset_seconds`: from prose like "resets in 4 hours and 50 minutes", "retry after ~28 minutes",
  "in 30s", "4h50m" → total seconds; first mention of each unit (h/m/s) wins; None if nothing found.
- `detect_quota`: quota only if `exit_code != 0` AND `QUOTA_RE` matches `text` → `(True, parse_reset_seconds(text))`;
  otherwise `(False, None)`. (A successful answer that merely mentions "429" must NOT count.)
- `build_agy_args` → `[*config.cmd, "-p", prompt, "--output-format", config.output_format,
  "--print-timeout", f"{timeout_minutes}m"]`, then `["--model", model]` if model, then
  `"--dangerously-skip-permissions"` if `config.skip_permissions`, then `["--add-dir", str(worktree)]` if
  `config.add_dir`, then `*config.extra_args`.
- `parse_output`: strip `\r`. For `json`: try `json.loads(stdout.strip())`; if that fails, try the last line that
  starts with `{`. If parsed dict: `ok = status == "SUCCESS"`, return `(ok, str(response or ""), str(error or ""))`.
  If not parseable (or format is `text`): `(bool(stdout.strip()), stdout.strip(), "")`.
- `run_agent`:
  1. `args = build_agy_args(...)`; `start = time.monotonic()`; `hard_timeout = _hard_timeout(timeout_minutes)`
     where module-level `def _hard_timeout(minutes: int) -> float: return minutes * 60 + 60` (tests monkeypatch it).
  2. If `config.use_pty`: `exit_code, stdout = _run_in_pty(args, worktree, hard_timeout)` (stderr merged);
     else `subprocess.run(args, cwd=worktree, capture_output=True, text=True, timeout=hard_timeout,
     stdin=subprocess.DEVNULL, check=False)`.
  3. `FileNotFoundError` → raise `AgentError(f"Nie znaleziono polecenia agenta: {config.cmd[0]}")`.
     `subprocess.TimeoutExpired` → result `ok=False, exit_code=-1, timed_out=True, error="timeout"`.
  4. `ok, response, error = parse_output(...)`; if `exit_code != 0` → `ok = False`.
     If exit 0 and stdout empty → `ok=False`, `error = "pusty wynik agy: brak uprawnień (soft-deny) albo błąd TTY –
     ustaw agent.use_pty = true"`.
  5. Quota: `detect_quota(exit_code, stdout + "\n" + stderr + "\n" + error)`.
  6. Write the log file (create parent dirs): the args with the prompt replaced by `<prompt: N znaków>`, exit code,
     duration, then `--- stdout ---` and `--- stderr ---` sections. Return `AgentResult` with `log_path`,
     `duration_s`, and `response` truncated to 2000 chars.
- `_run_in_pty(args, cwd, timeout) -> tuple[int, str]`: POSIX only (on Windows raise
  `AgentError("use_pty działa tylko na Linux/macOS")`). `master, slave = pty.openpty()`; set a wide window
  (2000 cols) with `fcntl.ioctl(slave, termios.TIOCSWINSZ, struct.pack("HHHH", 50, 2000, 0, 0))`; `Popen(args,
  cwd=cwd, stdin=subprocess.DEVNULL, stdout=slave, stderr=slave, close_fds=True)`; close slave in the parent; read
  master with `select` + `os.read` until EOF/`OSError`, killing the process on timeout (then raise
  `subprocess.TimeoutExpired`); strip ANSI escapes with `re.sub(r"\x1b\[[0-?]*[ -/]*[@-~]|\x1b\][^\x07]*\x07", "", text)`.

## `tests/fakes/fake_agy.py` (used by THIS task and later E2E tests — implement fully)
Executable Python script (shebang `#!/usr/bin/env python3`, also runnable as `python fake_agy.py ...`).
- Parse argv manually: prompt = value after `-p`; output format = value after `--output-format` (default text).
- If env `FAKE_AGY_LOG` is set: append `json.dumps(sys.argv[1:])` + newline to that file.
- Mode: if env `FAKE_AGY_MODES_FILE` points to an existing non-empty file, pop its FIRST line as the mode (rewrite
  the file without it); otherwise env `FAKE_AGY_MODE` (default `edit`).
- Modes (cwd = worktree):
  - `edit`: for each prompt line matching `^\s*FAKE_WRITE:\s*(\S+)\s*$` write that relative file (mkdir parents)
    with `"written by fake agy\n"`; write `.orkiestra-result.json` = `{"status":"done","note":"fake"}`; succeed.
  - `noop`: succeed without writing anything.
  - `blocked`: write result file `{"status":"blocked","note":"fake blocked"}`; succeed.
  - `quota`: print error envelope with error `"RESOURCE_EXHAUSTED: quota exceeded, resets in 2 minutes"`, exit 1.
  - `fail`: print error envelope with error `"boom"`, exit 1.
  - `empty`: print nothing, exit 0.
  - `sleep`: sleep `float(env FAKE_AGY_SLEEP or 5)` seconds, then behave like `edit`.
- Succeed = print `{"status":"SUCCESS","response":"DONE: fake","error":"","usage":{}}` for json, or `DONE: fake`
  for text; exit 0. Error envelope = `{"status":"ERROR","response":"","error":<msg>,"usage":{}}` (text: msg to stderr).
