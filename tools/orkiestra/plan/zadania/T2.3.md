# T2.3 — Prompt builder and template (Wave 2, parallel with T2.1, T2.2)

## Context
Read `orkiestra/models.py` first. Every agent run gets ONE self-contained prompt: fixed rules from a
template + the task's own prompt + (on retry) feedback about what failed. The prompt must keep the agent
cheap: no repo exploration, no git, a one-line final reply, and a small JSON result file.

## Files (create only these)
- `orkiestra/prompts.py`
- `orkiestra/templates/task_prompt.md`
- `tests/test_prompts.py`

(`orkiestra/templates/__init__.py` already exists — do not touch it.)

## `orkiestra/templates/task_prompt.md` (copy exactly; it is a `string.Template`)
```
You are an autonomous coding agent working in an isolated git worktree of a larger project.
Task ${task_id}: ${title} (wave ${wave_id})

## Rules
- Modify ONLY files matching these patterns (create them if needed):
${files}
- Open only the files you need. Do not explore or summarize the whole repository.
- Do NOT run git commit, push, checkout, branch or create pull requests.
- If AGENTS.md exists in the repository root, follow it.
${test_rule}
- When finished, write the file `${result_file}` in the repository root containing JSON:
  {"status": "done", "note": "<max 20 words>"}
  If you cannot complete the task, write {"status": "blocked", "note": "<reason, max 30 words>"} and stop.
- Your final reply must be ONE line, max 20 words. No summaries.

## Task
${prompt}
${feedback}
```

## `orkiestra/prompts.py`
```python
TEMPLATE_NAME = "task_prompt.md"
MAX_FEEDBACK_CHARS = 4000

def load_template(config: Config) -> str: ...
def effective_test_command(task: Task, config: Config) -> str | None: ...
def truncate_tail(text: str, max_chars: int) -> str: ...
def build_prompt(task: Task, wave: Wave, config: Config, feedback: str | None = None) -> str: ...
```
- `load_template`: if `config.repo_root / config.run.state_dir / TEMPLATE_NAME` exists, read it (user override);
  otherwise `importlib.resources.files("orkiestra.templates").joinpath(TEMPLATE_NAME).read_text(encoding="utf-8")`.
- `effective_test_command`: `task.test_command or config.project.test_command` (None if both empty).
- `truncate_tail`: if `len(text) <= max_chars` return it unchanged; else return
  `"...[skrócono]\n" + text[-max_chars:]` (keep the END — test output tails matter most).
- `build_prompt` uses `string.Template(...).substitute(...)` with:
  - `files`: one line per pattern: `  - <pattern>`
  - `test_rule`: if a test command exists:
    `- Before finishing, run \`<cmd>\` once; fix failures (max 3 attempts).` else empty string.
  - `result_file`: `RESULT_FILE` from models.
  - `feedback`: empty string, or when `feedback` is given:
    `"\n## Previous attempt failed\n" + truncate_tail(feedback, MAX_FEEDBACK_CHARS) +
    "\nFix exactly this problem. Keep the correct work already present in the files."`
  - Return the result with trailing whitespace stripped + `"\n"`; collapse 3+ consecutive newlines into 2.
- Use `substitute` (not `safe_substitute`) so a broken custom template fails loudly; task prompts may
  contain `$` — they are inserted as values, which is safe.
