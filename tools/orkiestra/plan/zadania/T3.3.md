## Public API of `orkiestra/github.py`
```python
def run_gh(args: list[str], cwd: Path, check: bool = True) -> subprocess.CompletedProcess[str]: ...
def ensure_ready(repo_root: Path) -> None: ...
def find_open_pr(repo_root: Path, branch: str) -> str | None: ...
def create_pr(repo_root: Path, branch: str, base: str, title: str, body: str) -> str: ...
def checks_state(pr_url: str, cwd: Path) -> str: ...          # "pass" | "fail" | "pending" | "none"
def wait_for_checks(pr_url: str, cwd: Path, timeout_minutes: int, *, poll_seconds: int = 30,
                    grace_seconds: int = 60, sleep: Callable[[float], None] = time.sleep,
                    clock: Callable[[], float] = time.monotonic) -> str: ...   # + "timeout"
def mergeable(pr_url: str, cwd: Path) -> str: ...             # "MERGEABLE" | "CONFLICTING" | "UNKNOWN"
def merge_pr(pr_url: str, cwd: Path, *, sleep: Callable[[float], None] = time.sleep) -> None: ...
def comment(pr_url: str, cwd: Path, body: str) -> None: ...
```
Behaviour:
- `run_gh`: `subprocess.run(["gh", *args], cwd=cwd, capture_output=True, text=True, check=False)`;
  `FileNotFoundError` → `GitHubError("Nie znaleziono gh – zainstaluj GitHub CLI")`; if `check` and
  returncode != 0 → `GitHubError(f"gh {args[0]} {args[1] if len(args) > 1 else ''} nie powiodło się", stderr=...)`.
- `ensure_ready`: `gh auth status` (check=False); non-zero → `GitHubError("gh nie jest zalogowany – uruchom: gh auth login")`.
- `find_open_pr`: `gh pr list --head <branch> --state open --json url --limit 1` → url or None.
- `create_pr`: return `find_open_pr(...)` if any; else
  `gh pr create --head <branch> --base <base> --title <title> --body <body>` → the last non-empty stdout line
  that starts with `https://` (else `GitHubError`).
- `checks_state`: `gh pr checks <url> --json name,bucket` with check=False. If stdout parses as a JSON list:
  empty → `"none"`; any bucket in {"fail", "cancel"} → `"fail"`; any `"pending"` → `"pending"`; else `"pass"`
  (`"skipping"` counts as pass). If not JSON: if `"no checks reported"` appears in lower-cased stdout+stderr →
  `"none"`; else raise `GitHubError` with stderr. (Do not rely on gh's exit code — it is non-zero for pending.)
- `wait_for_checks`: loop: `state = checks_state(...)`; `"pass"`/`"fail"` → return; `"none"` → return `"none"`
  only once `clock() - start >= grace_seconds` (GitHub registers checks a few seconds after the push), else keep
  polling; if `clock() - start >= timeout_minutes * 60` → return `"timeout"`; `sleep(poll_seconds)`.
- `mergeable`: `gh pr view <url> --json mergeable` → value of `mergeable` (default `"UNKNOWN"`).
- `merge_pr`: up to 5 tries: if `mergeable(...) == "CONFLICTING"` → `GitHubError("Konflikt – PR wymaga rebase")`;
  run `gh pr merge <url> --squash` (NO `--delete-branch`: it would try to switch branches in a worktree);
  success → return; on failure `sleep(5)` and retry (GitHub often reports UNKNOWN right after a push);
  after the last failure raise `GitHubError` with the stderr.
- `comment`: `gh pr comment <url> --body <body>` with check=False.

## `tests/test_github.py`
No real gh. Monkeypatch `orkiestra.github.subprocess.run` with a fake that records calls and returns
`subprocess.CompletedProcess(args, returncode, stdout, stderr)` chosen by a small rule table / queue. Inject fake
`sleep` and `clock` (a counter advancing by `poll_seconds` per sleep). Cover: missing gh → GitHubError; auth failure
message; create_pr reuses an existing PR (no `pr create` call) and parses the URL from multi-line output;
checks_state for empty list, fail, cancel, pending, pass+skipping, "no checks reported" text, unknown error;
wait_for_checks: pending→pass, early "none" waits for grace then returns "none", timeout path; merge_pr retries
after one failure, raises on CONFLICTING, never passes `--delete-branch`; comment ignores failure.
