## Tests to write
1. **Two waves, happy path**: w1 = tasks `a` (files `["src/a.txt"]`, prompt contains `FAKE_WRITE: src/a.txt`) and
   `b` (`src/b.txt`), w2 = task `c` (`src/c.txt`). Exit 0; `main` contains the 3 files (check with `git show
   main:src/a.txt` or the working tree of the repo); `status` output contains "zmergowane" 3 times; worktree dir
   has no leftovers; exactly 3 agent calls. Second `run` → exit 0 and NO new agent calls.
2. **Test command gate**: task-level `test_command` that checks the file exists
   (`'"<python>" -c "import pathlib,sys; sys.exit(0 if pathlib.Path(\'src/a.txt\').exists() else 1)"'`) → merged.
   Same task with mode `noop` via `FAKE_AGY_MODE` → exit 1, task "WYMAGA CZŁOWIEKA", exactly `max_attempts` (2) calls.
3. **Scope violation**: prompt writes `src/a.txt` AND `other/x.txt` while `files: ["src/a.txt"]` → exit 1,
   needs_human, state `last_error` mentions "spoza zakresu"; then `mark a skipped` and `run` → exit 0.
4. **Quota without waiting**: `FAKE_AGY_MODES_FILE` containing `quota\n` (then default `edit`) and `run --no-wait` →
   exit 75 and task still "czeka"; second `run` → exit 0, merged; state `attempts == 1`.
5. **Dry run**: `run --dry-run` → exit 0, zero agent calls, output contains `[dry-run]` and `--output-format`.
6. **validate**: overlapping files inside one wave → exit 1 with "wspólne pliki".
