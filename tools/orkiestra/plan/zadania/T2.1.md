# T2.1 — Plan loader and validator (Wave 2, parallel with T2.2, T2.3)

## Context
Read `orkiestra/models.py` and `orkiestra/errors.py` first (types `Plan`, `Wave`, `Task`, `PlanError`).
The plan file `waves.yaml` lists waves; tasks in one wave run in parallel, so their file patterns must not overlap.

## Files (create only these)
- `orkiestra/plan.py`
- `tests/test_plan.py`
- `examples/waves.example.yaml`

## Plan file format
```yaml
version: 1
waves:
  - id: w1
    tasks:
      - id: auth-model                 # required, regex ^[A-Za-z0-9][A-Za-z0-9._-]*$
        title: "User model"            # required, non-empty string
        files: ["src/auth/**", "tests/auth/**"]   # required, non-empty list of glob patterns
        prompt: |                      # exactly ONE of prompt / prompt_file
          ...
        prompt_file: tasks/auth.md     # path relative to the directory of waves.yaml
        model: "..."                   # optional str
        test_command: "pytest -q"      # optional str
        timeout_minutes: 30            # optional int >= 1
```

## Public API of `orkiestra/plan.py`
```python
def load_plan(path: Path) -> Plan: ...
def validate_plan(plan: Plan) -> list[str]: ...
def plan_hash(path: Path) -> str: ...
def normalize_pattern(pattern: str) -> str: ...
def literal_prefix(pattern: str) -> str: ...
def patterns_overlap(a: str, b: str) -> bool: ...
def out_of_scope(changed: list[str], patterns: tuple[str, ...]) -> list[str]: ...
```

### `load_plan(path)`
- Read with `yaml.safe_load` (UTF-8). Missing file → `PlanError(f"Brak pliku planu: {path}")`.
- Collect ALL structural problems into a list, then raise one `PlanError` whose message is the problems
  joined with `"\n"` (prefix each with location, e.g. `waves[1].tasks[0] (id=foo): ...`).
- Structural checks: top level is a mapping; `version` == 1; `waves` is a non-empty list; each wave is a
  mapping with `id` (str) and non-empty `tasks` list; each task: required keys, types, exactly one of
  `prompt`/`prompt_file`, unknown keys are errors (catch typos; allowed keys: id, title, files, prompt,
  prompt_file, model, test_command, timeout_minutes).
- `prompt_file` is read relative to `path.parent`; missing file → problem. Prompt text is `.strip()`-ed and
  must be non-empty.
- Patterns are passed through `normalize_pattern`. Absolute paths or patterns containing `..` → problem.
- Empty strings for `model` / `test_command` become `None`.
- Build frozen `Task`/`Wave`/`Plan` (tuples, not lists). Then call `validate_plan`; if it returns problems,
  raise `PlanError` with them joined by newline.

### `validate_plan(plan)` → list of problem strings (empty = valid)
- Wave ids unique; task ids unique across the WHOLE plan; ids match the regex.
- Inside each wave, for every pair of tasks, for every pair of their patterns: if `patterns_overlap` →
  problem `f"Fala {wave.id}: zadania {a.id} i {b.id} mają wspólne pliki ({pa} ~ {pb})"`.

### Helpers
- `normalize_pattern`: strip whitespace, convert `\` to `/`, strip leading `./`; a pattern ending with `/`
  gets `**` appended (`src/` → `src/**`).
- `literal_prefix`: the part of the pattern before the first of `*?[` (e.g. `src/auth/**` → `src/auth/`,
  `src/a.py` → `src/a.py`).
- `patterns_overlap(a, b)`: conservative. Let `pa, pb = literal_prefix(a), literal_prefix(b)`.
  If neither has wildcards → `a == b`. Otherwise → `pa.startswith(pb) or pb.startswith(pa)`.
  (Examples: `src/auth/**` vs `src/auth/models.py` → True; `src/a.py` vs `src/ab.py` → False;
  `src/a/**` vs `src/b/**` → False; `**/*.py` vs anything → True because prefix is empty.)
- `out_of_scope(changed, patterns)`: return the sorted list of changed paths that match NONE of the
  patterns, using `fnmatch.fnmatchcase(path, pattern)` (note: in fnmatch `*` also matches `/`, so
  `src/**` matches `src/a/b.py` — that is intended). Ignore `RESULT_FILE` from models.
- `plan_hash(path)`: `hashlib.sha256(path.read_bytes()).hexdigest()[:16]`.
