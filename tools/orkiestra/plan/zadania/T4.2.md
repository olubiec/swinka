## `orkiestra/cli.py`
`def main(argv: list[str] | None = None) -> int` with `argparse`. Global options (before the subcommand):
`--repo PATH` (default: `git rev-parse --show-toplevel` from cwd via `gitops.run_git`; fall back to cwd),
`--config PATH`, `-v/--verbose` (logging INFO→DEBUG; default level INFO with format `%(message)s`).
Subcommands (`--plan` defaults to `waves.yaml`, relative to the repo root):
- `init`: create if missing: `orkiestra.toml` (`config.DEFAULT_CONFIG_TOML`), `waves.yaml` (`WAVES_TEMPLATE`, a
  module constant: a minimal valid 1-wave 1-task plan with Polish comments), append missing lines `.orkiestra/` and
  `.orkiestra-result.json` to `.gitignore`, and `.github/workflows/orkiestra-ci.yml` from the template
  (`importlib.resources`) ONLY if `.github/workflows/` has no `*.yml`/`*.yaml` yet. Print one line per file:
  `utworzono: X` / `pominięto (istnieje): X`. Return 0.
- `validate [--plan]`: `plan.load_plan`; print `OK: <n> fal, <m> zadań` → 0; `PlanError` → print problems → 1.
- `run [--plan] [--wave ID] [--task ID] [--dry-run] [--no-wait]`: `cfg = load_config(repo, config_path)`,
  `p = load_plan(plan_path)`, `store = StateStore(state_dir(cfg))` (from `orkiestra.config`),
  `state = store.init_or_merge(p, plan_hash(plan_path))`;
  `runner = _make_runner(p, cfg, store, state, dry_run=..., wait_on_quota=not no_wait, notify=print)`;
  `outcome = runner.run(only_wave, only_task)`; print `report.format_status`; write
  `<state_dir>/summary.md`; exit code: 0 if `outcome.ok`, 75 if `outcome.stopped_on_quota`, else 1.
- `status [--plan]`: load plan + state (no changes; if no state file → all "czeka"); print report; return 0.
- `mark TASK STATUS [--plan]`: STATUS in {pending, merged, skipped, needs_human}; unknown task → error 2.
  `pending` also resets `attempts=0` and `last_error=None`. Print `<task>: <label>`. Return 0.
- `clean [--plan] [--all]`: for tasks with a `worktree` and status MERGED/SKIPPED (or every task with `--all`):
  `gitops.remove_worktree(repo_root, Path(ts.worktree), ts.branch)`; set `worktree=None`; print count. Return 0.
- `_make_runner(*args, **kwargs)`: lazy `from orkiestra.runner import WaveRunner`; return `WaveRunner(*args, **kwargs)`.
  Tests monkeypatch `cli._make_runner`.
- Error handling in `main`: `OrkiestraError` → print `Błąd: <msg>` (+ stderr attr if present) → return 2;
  `KeyboardInterrupt` → print `Przerwano – stan zapisany. Wznów: orkiestra run` → return 130.
`orkiestra/__main__.py`: `from orkiestra.cli import main` and `raise SystemExit(main())`.
