## Public API
```python
@dataclass
class RunOutcome:
    ok: bool
    stopped_on_quota: bool = False
    waves_done: list[str] = field(default_factory=list)
    needs_human: list[str] = field(default_factory=list)

AgentFn = Callable[..., AgentResult]   # same signature as agent.run_agent

class WaveRunner:
    def __init__(self, plan: Plan, config: Config, store: StateStore, state: RunState, *,
                 dry_run: bool = False, wait_on_quota: bool = True,
                 agent_fn: AgentFn | None = None,            # default: agent.run_agent (resolved at call time)
                 sleep: Callable[[float], None] = time.sleep,
                 notify: Callable[[str], None] | None = None) -> None: ...
    def run(self, only_wave: str | None = None, only_task: str | None = None) -> RunOutcome: ...
```
Import modules, not functions, so tests can monkeypatch them:
`from orkiestra import agent, gitops, github, prompts` and `from orkiestra import plan as planmod`,
`from orkiestra.config import worktree_root`. Call e.g. `github.create_pr(...)`, `gitops.fetch(...)`.
`notify` default = `logger.info`. All notify messages in Polish, short, prefixed `[<wave>/<task>]` when task-related.

## Naming
- branch: `f"orkiestra/{wave.id}/{task.id}"`
- worktree path: `worktree_root(config) / f"{wave.id}__{task.id}"`
- base: `gitops.base_ref(config.project)`

## `run(only_wave, only_task)`
1. If not dry_run: `merge_mode == "github"` → `github.ensure_ready(repo_root)`; `merge_mode == "local"` →
   require `gitops.current_branch(repo_root) == base_branch` and `gitops.is_clean(repo_root)`, else raise
   `OrkiestraError` with a Polish explanation.
2. For each wave in plan order (if `only_wave`, only that wave; unknown id → `OrkiestraError`):
   - selected tasks = wave tasks (filtered by `only_task` if given; unknown → `OrkiestraError`).
   - If every selected task is MERGED or SKIPPED → add to `waves_done`, continue.
   - `state.current_wave = wave.id`; `store.save(state)`.
   - dry_run → `self._describe(wave, tasks)`; continue (no git/gh/agent calls at all).
   - `result = self._execute_wave(wave, tasks)`; if `result == "quota"` → return
     `RunOutcome(ok=False, stopped_on_quota=True, ...)`.
   - `self._integrate_wave(wave, tasks)`.
   - If any selected task is not MERGED/SKIPPED: collect NEEDS_HUMAN ids; if `config.run.stop_on_failure` → return
     `RunOutcome(ok=False, needs_human=[...], waves_done=...)`; else continue to the next wave.
   - else append wave id to `waves_done`.
3. Return `RunOutcome(ok=not needs_human, ...)`.

## `_execute_wave(wave, tasks) -> "ok" | "quota"`
- github mode: `gitops.fetch(repo_root, remote)` once before starting.
- Loop (max 10 quota pauses):
  - `todo` = tasks with status PENDING (RUNNING counts as PENDING). Empty → return "ok".
  - Reset a `threading.Event` `self._quota_event` and `self._quota_reset: int | None = None`.
  - Run `self._run_task(wave, t)` for `todo` in `ThreadPoolExecutor(max_workers=config.run.max_parallel)`;
    wait for all; re-raise unexpected exceptions? NO — wrap each call: any exception → task NEEDS_HUMAN with
    `last_error = f"{type(e).__name__}: {e}"` (+ `e.stderr[-1500:]` if present), notify, continue.
  - If quota event set and some tasks are still PENDING:
    - `not wait_on_quota` → return "quota".
    - `seconds = (self._quota_reset or config.run.quota_wait_minutes * 60) + 60`; set
      `state.quota_paused_until` (UTC ISO) and save; notify `f"Limit Antigravity wyczerpany – czekam {seconds//60} min"`;
      `self.sleep(seconds)`; clear `quota_paused_until`; save; continue loop.
  - else return "ok".
- After 10 pauses → return "quota".

## `_run_task(wave, task)` (runs in a worker thread)
1. If `self._quota_event.is_set()` → return (task stays PENDING).
2. `ts = state.tasks[task.id]`; `store.update(state, task.id, status=RUNNING, branch=..., worktree=str(path))`;
   `gitops.create_worktree(repo_root, path, branch, base)`.
3. `feedback = ts.last_error if ts.attempts > 0 else None` (resume continues with the last problem).
4. While `ts.attempts < config.run.max_attempts`:
   a. If quota event set → `update(status=PENDING)`; return.
   b. `attempt = ts.attempts + 1`; `update(attempts=attempt)`; notify `próba {attempt}`.
   c. `prompt = prompts.build_prompt(task, wave, config, feedback)`.
   d. `res = agent_fn(prompt, path, config.agent, model=task.model or config.agent.model,
      timeout_minutes=task.timeout_minutes or config.agent.timeout_minutes, log_path=store.log_path(task.id, attempt))`.
   e. `res.quota_exhausted` → `self._quota_reset = res.quota_reset_seconds` (keep the max), set the event,
      `update(status=PENDING, attempts=attempt - 1, last_error=None)` (a quota hit does not burn an attempt); return.
   f. `problem, blocked, note = self._check(task, path, res)`.
   g. `blocked` → `update(status=NEEDS_HUMAN, last_error=f"Agent zgłosił blokadę: {note}")`; notify; return.
   h. `problem is None` → `gitops.commit_all(path, f"{task.id}: {task.title}")`;
      `update(status=VERIFIED, last_error=None, note=note)`; notify `gotowe`; return.
   i. else `feedback = problem`; `update(last_error=problem)`; notify the first line of problem.
5. Attempts exhausted → `update(status=NEEDS_HUMAN)`; notify.

## `_check(task, path, res) -> tuple[str | None, bool, str | None]`  (problem, blocked, note)
- Read `path / RESULT_FILE` if it exists (json; invalid json → ignore), take `status` and `note`; then delete the file.
- `status == "blocked"` → `(None, True, note)`.
- `changed = gitops.changed_files(path, base)`.
- No changes → problem: if `not res.ok` → `f"Błąd agenta: {res.error or res.response[:300] or 'brak odpowiedzi'}"`
  (+ `" (timeout)"` if `res.timed_out`) else `"Agent nie wprowadził żadnych zmian."`.
- `out = planmod.out_of_scope(changed, task.files)` non-empty → problem:
  `f"Zmieniono pliki spoza zakresu: {', '.join(out)}. Cofnij te zmiany; wolno zmieniać tylko: {', '.join(task.files)}."`
- Tests: `cmd = prompts.effective_test_command(task, config)`; if cmd → `subprocess.run(cmd, shell=True, cwd=path,
  capture_output=True, text=True, timeout=900)`; non-zero (or TimeoutExpired) → problem
  `f"Testy nie przechodzą (`{cmd}`):\n" + prompts.truncate_tail(stdout + stderr, 3000)`.
- Otherwise `(None, False, note)`.

## `_integrate_wave(wave, tasks)` — sequential, plan order, only tasks with status VERIFIED or PR_OPEN
For each such task, inside `try` (catch `GitError`, `GitHubError` → NEEDS_HUMAN with message + stderr tail):
- **local mode**: `gitops.rebase_onto(path, base_branch)` False → NEEDS_HUMAN "Konflikt przy rebase";
  `gitops.merge_local(repo_root, branch, base_branch)`; → MERGED.
- **github mode**:
  1. `gitops.fetch(repo_root, remote)`; `gitops.rebase_onto(path, f"{remote}/{base_branch}")` False → NEEDS_HUMAN.
  2. `gitops.push_branch(path, remote, branch)`.
  3. `url = ts.pr_url or github.create_pr(repo_root, branch, base_branch, title=f"[{wave.id}] {task.id}: {task.title}",
     body=...)`; `update(status=PR_OPEN, pr_url=url)`. Body (Polish): task id, wave, title, agent note,
     `"_Utworzone automatycznie przez orkiestra._"`.
  4. `r = github.wait_for_checks(url, repo_root, config.run.ci_timeout_minutes, sleep=self.sleep)`.
     `"pass"`/`"none"` → `github.merge_pr(url, repo_root, sleep=self.sleep)`;
     `gitops.delete_remote_branch(repo_root, remote, branch)`; → MERGED.
     `"fail"`/`"timeout"` → `github.comment(url, repo_root, f"orkiestra: CI = {r}. Zadanie wymaga człowieka.")`;
     NEEDS_HUMAN with `last_error=f"CI: {r}"`.
- On MERGED: `update(status=MERGED, last_error=None)`; `gitops.remove_worktree(repo_root, path, branch)`; notify `zmergowane`.

## `_describe(wave, tasks)` (dry run)
For each task notify: `f"[dry-run] {wave.id}/{task.id}: prompt {len(prompt)} znaków, pliki: {...}"` and the agy
command from `agent.build_agy_args(config.agent, "<prompt>", path, model=..., timeout_minutes=...)` joined with
spaces. Build the prompt with `prompts.build_prompt`. No side effects (do not create worktrees).

## `tests/test_runner.py`
Use REAL git in **local mode** (`git_repo` fixture; write `Config(repo_root=repo, project=ProjectConfig(
merge_mode="local", test_command=None), run=RunConfig(worktree_dir=str(tmp_path / "wt"), max_parallel=2))`),
`StateStore(tmp_path / "state")`, `state = store.init_or_merge(plan, "h")`, a recording fake `sleep`, and a fake
`agent_fn` (plain Python function writing files into the worktree `path` argument and returning `AgentResult`).
Build `Plan` objects directly. Cover:
1. Happy path: 2 waves (2 parallel tasks + 1) → all MERGED, files present on `main` of the repo, worktrees removed,
   outcome ok, `waves_done == ["w1", "w2"]`.
2. Scope violation on attempt 1 (writes an extra file), fixed on attempt 2 (fake reverts it — the prompt received on
   attempt 2 must contain "spoza zakresu") → MERGED, attempts == 2.
3. Failing `test_command` (`f'"{sys.executable}" -c "import sys; sys.exit(1)"'`) → NEEDS_HUMAN after max_attempts,
   outcome not ok, next wave NOT started when `stop_on_failure`.
4. No changes → problem "nie wprowadził"; blocked result file → NEEDS_HUMAN immediately (1 attempt).
5. Quota: first call returns `quota_exhausted=True, quota_reset_seconds=30`, later calls succeed → sleep called once
   with 90, task MERGED, attempts == 1. With `wait_on_quota=False` → `stopped_on_quota=True`, task PENDING.
6. Resume: run again on a finished state → no agent calls, outcome ok.
7. Dry run → no agent calls, no worktree dir created, notify received `[dry-run]` lines.
8. github mode with monkeypatched `runner.github` functions (`ensure_ready`, `create_pr`, `wait_for_checks`,
   `merge_pr`, `comment`) and `runner.gitops.fetch` / `push_branch` / `delete_remote_branch` / `rebase_onto` stubs,
   using `git_repo` (no remote): "pass" → MERGED with pr_url stored; "fail" → NEEDS_HUMAN and comment called.
9. An exception inside `agent_fn` → that task NEEDS_HUMAN, the other task in the wave still MERGED.
