# R48: Taniec do muzyki w Home (Dance Sync)

## 1. Jak gra muzyka i skąd BPM

1. **Dwa odtwarzacze w Home, jeden aktywny:**
   - Główny odtwarzacz tła i minigier to `window.CuyMusic` (`web/home/music.js:172-264`). Tworzy element `<audio>` przez `new Audio(ASSET_PREFIX + track.file)` (`web/home/music.js:152`), gdzie `ASSET_PREFIX` to `'https://cuy.assets/'` w WebView2 lub `'../../assets/'` w przeglądarce (`web/home/music.js:12`).
   - Publiczne API `window.CuyMusic` udostępnia m.in. `isPlaying()` (`web/home/music.js:179-181`), `getCurrentAudio()` / `currentAudio` (`web/home/music.js:173-178`), `isEnabled()` (`web/home/music.js:258-260`), `getVolume()` (`web/home/music.js:231-233`) oraz `tracks()` (`web/home/music.js:261-263`).
   - Prywatna zmienna `currentId` (`web/home/music.js:17`) nie jest eksponowana w API `CuyMusic`, ale `currentAudio.src` zawiera nazwę pliku z `tracks.json` (np. `music/calm_loop.ogg`), co pozwala rozpoznać utwór bez modyfikowania `web/home/music.js`.
   - Drugi system to moduł gramofonu `CuyMusicEngine` (`web/home/features/music/engine.js:1-293`) i `CuyMusicPlayer` (`web/home/features/music/player.js:1-305`), jednak panel gramofonu jest obecnie wyłączony (`autoMount()` i `autoEngine()` zwracają `null` w `web/home/features/music/player.js:254-260`).
2. **Brak BPM w obecnych danych:**
   - `assets/music/tracks.json:1-7` zawiera 5 utworów (`games_1`, `games_2`, `games_boss`, `menu`, `calm`) z polami `id`, `file`, `title`, `author`, `license`, `url`, `use` — żaden wpis nie ma pola `bpm`.
3. **Dlaczego nie `AnalyserNode` (Web Audio API):**
   - `web/home/music.js:152` tworzy `new Audio(...)` bez ustawienia `audio.crossOrigin = 'anonymous'`. W WebView2 `ASSET_PREFIX` (`https://cuy.assets/`) ma inny origin niż strona Home, więc `audioCtx.createMediaElementSource(audio)` bez nagłówków CORS zwracałoby w `AnalyserNode` same zera i mogłoby wyciszyć odtwarzanie.
   - Ponadto `createMediaElementSource` przejmuje wyjście elementu `<audio>` (ryzyko ciszy przy zawieszonym `AudioContext`) i rzuca `InvalidStateError` przy ponownym podpięciu, podczas gdy `stopCurrent` czyści `a.src = ''` (`web/home/music.js:91`) i tworzy nowy `Audio` dla każdego utworu (`web/home/music.js:152`).
   - W testach headless (Playwright) brak urządzenia audio lub blokada autoplay również dają zera na `AnalyserNode`.
   - **Decyzja:** detekcja uderzeń działa deterministycznie przez zegar `beatClock` i tabelę BPM (`assets/data/music_bpm.json`), bez `AnalyserNode` i bez zmian w `web/home/music.js`.

## 2. Kontrakt `dance-sync.js` i zasady tańca

Moduł UMD `web/home/lib/dance-sync.js` (wzorzec jak `web/home/lib/pig-behavior.js:1-4,618-622`): w Node eksportuje `module.exports`, w przeglądarce ustawia `window.DanceSync`.

### Część czysta (rdzeń, zero DOM / `window` / I/O)

Stałe domyślne:
- `DEFAULT_BPM = 120`
- `FRAMES_PER_BEAT = 4`
- `MIN_FPS = 4`
- `MAX_FPS = 16`
- `MAX_DANCE_MS = 30000`

Funkcje i obiekty:
- `beatClock(opts)` — przyjmuje `{ bpm, startMs, offsetMs }` (`bpm > 0`, domyślnie `120`; `startMs` domyślnie `0`; `offsetMs` domyślnie `0`). Zwraca obiekt zegara:
  - `phase(nowMs)`: znormalizowana faza w bieżącym uderzeniu w przedziale `[0, 1)`, liczona jako `(((elapsed % beatMs) + beatMs) % beatMs) / beatMs`, gdzie `elapsed = nowMs - startMs - offsetMs` i `beatMs = 60000 / bpm`.
  - `beatIndex(nowMs)`: `Math.floor(elapsed / beatMs)` (liczba całkowita).
  - `onBeat(cb)`: rejestruje `cb(beatIndex, nowMs)` i zwraca funkcję `unsubscribe()`.
  - `update(nowMs)`: jeśli `beatIndex(nowMs) > lastBeat`, aktualizuje `lastBeat`, wywołuje wszystkie callbacki `onBeat` dokładnie raz dla nowego uderzenia (bez nadrabiania zaległych po długiej pauzie) i zwraca `true`; w przeciwnym razie `false`.
  - `bpm()`: zwraca aktywne BPM.
  - `beatMs()`: zwraca `60000 / bpm`.
- `fpsForBpm(bpm, framesPerBeat)` — zwraca `Math.max(MIN_FPS, Math.min(MAX_FPS, Math.round((b / 60) * fpb)))` (dla `120` BPM i `4` klatek/beat daje `8`, czyli dokładnie `ANIM_DEFS.dance.fps` z `web/home/canvas-pig.js:230`).
- `resolveTrackBpm(trackIdOrSrc, bpmTable)` — szuka po kluczu `bpmTable.tracks[id]`, a jeśli nie trafi, dopasowuje sufiks/nazwę pliku z `entry.file` przeciw `trackIdOrSrc` (np. `calm_loop.ogg` -> `calm`). Zwraca `{ id, bpm, offsetMs }` z fallbackiem na `bpmTable.defaultBpm || DEFAULT_BPM` oraz `offsetMs: 0`.
- `shouldStartDance(ctx)` — przyjmuje `{ musicPlaying, muted, mood, energy, sleeping, sick, dragging, modalOpen }`. Zwraca `true` wyłącznie gdy:
  - `ctx.musicPlaying === true` i `!ctx.muted`,
  - `!ctx.sleeping && !ctx.sick && !ctx.dragging && !ctx.modalOpen`,
  - `mood >= 85` i `energy >= 40` (progi spójne z `assets/data/actions.json:448-451`; brak pola w `needs` przyjmuje domyślnie `50`, więc bez wysokiego humoru nie startuje).
- `shouldStopDance(ctx, elapsedMs)` — zwraca `{ stop: boolean, reason: string | null }`:
  - `{ stop: true, reason: 'music_stopped' }` gdy `!ctx.musicPlaying || ctx.muted`,
  - `{ stop: true, reason: 'time_limit' }` gdy `elapsedMs >= (ctx.maxDanceMs || MAX_DANCE_MS)`,
  - `{ stop: true, reason: 'sleeping' }` gdy `ctx.sleeping`,
  - `{ stop: true, reason: 'sick' }` gdy `ctx.sick`,
  - `{ stop: true, reason: 'low_mood' }` gdy `typeof ctx.mood === 'number' && ctx.mood < 75` (histereza 10 pkt względem progu startu `85`),
  - `{ stop: true, reason: 'low_energy' }` gdy `typeof ctx.energy === 'number' && ctx.energy < 30` (histereza 10 pkt względem `40`),
  - w pozostałych przypadkach `{ stop: false, reason: null }`.

### Część przeglądarkowa (za strażnikiem `typeof window !== 'undefined'`)

- `createBrowserSync(opts)` — łączy `window.CuyMusic` (`web/home/music.js:172`) i `window.Sound`:
  - `setBpmTable(data)` / `loadBpmTable(url)`: zapisuje lub pobiera `music_bpm.json` przez `fetch`.
  - `isMusicAudible()`: `true` gdy `CuyMusic.isPlaying()`, `CuyMusic.isEnabled()`, `CuyMusic.getVolume() > 0` oraz `!(window.Sound && window.Sound.isMuted)`.
  - `currentTrackKey()`: zwraca `CuyMusic.getCurrentAudio().src` (lub `null`).
  - `sync(nowMs)`: wykrywa zmianę utworu (tworzy nowy `beatClock` z `startMs: nowMs` i `bpm` z `resolveTrackBpm`), wywołuje `clock.update(nowMs)` i zwraca `{ audible, trackId, bpm, fps, phase, beatChanged }`.

### Zasady integracji z `PigBehavior` i animacją `dance`

- `PigBehavior` (`web/home/lib/pig-behavior.js:411-413`) już premiuje akcję `dancing` mnożnikiem `1.5`, gdy `ctx.musicPlaying === true`, a `canvas-pig.js:3407` przekazuje `musicPlaying`.
- Ponieważ `home_behavior.json:298-299` ustawia krótki czas `3500-5000` ms, zsynchronizowany taniec do muzyki w `canvas-pig.js` ustawia `this._danceSynced = true` i `animTimer = MAX_DANCE_MS` (`30000` ms).
- `defFor('dance')` (`web/home/canvas-pig.js:4664-4670`) dla aktywnego `_danceSynced` podstawia `fps` z `DanceSync.fpsForBpm(bpm)` (z zachowaniem spowolnienia `0.8` dla `senior`/`legend` z `SLOW_ANIMS` w `web/home/canvas-pig.js:271`).
- W `update(dt)` (`web/home/canvas-pig.js:4128-4135`) `shouldStopDance` kończy zsynchronizowany taniec natychmiast po zatrzymaniu/wyciszeniu muzyki, przekroczeniu 30 s lub spadku potrzeb, ustawiając cooldown (np. 10 s) przed kolejnym autostartem.

## 3. Dane BPM i zachowanie bez muzyki

1. **Nowy plik `assets/data/music_bpm.json` (własność `PK-DN1`):**
   - Nie edytujemy `assets/music/tracks.json` (unikamy kolizji z innymi modułami).
   - Format pliku:
     ```json
     {
       "version": 1,
       "defaultBpm": 120,
       "framesPerBeat": 4,
       "maxDanceMs": 30000,
       "tracks": {
         "games_1": { "file": "music/adventure_stage1.ogg", "bpm": 132, "offsetMs": 0 },
         "games_2": { "file": "music/adventure_stage2.ogg", "bpm": 138, "offsetMs": 0 },
         "games_boss": { "file": "music/adventure_boss.ogg", "bpm": 150, "offsetMs": 0 },
         "menu": { "file": "music/adventure_select.ogg", "bpm": 116, "offsetMs": 0 },
         "calm": { "file": "music/calm_loop.ogg", "bpm": 96, "offsetMs": 0 }
       }
     }
     ```
   - Wartości `bpm` powyżej są wartościami startowymi (`UNVERIFIED` względem rzeczywistej analizy audio `.ogg`) do późniejszego dostrojenia w JSON.
2. **Zachowanie bez muzyki (`!CuyMusic.isPlaying()`):**
   - `shouldStartDance` zwraca `false` — zsynchronizowany taniec nie startuje.
   - Zwykła, krótka animacja `dance` wywołana poza muzyką (np. sztuczka z `canvas-pig.js:3426` lub decyzja `PigBehavior` przy `mood >= 85` i `energy >= 40` bez bonusu `1.5x`) ma `_danceSynced = false` i odtwarza się z domyślnym `ANIM_DEFS.dance.fps = 8` (`canvas-pig.js:230`) przez swój krótki czas (`3.5-5` s z `home_behavior.json:298-299`).
   - Jeśli muzyka grała i została zatrzymana (`stop()`, `pause()`, koniec utworu), `shouldStopDance` zwraca `{ stop: true, reason: 'music_stopped' }`, kończąc `_danceSynced` powrotem do `idle`.
3. **Zachowanie przy wyciszeniu (`Sound.isMuted`, `CuyMusic.isEnabled() === false`, `volume === 0`):**
   - `isMusicAudible()` zwraca `false`. W `_buildBehaviorCtx()` (`canvas-pig.js:3407`) `musicPlaying` przyjmuje `false`, więc świnka nie zaczyna tańczyć do wyciszonego dźwięku, a trwający taniec zsynchronizowany kończy się z powodem `'music_stopped'`.

## 5. Przypadki dla PK-T24

1. **Zegar uderzeń (`beatClock`):** dla `bpm: 120`, `startMs: 0` sprawdza `beatMs() === 500`, `phase(0) === 0`, `phase(250) === 0.5`, `phase(500) === 0`, `beatIndex(999) === 1`, `beatIndex(1000) === 2`.
2. **Callback `onBeat`:** wywołania `update(0)`, `update(250)`, `update(500)`, `update(510)`, `update(1000)` odpalają `onBeat` dokładnie dla indeksów `1` (przy 500) i `2` (przy 1000), a `unsubscribe()` zatrzymuje dalsze wywołania.
3. **Przeliczanie FPS (`fpsForBpm`):** `96 BPM -> 6 fps`, `120 BPM -> 8 fps`, `150 BPM -> 10 fps`, wartości skrajne klamrowane do `[4, 16]`.
4. **Dopasowanie utworu (`resolveTrackBpm`):** `'calm'` -> `96`, `'https://cuy.assets/music/adventure_boss.ogg'` -> `150`, `'unknown_track'` -> `120` (`defaultBpm`).
5. **Warunki startu/stopu (`shouldStartDance`, `shouldStopDance`):**
   - Start `true` tylko przy `musicPlaying: true, muted: false, mood: 90, energy: 50, sleeping: false, sick: false`.
   - Start `false` przy `muted: true`, `mood: 84`, `energy: 39`, `sleeping: true` lub `sick: true`.
   - Stop zwraca `'music_stopped'` przy `musicPlaying: false` lub `muted: true`, `'time_limit'` przy `elapsedMs >= 30000`, `'low_mood'` przy `mood < 75`, `'low_energy'` przy `energy < 30`.
6. **Playwright Home:** po ustawieniu wysokiego `mood`/`energy` w stanie mock i włączeniu muzyki (`CuyMusic.play('calm')`), `PigCanvas` wchodzi w animację `'dance'` z `fps` zsynchronizowanym do BPM; po `CuyMusic.stop()` lub wyciszeniu wraca do `'idle'`.
