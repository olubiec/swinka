## 2. Model wybiegu w zjednoczonym świecie

- **Siatka i scena**: `assets/data/places.json:69-87` definiuje `garden` (`16x9` lvl 1 koszt 400, `20x10` lvl 2 koszt 470). `assets/data/place_scenes.json:22-42` ma rozmiar `256x144` (komórka `16x16` px dla `16x9`) i `walk: [8, 80, 248, 138]`.
- **Płoty i bramka**: `assets/data/world_items.json:199-223,680-692` zawiera elementy `garden` (`layer: "floor"`, `1x1`): `fence_wood` (15), `hedge` (30, comfort 1), `gate_garden` (40, comfort 1). `home_economy.json:22-30` już definiuje `min_cells: 12`, `cells_per_pig: 6`, `gate_item: "gate_garden"`, `blockers: ["fence_wood", "hedge", "gate_garden"]`.
- **Kolizje na płótnie**: `places/scenes.js:513-567` (`buildInstanceBlockers`) buduje `blockerRects` z `layout.items`, a `canvas-pig.js:695-717` (`isFree`) i `findPath` (`canvas-pig.js:838`) omijają płoty automatycznie.
- **Minimalny model**:
  - Wybieg to największa spójna (4-sąsiednia) grupa wolnych pól wewnątrz siatki ogrodu nie dotykająca krawędzi (`x==0 || x==cols-1 || y==0 || y==rows-1`), mająca `>= min_cells` (12) pól i co najmniej jeden `gate_garden` sąsiadujący bokiem; pojemność `max(1, floor(cells / cells_per_pig))`.
  - Wejście wyłącznie w scenie ogrodu (`CuyPlaces.getCurrentPlace() === 'garden'`, `places/feature.js:1600`), bez nowego okna.
  - Nakładka pól na płótnie przez `window.CuyRoom.addLayer('run_overlay', 6, ...)` (`canvas-pig.js:470-476`); główna świnka w ogrodzie może odtwarzać `run` (`ANIM_DEFS`, `canvas-pig.js:217`). Bez nowej ekonomii.

### `src/Cuy.Core/World/RunCheck.cs` (namespace `Cuy.Core.World`)
```csharp
public sealed class RunConfig
{
    public static RunConfig Current { get; } // lazy LoadDefault(), wzorzec HomeEconomyConfig
    public int MinCells { get; set; } = 12;

    public IReadOnlyList<string> Blockers { get; set; } = new[] { "fence_wood", "hedge", "gate_garden" };
    public int MaxHoursPerDay { get; set; } = 6;
    public int DayFromHour { get; set; } = 8;
    public int DayToHour { get; set; } = 19;
    public int MinTempC { get; set; } = 10;

    public double MoodPerHour { get; set; } = 1.0;
    public int MoodCapPerDay { get; set; } = 6;

    public static RunConfig CreateDefault();
    public static RunConfig Load(string json);
    public static RunConfig LoadDefault();
}

public sealed class RunInfo
{
    public bool Valid { get; set; }
    public int Cells { get; set; }
    public int Capacity { get; set; }
    public bool HasGate { get; set; }
    public string Reason { get; set; } // "ok" | "no_fence" | "too_small" | "no_gate" | "open_edge"
    public IReadOnlyList<(int x, int y)> CellList { get; set; }

public static class RunCheck
{
    public static RunInfo Analyze(RoomLayout garden, int cols, int rows, WorldItemCatalog items = null, RunConfig cfg = null);
    public static bool IsFenced(RoomLayout garden, int cols = 16, int rows = 9, WorldItemCatalog items = null, RunConfig cfg = null);
    public static int Capacity(RoomLayout garden, int cols = 16, int rows = 9, WorldItemCatalog items = null, RunConfig cfg = null);
}
```
Reguły `Analyze`:
1. Brak `garden`/`Items` lub brak żadnego blokera z `cfg.Blockers` -> `Valid = false, Reason = "no_fence", Cells = 0, Capacity = 0, CellList = Array.Empty<(int,int)>()`.
2. Komórki `EffectiveFootW x EffectiveFootH` blokerów z `cfg.Blockers` są zablokowane.
3. Flood fill 4-sąsiedni po wolnych komórkach: składowa dotykająca krawędzi (`x==0 || x==cols-1 || y==0 || y==rows-1`) jest otwarta; brak zamkniętej składowej -> `Reason = "open_edge"`.
4. Największa zamknięta składowa (remis: mniejsze `(y, x)`) z `< cfg.MinCells` -> `Reason = "too_small", Cells = count`.
5. Brak postawionego `cfg.GateItem` sąsiadującego bokiem ze składową -> `HasGate = false, Reason = "no_gate", Cells = count`.
6. Poprawny wybieg -> `Valid = true, HasGate = true, Reason = "ok", Cells = count, Capacity = Math.Max(1, count / Math.Max(1, cfg.CellsPerPig))`, `CellList` posortowana po `(y, x)`.

### `src/Cuy.Core/World/RunRules.cs` (namespace `Cuy.Core.World`)
```csharp
public enum RunVerdict { Ok, TooEarly, TooLate, TooWet, TooCold, TooHot, Dark }

public static class RunRules
{
    public static RunVerdict CanBeOut(DateTime localNow, WeatherInfo weatherOrNull, RunConfig cfg = null);
    public static string Message(RunVerdict verdict);
    public static double MoodFor(double hoursOut, double alreadyCreditedToday, RunConfig cfg = null);
    public static double CreditableHours(DateTime outSinceUtc, DateTime untilUtc, DateTime localDayStart, TimeSpan utcOffset, RunConfig cfg = null);
    public static double CreditableHours(DateTime outSinceLocal, DateTime untilLocal, RunConfig cfg = null);
}
```
- `CanBeOut`: gdy `weatherOrNull != null`: `!IsDay` -> `Dark`; `IsWet` lub `Condition` spoza `AllowedConditions` -> `TooWet`; `TemperatureC < MinTempC` -> `TooCold`; `TemperatureC > MaxTempC` -> `TooHot`. Zawsze: `localNow.Hour < DayFromHour` -> `TooEarly`; `localNow.Hour >= DayToHour` -> `TooLate`.
- `Message`: niepusty ciąg EN bez polskich znaków (`Ok`: `"Ready for the garden run"`, `TooWet`: `"It is a bit wet outside today"`, `TooEarly`: `"Too early for the garden run"`, `TooLate`: `"Evening is coming, time to rest inside"`, `TooCold`: `"It is too chilly outside today"`, `TooHot`: `"It is too warm outside today"`, `Dark`: `"It is dark outside"`).
- `MoodFor`: `Math.Min(Math.Max(0, cfg.MoodCapPerDay - alreadyCreditedToday), Math.Max(0, hoursOut) * cfg.MoodPerHour)`.
