### `src/Cuy.Core/World/DesktopPropOps.cs` (namespace `Cuy.Core.World`)
```csharp
public sealed class DesktopProp
{
    public string Uid { get; set; } = string.Empty;
    public string ItemId { get; set; } = string.Empty;
    public double X { get; set; }
    public double Y { get; set; }
    public void Clamp(); // NaN/Inf -> 0.5; inaczej [0.0, 1.0]
}

public enum DesktopPropResult { Ok, Disabled, UnknownItem, NotOwned, Full, NotFound, RoomRefused, Stored }

public static class DesktopPropOps
{
    public static int OwnedCount(WorldState world, GameState gameState, string itemId, DesktopPropCatalog catalog);
    public static int PlacedInRoomsCount(WorldState world, string roomItemId);
    public static int OnDesktopCount(IList<DesktopProp> desktop, string itemId);
    public static int FreeCount(IList<DesktopProp> desktop, WorldState world, GameState gameState, string itemId, DesktopPropCatalog catalog);
    public static DesktopPropResult PutOnDesktop(IList<DesktopProp> desktop, WorldState world, GameState gameState, string itemId, double x, double y, DesktopPropCatalog catalog, out DesktopProp added);
    public static DesktopPropResult MoveOnDesktop(IList<DesktopProp> desktop, string uid, double x, double y);
    public static DesktopPropResult RemoveFromDesktop(IList<DesktopProp> desktop, string uid);
    public static DesktopPropResult ToRoom(IList<DesktopProp> desktop, WorldState world, GameState gameState, string uid, string roomId, int cellX, int cellY, int cols, int rows, int wallRows, WorldItemCatalog items, DesktopPropCatalog catalog);
    public static DesktopPropResult FromRoom(IList<DesktopProp> desktop, WorldState world, string roomId, string placedUid, double x, double y, DesktopPropCatalog catalog);
}
```
Reguły: nieznany ID -> `UnknownItem`; `FreeCount == 0` -> `NotOwned`; `desktop.Count >= MaxOnDesktop` -> `Full`. Zawsze `OnDesktopCount + PlacedInRoomsCount + FreeCount == OwnedCount`. `ToRoom` przy odmowie `RoomLayoutOps.Place` przywraca wpis na pulpit (`RoomRefused`); `FromRoom` przy pełnym pulpicie zwraca `Stored`.

- `props.move` `{ uid: string, x: number, y: number }` (`uid` 1..64 zn., `x,y` w `[0,1]`)
- `props.remove` `{ uid: string }` (`uid` 1..64 zn.)

- `props.fromRoom` `{ room: string, uid: string, x: number, y: number }` (`room,uid` 1..64 zn., `x,y` w `[0,1]`)

Toasty: `"The desktop is full"`, `"Something is in the way"`, `"Put back on your desktop"`, `"Item is not owned"`.
