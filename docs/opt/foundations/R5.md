## 3. Risks: P5-04 (Second Pig Window on Desktop)

`PLAN_POPRAWEK_UX.md:319` flagged this risk: `BrainController` only supports one pig today.

### Cost and Conflict Analysis in `BrainController`:
1. **Single Simulation & AI Instance:**
   - `src/Cuy.Core/GameSession.cs:29`: `public Pet Pet { get; }` manages needs for exactly one pig. There is no second `Pet` in Core.
   - `src/Cuy/dotNet/BrainController.cs:103`: `_brain = new Brain(_session.Pet);` is a single Utility AI instance.
2. **Sequence Callback Clashing:**
   - `src/Cuy/dotNet/FormPet.cs:1466`: When animation ends, `FormPet` calls `_brain.OnAnimationSequenceFinished(CurrentAnimation.Name)`.
   - `src/Cuy/dotNet/BrainController.cs:789-880`: Reads and overwrites single fields `_brain.CurrentAction`, `_subStage` ("entrance", "main", "exit"), and `_isWakingUp`.
   - If two windows run concurrently, Pet 2 clobbers Pet 1's action state on every animation end, causing broken transitions and erratic jumps.
3. **Subsystems Bound to `FormPet.ActivePet`:**
   - `FoodManager.cs:78, 214, 316`, `InteractionManager.cs:36`, `PoopManager.cs:123`, `StatusBubble.cs:53`, and `BrainController.cs:561-576` (`BehaviorContext`) all reference single `FormPet.ActivePet`. Only one pet feeds or reacts to cursors.

### Options for the Owner:
- **Option A (Minimal Ambient Companion — Recommended if 2nd window is required):**
  - Pet 2 is an ambient visual companion. It does NOT route through `BrainController.OnAnimationSequenceFinished` or `_brain`.
  - Instead, Pet 2 runs an autonomous wander/idle loop in `FormPet` cycling random animations (`idle`, `walk`, `sniff`, `popcorn`).
  - Physics/dragging remain independent per window (`FormPet.Motion.cs`). Feeding remains on `ActivePet`. Low cost (~1 day), 0 risk to Core AI.
- **Option B (Resignation from 2nd Desktop Window — Lowest Risk):**
  - Keep exactly 1 pig on the desktop. In `pigs/feature.js`, provide an active desktop pig selector ("Set as desktop pet").
  - Multi-pig cohabitation remains strictly in Home scenes/rooms. Zero desktop risk.
