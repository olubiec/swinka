## 3. Technika pikselowa i zrzuty

Źródła: `tools/qa/ux-p39-light.js`, `ux-p45-room-draw.js`, `ux-p45-overlay-pig.js`, `screen-matrix.js`, `canvas-pig.js`.
- **Odczyt płótna**: `const c = document.getElementById('pigCanvas'); const d = c.getContext('2d').getImageData(0, 0, c.width, c.height).data;` (`ux-p39-light.js:120-128`) lub `canvas.toDataURL('image/png')` (`scene-overlay.js:239`). Wymaga serwera z `ux.startServer()` (bez CORS w WebView2 canvas jest tainted, `paths-test.js:25`).
- **Współrzędne i prostokąty**:
  - `CanvasPig.toClient(x, y)` -> `{ clientX, clientY }` (`canvas-pig.js:1424, 3110`); `CanvasPig.toScene(e)` -> `{ x, y }` (`canvas-pig.js:1404, 3115`).

  - Luminancja: `0.299 * r + 0.587 * g + 0.114 * b` (`ux-p39-light.js:126`). Tolerancja koloru: `Math.abs(r - R) <= 2 && ... && a > 0` (`ux-p45-overlay-pig.js:58-65`).

- **Determinizm**: stały `window.__cuyNow` przed `goto`, `setExitsEnabled(false)` (`ux-p34-pig-walk.js:31`), jawne `CanvasPig.pigX`/`pigY` (`ux-p44-shots.js:66-67`), LCG seed (`perf-soak.js:79-80`).

## 5. Wydajność: co i jak mierzyć

Źródła: `tools/qa/perf-soak.js`, `tools/qa/soak.js`, `tools/qa/music-world-test.js`.
- **Start Chromium**: `args: ['--no-sandbox', '--enable-precise-memory-info']` (`perf-soak.js:46`) + `const cdp = await ctx.newCDPSession(page)` (`perf-soak.js:50`).
- **Metryki**:
  - Pamięć: `await cdp.send('HeapProfiler.collectGarbage')` + `performance.memory.usedJSHeapSize` (`perf-soak.js:68, 72`).
  - DOM i nasłuchiwacze: `cdp.send('Memory.getDOMCounters')` -> `nodes`, `jsEventListeners` (`perf-soak.js:69, 73`); szczegóły przez `DOMDebugger.getEventListeners` (`perf-soak.js:103`).
  - Wrapper `addEventListener` w `context.addInitScript`: zliczaj aktywne `(target, type, fn)` przy `addEventListener`/`removeEventListener` (wzorzec `RAF_INIT` w `perf-soak.js:21-31`).
  - Oczekujące rAF: `RAF_INIT` -> `window.__rafPending()` (`perf-soak.js:30`).
  - Wywołania `drawImage`: owiń `CanvasRenderingContext2D.prototype.drawImage` licznikiem na N klatek (wzorzec `music-world-test.js:89`).
  - Czas klatki: pętla `requestAnimationFrame` + `performance.now()` (mediana/p95 z 60 klatek po rozgrzewce).
- **Progi względne i stabilność**: stosunek do sceny bazowej (`salon`, 1 świnka, dzień) w tej samej sesji zamiast sztywnych ms. Odrzuć pierwsze 25% próbek (warm-up) i porównuj minimum (floor) po GC z 2. połowy vs 1. połowa (`nodes`/`listeners` +5% lub +25, `raf` +3, `perf-soak.js:14-17, 122-135`).
