## 2. Kontrakt `play-targets.js`

Plik: `web/home/lib/play-targets.js` (UMD: `module.exports = api` / `window.CuyPlayTargets = api`, czyste funkcje, bez DOM).

- **`kindOf(thing)`**: zwraca `'tunnel'` dla `id`/`itemId` w `['tunnel','prop_tunnel','willow_tunnel','tunnel_playground']` (lub zawierających `'tunnel'`), `'ball'` dla `['ball','prop_ball','prop_hay_ball']` (lub kończących się na `'_ball'`), inaczej `null`. Ignoruje `thing.flat === true` lub brak skończonych `thing.x`, `thing.y`.
- **`interactionSpots(thing, def)`**:
  - Wejście: `thing` (`{ id?, uid?, itemId?, x, y, w?, h?, flip? }`), opcjonalnie `def` (`{ w?, h?, kind? }`).
  - `w = (def && def.w) || thing.w || (kind === 'tunnel' ? 32 : 16)`, `halfW = Math.round(w / 2)`.
  - Dla `'tunnel'`: `[{ x: Math.round(thing.x - halfW - 12), y: Math.round(thing.y), facing: 1, side: 'left' }, { x: Math.round(thing.x + halfW + 12), y: Math.round(thing.y), facing: -1, side: 'right' }]` (odwrócone gdy `thing.flip === true`).
  - Dla `'ball'`: `[{ x: Math.round(thing.x - halfW - 10), y: Math.round(thing.y), facing: 1, side: 'left' }, { x: Math.round(thing.x + halfW + 10), y: Math.round(thing.y), facing: -1, side: 'right' }]`.
  - Błędne wejście -> `[]` bez wyjątku.
- **`pickReachable(things, pigPos, isFree, findPath, rng, defs)`**:
  - Waliduje: `Array.isArray(things)`, `pigPos` ze skończonymi `x, y`, funkcje `isFree` i `findPath`; przy braku zwraca `null`.
  - Dla każdej zabawki (`kindOf(t)`) sprawdza kandydatów `interactionSpots(t, def)`: wymaga `isFree(spot.x, spot.y) === true` oraz `path = findPath(pigPos.x, pigPos.y, spot.x, spot.y)` jako niepustej tablicy. Bierze pierwszy osiągalny `spot` zabawki.
  - Z listy osiągalnych zabawek wybiera indeks `Math.floor((rng ? rng() : Math.random()) * list.length)`.
  - Zwraca `{ thingUid: string, itemId: string, kind: 'tunnel' | 'ball', spot: { x, y, facing, side }, path: Array<{ x, y }> }` lub `null` (brak zabawek, zabawka za meblem, brak ścieżki).

## 3. Synchronizacja zabawki (suppressDraw): funkcje i linie

1. **`drawThing(ctx, thing)` (`web/home/canvas-pig.js:1327-1348`)**: na początku (`1328`) `if (!thing || thing.suppressDraw) return;`. Stojąca kopia w `allStanding` (`2329-2360`) znika na czas zabawy.
2. **Wybór i start zabawy (`pickRandomWalkTarget` `1131`, `update` `2167-2201`)**:
   - W `PigCanvas` pole `this.activePlay = null` i `this.pendingPlay = null`.
   - `pickRandomWalkTarget()` przy `window.CuyPlayTargets` wywołuje `pickReachable(this.things, { x: this.pigX, y: this.pigY }, (x,y)=>this.isFree(x,y), (sx,sy,tx,ty)=>this.findPath(sx,sy,tx,ty), Math.random, id=>this.getItemDef(id))` (np. `Math.random() < 0.25`), zapisuje `this.pendingPlay = res` i ustawia `this.path`.
   - Po dojściu do `res.spot` (`2167-2201`) znajduje `thing` (`id === res.thingUid || uid === res.thingUid`), ustawia `thing.suppressDraw = true`, zapamiętuje `originX = thing.x`, `originY = thing.y`, ustawia `this.facing = res.spot.facing` i kolejkę animacji: `tunnel`: `['tunnel_in', 'tunnel_wiggle', 'tunnel_out']`; `ball`: `['ball_push']`.
3. **Skala (`drawPig` `2619-2668`, `scaleAt` `975-985`)**: `drawPig` używa `scale = this.getDrawScale()` (`scaleAt(this.pigY)`) i `dw = this.getDrawnSize(scale)`. Ponieważ w `animations.json:361-388` zabawka jest w klatce 64x64, renderuje się dokładnie w skali `scaleAt(this.pigY)` dla wszystkich 5 etapów (`baby..legend`).
4. **Koniec i przerwanie**: po ostatniej animacji zabawy w `update` (`2214-2220`) przywraca `thing.suppressDraw = false` (zabawka zostaje w `(originX, originY)`). W `setScene` (`872-944`), `setThings` (`946-965`) i przy starcie `drag`: czyści `pendingPlay`/`activePlay` i zeruje `t.suppressDraw = false` dla `this.things`.

## 4. Kontrakt `weather.js` i `weather.json`

- **Bez edycji `canvas-pig.js`**: `web/home/canvas-pig.js:392-400` udostępnia `window.CuyRoom.addLayer(name, z, drawFn)` i `removeLayer(name)`. W `render()` (`2368`) warstwy `z >= 10` rysują się po tle, meblach, śwince i `applySceneLight` z argumentem `scene = { width, height, wallH, floorY, state, time }` (`2271-2280`). `CanvasPig.addLayer` NIE istnieje (`3024-3220`) — PK-PF2 rejestruje warstwę przez `window.CuyRoom.addLayer('weather', 15, fn)`.
- **`assets/data/weather.json`** (kolory z `assets/data/style_palette.json:13`):

- **`web/home/lib/weather.js`** (UMD: `module.exports = api` / `window.CuyWeather = api`, czyste funkcje, bez mutacji wejścia):
  - `stateFor(dateKey, sceneKind, settings, data)`:
    - `sceneKind !== 'outdoor'` -> `{ type: 'none', outdoor: false, seed: 0, config: null }`.
    - `settings && (settings.weatherEnabled === false || settings.weather === false)` -> `{ type: 'none', outdoor: true, disabled: true, seed: 0, config: null }`.
    - `dateKey` (string / `Date` -> `YYYY-MM-DD` / liczba) haszowane deterministycznie (FNV-1a) do `u` w `[0, 1)`, mapowane po skumulowanych `weight` z `data.types` (lub wbudowanego fallbacku). Zwraca `{ type, outdoor: true, seed, dateKey, config }`.
  - `draw(ctx, state, tMs, w, h)`:
    - Gdy `!ctx || !state || !state.outdoor || state.type === 'none' || state.type === 'clear'`: natychmiastowy `return` (0 wywołań `ctx`).
    - Bezpieczne domyślne: `w > 0 ? w : 256`, `h > 0 ? h : 144`, `t = (Number.isFinite(tMs) && tMs >= 0) ? tMs / 1000 : 0`.
    - Rysuje tint (`fillRect(0, 0, w, h)`), a dla `'rain'` `streakCount` deterministycznych smug przesuwanych o `(windX * t, speedY * t)` modulo `(w, h)`. Zero wpływu na Core/statystyki.

## 6. Nocne światło na dworze (lights.js, lights.json)

  - `autoOn(src, period)` (`82-86`) zwraca `true` dla `periodIndex(period) >= periodIndex(src.auto_at || 'evening')` gdy `src.toggle` jest `true`. Uwaga: `autoOn` nie jest dziś w `api` (`161-169`) — PK-P6c eksportuje `autoOn`.
  - **Straż `toggle: false`**: w `activeSources` (`99-106`) `manual[key]` i `placed.on` obecnie nadpisują `autoOn` nawet dla `src.toggle === false` (okna). Poprawka: `var on = (src.toggle === false) ? autoOn(src, period) : (...)`.
- **`assets/data/lights.json`**:
  - `torch` (`265`), `lamp_oil` (`287`), `lantern` (`309`), `brazier` (`356`) mają `"place": "outdoor"`, `"toggle": true`; dodać `"auto_at": "evening"` (tak jak ma `lamp_street` `343`), żeby o zmierzchu (17:00+) świeciły bez ręcznego kliku.
