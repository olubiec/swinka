## 3. Weryfikacja projektu PK-P47r i kto jeszcze liczy piksele

### Kontrakt `room-geometry.js` (`CuyRoomGeometry`)
`stageOffset(cols, rows)` wystarcza, jeśli `cellToPx` i `pxToCell` zostają w lokalnych współrzędnych pokoju (`0..cols*16`, `0..rows*16`) — wtedy zapis (`WorldState.Rooms`) i C# (`RoomsFeature.cs:641-642`) nie wymagają zmian.

Eksport w `web/home/features/places/room-geometry.js`:
- `STAGE_W = 256`, `STAGE_H = 144`
- `stageOffset(cols, rows)`:
  ```js
  function stageOffset(cols, rows) {
    const c = isValidPosInt(cols) ? cols : DEFAULT_COLS;
    const r = isValidPosInt(rows) ? rows : DEFAULT_ROWS;
    return {
      x: Math.floor((STAGE_W - c * CELL) / 2),
      y: Math.floor((STAGE_H - r * CELL) / 2)
    };
  }
  ```
- Offsety: `10x6 -> {x:48,y:24}`, `12x7 -> {x:32,y:16}`, `14x8 -> {x:16,y:8}`, `16x8 -> {x:0,y:8}`, `20x9 -> {x:-32,y:0}` (`20x9` ma `320 px > 256 px`, więc bez kamery kolumny `0..1` i `18..19` wychodzą poza kadr `0..255`).

### Kto jeszcze liczy piksele z kratek i czy potrzebuje `stageOffset`

1. `web/home/canvas-pig.js` (**PK-P47r**, F2-2):
   - `setScene(def)` (`:896-922`): zawsze `sceneWidth = 256`, `sceneHeight = 144`, `canvas.width = 256`, `canvas.height = 144`. Dla `sceneKind === 'room'` liczy `cols = Math.round((def.size[0] || 192) / 16)`, `rows = Math.round((def.size[1] || 112) / 16)`, `this.roomOffset = CuyRoomGeometry.stageOffset(cols, rows)` (fallback `{x: Math.floor((256-cols*16)/2), y: Math.floor((144-rows*16)/2)}`), `this.roomSize = [cols*16, rows*16]`.    - `walk` (`:903, 926`): przesuwa `def.walk` o `(offX, offY)`: `[w[0]+offX, w[1]+offY, w[2]+offX, w[3]+offY]`.
