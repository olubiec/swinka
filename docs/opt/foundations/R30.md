## 3. `scene_hotspots.json` i `hotspots.js` (schemat i API)

### Schemat `assets/data/scene_hotspots.json`
Wyłącznie obiekty niebędące instancjami (pokoje mają `[]`):
```json
{
  "version": 1,
  "scenes": {
    "room": [],
    "garden": [
      { "id": "pond", "kind": "decor", "rect": [62, 126, 76, 132], "label": "Pond" },
      { "id": "flowerbed", "kind": "decor", "rect": [10, 118, 42, 124], "label": "Flower bed" }
    ],
    "park": [{ "id": "gazebo", "kind": "decor", "rect": [70, 70, 130, 84], "label": "Gazebo" }],
    "farm": [
      { "id": "orchard", "kind": "orchard", "rect": [12, 24, 96, 62], "label": "Orchard" },
      { "id": "shop", "kind": "shop", "rect": [170, 32, 242, 76], "label": "Farm shop" }
    ],
    "market": []
  }
}
```
`tools/qa/hotspots-check.js` (`validate(data)`): unikalne `id` w scenie, `kind` z `['stall','plot','orchard','shop','decor','lamp']`, `rect` 4 liczby `0 <= x0 < x1 <= 256`, `0 <= y0 < y1 <= 144`, `label` niepusty `<= 14` znaków.

### Kontrakt `web/home/lib/hotspots.js` (UMD, czysty, ES2020)
Wzorzec UMD jak `web/home/lib/lights.js:3` (`module.exports` w Node, `window.CuyHotspots` w przeglądarce), zero DOM i zero zależności.
- **`KINDS`**: `['stall', 'plot', 'orchard', 'shop', 'decor', 'lamp']`.
- **`fromScene(sceneId, staticData, instances, catalog)`**:
  - Dla pokoi (`room`, `salon`, `bedroom`, `playroom`, `dorm`, `pig:*`) bez instancji lamp zwraca wspólną zamrożoną tablicę `EMPTY` (zero alokacji).
  - Z `instances` (`placedThings` lub `{ uid/id, itemId, x, y, anchorX, anchorY, w, h }`) buduje `{ id, kind, rect, label, uid }`:
    `rect = [Math.round(x - anchorX), Math.round(y - anchorY), Math.round(x - anchorX + sw), Math.round(y - anchorY + sh)]`.
    - Stragany (`fx:market:stall_*` / `stall_basic` / `stall_big`) -> `kind: 'stall'`, `id`: `'stall:seeds'|'stall:pantry'|'stall:decor'|'stall:own'` (lub `'stall:' + n`), `uid`.
    - Grządki (`fx:farm:plot:<n>`) -> `kind: 'plot'`, `id: 'plot:' + n`, `uid`.
    - Lampy (z `catalog` lub `lamp_*`/`fairy_lights`/`brazier`/`campfire`) -> `kind: 'lamp'`, `id: uid`, `uid`.
  - Łączy z `staticData.scenes[sceneId]`; przy kolizji `id` wygrywa hotspot z instancji.
- **`hit(list, x, y)`**: trafiony hotspot lub `null`; przy nakładaniu wygrywa wyższy `rect[3]`, przy remisie mniejsze pole `(x1-x0)*(y1-y0)`. Odporny na `null`/`NaN`/odwrócony `rect`.
- **`arbitrate({ overPig, editMode, dragging })`**: `editMode ? 'edit' : dragging ? 'drag' : overPig ? 'pig' : 'hotspot'`.
- **`clampLabelRect(rect, labelW, labelH, sceneW = 256, sceneH = 144)`**: pozycjonuje etykietę i przycina do `[0..sceneW-labelW, 0..sceneH-labelH]`.
- **`sortKeyboard(list)`**: sortuje po `rect[1]` (y), potem `rect[0]` (x).
- **`createTracker({ cooldownMs = 250, now = () => Date.now() })`** (lub metody na `CuyHotspots`): `hoverId`, `activeId`, `setHover(id)`, `trigger(hotspot, nowMs)` (ignoruje powtórkę tego samego `id` w `< 250` ms), `on(kind, fn)` -> `unsubscribe`.
