## 3. Przyczyny z numerami linii (CSS vs C#)

### Przyczyny CSS (PK-P47c)
1. **`.stage-viewport` i `#pigCanvas` nie kurczą się pionowo** (`web/home/style.css:380-392`, `web/home/features/places/feature.css:37-46`): `.stage-viewport` ma `flex: 0 0 auto; height: auto;`, a `#pigCanvas` ma `width: 100%; height: auto;`. Scena narzuca wysokość z pełnej szerokości (`196..231.7px` przy `420px`) zamiast oddać miejsce dolnemu paskowi.
2. **`.actions-section` ma za małe `min-height` i zbyt małą rezerwę** (`web/home/style.css:559-560`): `flex: 1 1 auto; min-height: 96px;`. Dwa wiersze `.game-btn` (`min-height: 48px`, `style.css:594`) + `gap: 4px` (`style.css:569`) + `padding: 4px 10px 6px` (`style.css:555`) wymagają `112px`. Gdy brakuje miejsca w `.game-device`, `.actions-section` zatrzymuje się na `96..102px`, a `#btnMore` wystaje w dół poza `.game-device` (`overflow: hidden`, `style.css:114`) o `2.5..55.1px`.
3. **Brak `flex: 0 0 auto` na stałych sekcjach** (`style.css:119`, `style.css:251`, `style.css:415`): `.game-header`, `.pet-identity-card` i `.needs-section` nie mają jawnego `flex-shrink: 0`.

### C# (`src/Cuy/dotNet/HomeWindow.cs` — PK-P24c)
- `HomeWindow.cs:232-235` ustawia bazowy rozmiar `420x640`, a `PositionNearTray` (`HomeWindow.cs:286-296`) skaluje okno przez `dpiScale` i `fit = Math.Min(1f, ...)` oraz ustawia `_webView.ZoomFactor = fit` (`HomeWindow.cs:296, 448`).
- Przeliczenie DPI i `ZoomFactor` dostarcza stronie WebView2 dokładnie `420x640` CSS px (lub proporcjonalnie przeskalowane przy niskim ekranie). C# **nie** ucina dołu okna — przyczyna leży wyłącznie w CSS.

## 4. Poprawka dla PK-P47c: selektory i wartości

Cel: `.stage-viewport` wypełnia wyłącznie wolną przestrzeń między `#placesBar` (plus opcjonalnym `#placesLockedHint`) a `.needs-section`, a `#pigCanvas` mieści się w niej z proporcją `16:9` (`width: auto; height: auto; max-width: 100%; max-height: 100%`).

Kolejność zmian w CSS:
1. **`web/home/style.css`**:
   - `.game-header` (`style.css:119`): dodać `flex: 0 0 auto;`.
   - `.pet-identity-card` (`style.css:251`): dodać `flex: 0 0 auto;`.
   - `.stage-viewport` (`style.css:380-382`): zmienić `flex: 0 0 auto; min-height: 80px; height: auto;` na:
     `flex: 1 1 0; min-height: 80px; height: 0;`

     `width: auto; height: auto; max-width: 100%; max-height: 100%; aspect-ratio: 16 / 9; object-fit: contain;`
   - `.needs-section` (`style.css:415`): dodać `flex: 0 0 auto;`.
   - `.actions-section` (`style.css:559-560`): zmienić `flex: 1 1 auto; min-height: 96px;` na:
     `flex: 0 0 auto; min-height: 0;`
2. **`web/home/features/places/feature.css`**:
   - `.places-bar` (`feature.css:6-24`): `height: 26px; flex: 0 0 auto;` (zgodnie z artem `nav_bar_frame.png` w PK-P47c).
   - `.places-locked-hint` (`feature.css:118`): dodać `flex: 0 0 auto;`.
   - `.stage-viewport` (`feature.css:37-39`): zmienić `flex: 0 0 auto; min-height: 80px; height: auto;` na:
