# R49: Live weather from Open-Meteo with consent

## 1. Reguły sieci i dokładne dane wychodzące
- **Stan obecny w repo**: gra nie wysyła żadnej telemetrii ani danych pogody. Istniejące użycia `HttpClient` dotyczą wyłącznie ręcznego sprawdzania aktualizacji (`src/Cuy.Core/Platform/UpdateChecker.cs:19,75,116`, `src/Cuy/dotNet/Features/SettingsFeature.cs:228,232`, `src/Cuy/dotNet/Platform/UpdateApplier.cs:26`). W `src/Cuy.Core/Weather/WeatherInfo.cs:46-75` istnieją już czyste helpery `OpenMeteo` (`FromWmo`, `GeocodeUrl`, `ForecastUrl`, `ParseGeocode`, `ParseCurrent`), ale brak klasy `WeatherService`. W `web/home/` wywołania `fetch(...)` dotyczą wyłącznie plików lokalnych (`app.js:120,134-135,1067`, `features/places/feature.js:140`).
- **Zasady `AGENTS.md`**: brak telemetrii, brak reklam, brak płatności, zasoby lokalne, atrybucja CC BY 4.0 (`WeatherInfo.cs:48`: `"Weather data by Open-Meteo.com (CC BY 4.0)"`).
- **Dozwolone hosty**:
  1. `https://api.open-meteo.com/v1/forecast` — bieżąca pogoda.
  2. `https://geocoding-api.open-meteo.com/v1/search` — wyłącznie na jawne żądanie użytkownika przy wpisaniu nazwy miasta (brak geolokalizacji IP, brak lokalizacji systemowej/GPS).
- **Dokładne dane wychodzące**:
  - Do `api.open-meteo.com`: wyłącznie `latitude` i `longitude` zaokrąglone do **1 miejsca po przecinku** (`Math.Round(v, 1, MidpointRounding.AwayFromZero)`, dokładność ~11 km) oraz stałe parametry `current=temperature_2m,weather_code,is_day&timezone=auto`. Żadnych ID użytkownika/urządzenia, nazwy świnki ani ciasteczek. Uwaga: `OpenMeteo.ForecastUrl` (`WeatherInfo.cs:70-75`) formatuje `0.####`, więc `WeatherService` musi zaokrąglić `lat`/`lon` do 1 miejsca przed wywołaniem `ForecastUrl`.
  - Do `geocoding-api.open-meteo.com`: wyłącznie `name` (wpisane miasto), `count=1`, `format=json`, `language=en`.
- **Częstotliwość, timeout, cache, offline**:
  - Maksymalnie 1 żądanie prognozy na **30 minut** (`TimeSpan.FromMinutes(30)`).
  - Timeout `HttpClient`: **5 sekund**.
  - Cache na dysku: `%AppData%/Cuy/weather_cache.json` (`SaveSystem.DefaultDirectory` w `SaveSystem.cs:58-65`).
  - Brak połączenia, błąd HTTP lub zły JSON nigdy nie rzucają wyjątku na zewnątrz; zwracany jest ostatni ważny cache lub stan `"offline"` / `"error"`. Pogoda ma efekt wyłącznie wizualny (zero wpływu na potrzeby i rozgrywkę).

## 2. Zgoda i ustawienia (UX i zapis)
- **Domyślnie WYŁĄCZONE**: przy nowym zapisie oraz przy ładowaniu starego zapisu bez sekcji pogody (`Consent = false`, `LocationName = ""`, `Latitude = null`, `Longitude = null`, `ConsentChangedUtc = null`).
- **Ekran "Live weather"**:
  - Tekst zgody przed włączeniem: *"Live weather sends only your rounded coordinates (1 decimal place, ~11 km) to Open-Meteo (api.open-meteo.com) at most once every 30 minutes. No player name, pig data, or device ID is sent. Weather is visual only."*
  - Informacja przy wyszukiwaniu miasta: *"Searching a city sends the typed city name once to geocoding-api.open-meteo.com to resolve coordinates."*
  - Widoczna atrybucja: `Weather data by Open-Meteo.com (CC BY 4.0)`.
- **Kontrolki UI**:
  - Przełącznik `Live weather` (domyślnie OFF, pełna obsługa klawiatury).
  - Pole ręcznego wpisu miasta lub współrzędnych `"lat, lon"` (zakres `lat` `[-90, 90]`, `lon` `[-180, 180]`, brak `NaN`/`Infinity`) + przycisk `Save location`.
  - Przycisk `Delete my location` — czyści `LocationName`, `Latitude`, `Longitude` w zapisie oraz usuwa plik cache z dysku.
  - Status tekstowy: `Off`, `Connected`, `Location required`, `Offline`, `Error`.
- **Ślad zgody w zapisie**: `GameState.Weather` (`WeatherSettings`) przechowuje `Consent`, `ConsentChangedUtc`, `LocationName`, `Latitude`, `Longitude` (zawsze zaokrąglone do 1 miejsca po przecinku).

### `src/Cuy.Core/Weather/WeatherMapping.cs`
- `public static class WeatherMapping` (namespace `Cuy.Core.Weather`):
  - `public static string FromWmo(int code)`:
    - Dla kodów spoza zakresu `0..99` lub nieznanych kodów WMO zwraca `"clear"`.
    - Dla znanych kodów WMO `0..99` deleguje do `OpenMeteo.FromWmo(code)` (`WeatherInfo.cs:50-61`) i zwraca jedną z 6 stałych: `"clear"`, `"cloudy"`, `"fog"`, `"rain"`, `"snow"`, `"storm"`.
    - Uwaga: `OpenMeteo.FromWmo` w `WeatherInfo.cs:60` zwraca `Cloudy` dla nieznanych kodów; `WeatherMapping.FromWmo` jawnie zwraca `"clear"` dla nieznanych kodów zgodnie z wymaganiem `PK-WX1` i `PK-T25`.
  - `public static double RoundCoord(double value)` -> `Math.Round(value, 1, MidpointRounding.AwayFromZero)`.
  - `public static bool TryParseCoords(string latText, string lonText, out double lat, out double lon)` -> parsuje `CultureInfo.InvariantCulture`, odrzuca `NaN`/`Infinity`, sprawdza `lat >= -90 && lat <= 90` oraz `lon >= -180 && lon <= 180`, zapisuje wartości zaokrąglone przez `RoundCoord`.

### `src/Cuy.Core/Input/Validation/WeatherMessages.cs`
- Klasa `public sealed class WeatherMessages : IMessageRuleSet` (odkrywana przez refleksję w `MessageValidator.cs:62-80`).
- Ponieważ `FieldRule` (`IMessageRuleSet.cs:58-68`) ma tylko `Str`, `Int`, `Bool`, `Id` (brak `Double`), współrzędne idą jako `FieldRule.Str`:
  - `new MessageRule("weather.setConsent", FieldRule.Bool("consent"))`
  - `new MessageRule("weather.setLocation", FieldRule.Str("city", 80, required: false), FieldRule.Str("lat", 16, required: false), FieldRule.Str("lon", 16, required: false))`
  - `new MessageRule("weather.deleteLocation")`
  - `new MessageRule("weather.refresh")`

### `src/Cuy/dotNet/WeatherService.cs`
- `public sealed class WeatherService : IDisposable` (namespace `Cuy`):
  - `public static readonly TimeSpan MinRefreshInterval = TimeSpan.FromMinutes(30);`
  - `public static readonly TimeSpan RequestTimeout = TimeSpan.FromSeconds(5);`
  - Konstruktor: `public WeatherService(Func<bool> hasConsent, Func<DateTime> utcNow = null, HttpMessageHandler handler = null, string cachePath = null)`
  - `HttpClient` tworzony leniwie wyłącznie przy pierwszym żądaniu gdy `hasConsent() == true` (gdy `false`, nigdy nie powstaje `HttpClient` ani żądanie).
  - `public Task<WeatherFetchResult> GetCurrentAsync(double lat, double lon, bool force = false)` — sprawdza `_hasConsent()`, zaokrągla `lat`/`lon` do 1 miejsca, sprawdza 30-min interwał i cache, pobiera `OpenMeteo.ForecastUrl(rLat, rLon)`, parsuje `OpenMeteo.ParseCurrent`, zapisuje cache, nigdy nie rzuca wyjątków.
  - `public Task<GeoPlace> GeocodeCityAsync(string city)` — sprawdza `_hasConsent()`, pobiera `OpenMeteo.GeocodeUrl(city, "en")`, parsuje `OpenMeteo.ParseGeocode`, nigdy nie rzuca wyjątków.
  - `public void ClearCache()` — usuwa cache z pamięci i pliku.
  - `WeatherFetchResult`: `Status` (`"off" | "ok" | "offline" | "error" | "no_location"`), `Info` (`WeatherInfo`), `FromCache` (`bool`).
