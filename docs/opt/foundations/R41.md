## 3. Kontrakt `pig-reactions.js`

Plik: `web/home/lib/pig-reactions.js` (czysty UMD: `window.PigReactions`, `module.exports`, bez DOM/bridge).

### Priorytety i reguły nadrzędne
- `PRIORITIES`: `{ sulk: 90, sick: 80, birthday: 75, feed: 70, treat: 70, trick: 65, vet: 60, groom: 55, chin: 55, pet: 55, poop: 50, autonomous: 30 }`.
- Każda reakcja ma `priority >= 50`, więc **przerywa** bieżącą akcję autonomiczną z `pig-behavior.js` (`interruptAutonomous: true`).
- Gdy `ctx.isSulking === true`: zdarzenia `pet`, `chin`, `call`, `trick` zwracają animację `'chatter'` (`durationMs: 1800`, `bubble: 'Hmph!'`, `sound: 'chatter'`, `blocked: true`).
- Gdy `ctx.isSick === true`:
  - `SICK_BLOCKED_ANIMS = ['run', 'popcorn', 'hurdle', 'spin', 'greet']`.
  - Zdarzenia energiczne (`trick`, `treat` z `popcorn`, `play`) są blokowane przez chorobę i zwracają `{ anim: ctx.sicknessAnim || 'sick', durationMs: 2500, bubble: 'Not feeling well...', sound: 'chirp', effect: 'sweat', priority: 80, interruptAutonomous: true, blocked: true }`.
  - `isBlockedBySickness(anim, ctx)`: zwraca `true` jeśli `ctx && ctx.isSick && SICK_BLOCKED_ANIMS.indexOf(anim) >= 0`.

### API `window.PigReactions`
- `PRIORITIES`, `SICK_BLOCKED_ANIMS`
- `detectSulk(timestampsMs, nowMs, windowMs = 3000, threshold = 8)`: filtruje `timestampsMs` w oknie `nowMs - windowMs`; zwraca `{ triggered: count > threshold, recent: filtered }` (parytet z `InteractionManager.cs:204-213`).
- `canInterrupt(currentPriority, nextReaction)`: `boolean` (`nextReaction.priority >= (currentPriority || 0)`).
- `react(event, ctx = {})`: `event` to string (`'pet'`) lub `{ type, item?, trickId?, conditionId?, healed? }`. Zwraca `{ anim, durationMs, bubble, sound, effect, priority, interruptAutonomous, blocked }`:
  1. `feed`: przy `ctx.fullness >= 95` -> `{ anim: 'idle', durationMs: 1200, bubble: "I'm full!", sound: 'click', effect: null, priority: 70, blocked: true }`; dla `item === 'cake'` -> `{ anim: 'party', durationMs: 4000, bubble: 'Celery cake!', sound: 'fanfare', effect: 'confetti', priority: 75 }`; inaczej -> `{ anim: item === 'hay' ? 'eat' : 'eat_treat', durationMs: 3500, bubble: 'Yum! Crunch crunch!', sound: 'crunch', effect: 'crunch', priority: 70 }`.
  2. `treat`: dla ulubionego (`ctx.favoriteFood === event.item && !ctx.isSick`) -> `{ anim: 'popcorn', durationMs: 2200, bubble: 'My favourite!', sound: 'pop', effect: 'hearts', priority: 70 }`; przy `ctx.isSick` lub zwykłym smakołyku -> `{ anim: 'eat_treat', durationMs: 3500, bubble: 'Tasty treat!', sound: 'crunch', effect: 'crunch', priority: 70 }`.
  3. `pet`: przy `ctx.isSleeping` -> `{ anim: 'wake_up', durationMs: 1500, bubble: '*yawn*', sound: 'chirp', effect: null, priority: 55 }`; inaczej -> `{ anim: 'purr_pet', durationMs: 3000, bubble: 'Purr...', sound: 'purr', effect: 'hearts', priority: 55 }`.
  4. `chin`: przy `ctx.isSulking` -> `chatter`; inaczej -> `{ anim: 'chin_rub', durationMs: 2600, bubble: 'Mmm, chin rubs!', sound: 'purr', effect: 'hearts', priority: 55 }`.
  5. `trick`: przy `ctx.isSick` -> blokada chorobą (zwraca `ctx.sicknessAnim || 'sick'`, `blocked: true`); inaczej `anim = event.trickId` (`'spin' | 'stand_up' | 'popcorn' | 'hurdle'`, fallback `'popcorn'`), `durationMs: 2400`, `bubble: 'Ta-da!'`, `sound: anim === 'popcorn' ? 'pop' : 'fanfare'`, `effect: 'sparkles'`, `priority: 65`.
  6. `sick`: gdy `event.healed` -> `{ anim: 'happy', durationMs: 2500, bubble: 'All better!', sound: 'wheek', effect: 'hearts', priority: 60 }`; inaczej -> `{ anim: ctx.sicknessAnim || 'sick', durationMs: 3000, bubble: 'Feeling unwell...', sound: 'chirp', effect: 'sweat', priority: 80 }`.
  7. `poop`: `{ anim: 'happy', durationMs: 2200, bubble: 'All clean and fresh!', sound: 'sweep', effect: 'hearts', priority: 50 }`.
  8. `groom`: `{ anim: 'happy', durationMs: 2800, bubble: 'So fresh and fluffy!', sound: 'purr', effect: 'sparkles', priority: 55 }`.
  9. `sulk`: `{ anim: 'chatter', durationMs: 3000, bubble: 'Hmph! Too many pokes!', sound: 'chatter', effect: 'sweat', priority: 90 }`.
  10. `birthday`: `{ anim: 'party', durationMs: 4000, bubble: 'Happy birthday!', sound: 'fanfare', effect: 'confetti', priority: 75 }`.
- Nowe syntetyczne dźwięki wymagane w `web/home/sound.js`: `purr`, `pop`, `chirp`, `chatter` (wszystkie `<= 0.25s` ZzFX w `Sound.CUES`).

## 4. Braki wymagające C# i ich komunikaty

### Już istnieje po stronie C# (nie dodawać duplikatów)
- `feed` (`HomeWindow.cs:700-703,773-862`), `clean` (`HomeWindow.cs:713-715,901-922`), `call` (`HomeWindow.cs:717-719,924-934`), `pet` (`HomeWindow.cs:728-730,963-970`), `trick` (`TricksFeature.cs:28-34`), `vet_checkup` / `vet_treat` / `vet_dose` (`VetFeature.cs:218-265`).

### Braki wymagające zmian w C# / Core
1. **Nowa wiadomość `care_interact`** (bo `chin` i `groom` nie mają żadnego komunikatu z Home do Core):
   - Walidacja (nowy plik `src/Cuy.Core/Input/Validation/CareInteractMessages.cs` implementujący `IMessageRuleSet`, bez edycji `MessageValidator.cs`):
     - `type`: `"care_interact"`
     - `action`: wymagany string z `["chin", "groom"]`
     - `taskId`: opcjonalny string z `["brush", "nails", "full_clean", "spot_clean"]` (tylko przy `action === "groom"`)
   - Obsługa w C# (`src/Cuy/dotNet/Features/CareInteractFeature.cs` jako `HomeFeatureBase`):
     - `"chin"`: wywołuje `pet.TryRewardPetting(3.0)` (lub `AddBondPoints(1)` + mood `+3`, wspólny limit godzinowy), `brain.RequestAnimation("chin_rub")`.
     - `"groom"`: opcjonalnie `pet.MarkCareDone(taskId)` + `pet.AwardCareTask()`, `pet.AddBondPoints(1)`, `pet.Needs.Mood = Math.Min(100, +4)`, `pet.Needs.Cleanliness = Math.Min(100, +8)`, `brain.RequestAnimation("happy")`.
2. **Dodatkowe pola w stanie wysyłanym do Home (`HomeWindow.cs:605-659` / `VetFeature.cs:183`)**:
   - `sicknessAnim`: `pet.SicknessAnimation` (np. `"sick"`, `"sad"`, `"scratch"`, `"shiver"`, `null` gdy zdrowa),
   - `isBirthday`: `bool` (gdy urodziny nastąpiły w bieżącym dniu gry / przy zdarzeniu `pet.Birthday` z `HomeWindow.cs:189`).

1. **Unit `PigReactions` (wszystkie 10 zdarzeń)**: weryfikacja pól `{ anim, durationMs, bubble, sound, effect, priority }` dla `feed` (`hay`, warzywo, `cake`, `fullness>=95`), `pet` (`isSleeping=false/true`), `chin`, `treat` (`favoriteFood`), `trick` (`spin`, `stand_up`, `popcorn`, `hurdle`), `sick` (`healed=false/true`), `poop`, `groom`, `sulk`, `birthday`.

4. **Playwright E2E (`tools/qa/ux-p16-pig-reactions.js`, `420x640`)**:
   - Karmienie sianem i kliknięcie świnki -> zmienia się dymek (`Purr...`) i wysyłany jest `pet` / `feed`.
