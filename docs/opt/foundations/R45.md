## 2. Wybrany projekt i uzasadnienie

- **Jeden opcjonalny towarzysz (`id: "garden_friend"`):** mały, przyjazny towarzysz ogrodowy pojawiający się **wyłącznie** w scenach `garden` i `park` (nigdy w `salon`, `room`, `farm`, `market`, `pig:*`).
- **Brak wpływu na potrzeby i ekonomię:** nie modyfikuje `Needs`, nie generuje koniczynek (`Clovers`), nie kosztuje koniczynek (`price: 0`, darmowy przełącznik w Ustawieniach), nie tworzy kupek (`Poops`) i nie tyka `Brain` (`src/Cuy.Core/AI/Brain.cs`).
- **Zachowanie w pasie sceny:** chodzi w pasie `walk` sceny (`[8, 80, 248, 138]` z `place_scenes.json:26,47`), omija kolizje przez `ctx.isFree(x, y)` i utrzymuje minimalny dystans `minPigGap: 20` px od wszystkich świnek z `ctx.pigs` (brak nakładania). Gdy któraś świnka znajdzie się w promieniu `reactRadius: 34` px, towarzysz przechodzi w reakcję `popcorn` lub `sniff` i obraca się w jej stronę (`facing`).
- **Uzasadnienie graficzne:** ponieważ na dysku nie ma sprite'ów ptaka ani ślimaka, a pakiety `PK-CO1`/`PK-CV4` nie tworzą binarnych PNG, wybór `sprites/companion_agouti/spritesheet.png` w skali `0.45` (mniejszy od dorosłej świnki) gwarantuje istniejący plik na dysku (`K8 data-valid`), poprawną animację z `animations.json` (64x64, `floor_y: 59`), pełną kompatybilność z `litFrame` i cieniami `canvas-pig.js`, a w przyszłości właściciel może podmienić samą ścieżkę PNG i `frameSize` w `assets/data/companions.json` bez zmian w kodzie.
- **Przełącznik w Ustawieniach:** domyślnie **wyłączony** (`CompanionEnabled = false`), zapisywany w `GameState.CompanionEnabled` i `GameState.CompanionId`.

## 3. Kontrakt `companion.js`, dane, stan, komunikat

### A. Dane: `assets/data/companions.json`
```json
{
  "version": 1,
  "defaultId": "garden_friend",
  "allowedScenes": ["garden", "park"],
  "companions": [
    {
      "id": "garden_friend",
      "name": "Garden Friend",
      "sprite": "sprites/companion_agouti/spritesheet.png",
      "frameSize": [64, 64],
      "floorY": 59,
      "scale": 0.45,
      "speed": 22,
      "minPigGap": 20,
      "reactRadius": 34,
      "reactCooldownMs": 3500,
      "idleMinMs": 1400,
      "idleMaxMs": 3200,
      "animations": {
        "idle": { "row": 0, "frames": 16, "fps": 8 },
        "sniff": { "row": 1, "frames": 12, "fps": 12 },
        "walk": { "row": 2, "frames": 8, "fps": 10 },
        "popcorn": { "row": 4, "frames": 12, "fps": 14 }
      }
    }
  ]
}
```
- Wszystkie liczby zachowania i grafiki mieszkają w `assets/data/companions.json` (z fallbackiem `DEFAULT_DATA` w `companion.js`, wzór `web/home/lib/weather.js:9-28`).

### B. Moduł UMD: `web/home/lib/companion.js`
- Eksport: `window.Companion` w przeglądarce oraz `module.exports` w Node (UMD IIFE jak `weather.js:190-193`).
- Deterministyczny PRNG (np. LCG/mulberry32 z opcjonalnym `opts.seed`, domyślnie `1337`) — brak `Math.random()` w testach deterministycznych.
- **API publiczne (DOSŁOWNE):**
  - `Companion.DEFAULT_DATA`: wbudowana kopia domyślnej konfiguracji z `companions.json`.
  - `Companion.create(data, opts)`:
    - `data`: obiekt jak `companions.json` (gdy `null`/zły, używa `DEFAULT_DATA`).
    - `opts`: `{ enabled?: boolean, id?: string, seed?: number }`.
    - Zwraca instancję `{ step(dt, ctx), entries(), setEnabled(on), setId(id), isEnabled(), getId() }`.
  - `inst.step(dt, ctx)`:
    - `dt`: liczba ms (`<= 0` lub `!Number.isFinite(dt)` -> no-op; przycinane do bezpiecznego kroku np. `max 2000` ms w sub-krokach max `50` ms, wzór `scene-pigs.js:9-10`).
    - `ctx`: `{ sceneId: string, walk?: [x0,y0,x1,y1], pigs?: Array<{x,y}>, isFree?: (x,y)=>boolean }`.
    - Gdy `!enabled` lub `sceneId` nie należy do `allowedScenes` (`['garden', 'park']`): czyści aktywną obecność (`entries()` zwraca `[]`).
    - Gdy dozwolona scena: przy pierwszym wejściu spawnuje towarzysza w pasie `walk` z dala od `ctx.pigs` (`>= minPigGap`) i w punkcie `isFree(x, y)`. W kolejnych krokach losuje cel w `walk` (omijając `pigs` i przeszkody), idzie z prędkością `speed` px/s, po dojściu stoi `idle`/`sniff`, a gdy najbliższa świnka wejdzie w `reactRadius` i minął `reactCooldownMs`, uruchamia reakcję (`popcorn` lub `sniff`) skierowaną do świnki.
  - `inst.entries()`:
    - Zwraca `[]`, jeśli wyłączony lub scena niedozwolona.
    - W przeciwnym razie zwraca tablicę 1-elementową:
      `[{ id, x, y, frame, row, anim, facing, sprite, frameSize, floorY, scale }]`
      gdzie:
      - `id`: string (np. `'garden_friend'`),
      - `x`, `y`: liczby w granicach pasa `walk`,
      - `frame`: int `>= 0` (indeks klatki w wierszu `row`),
      - `row`: int `>= 0`, `anim`: `'idle'|'walk'|'sniff'|'popcorn'`, `facing`: `1 | -1`,
      - `sprite`: string z `companions.json` (np. `'sprites/companion_agouti/spritesheet.png'`),
      - `frameSize`: `[64, 64]`, `floorY`: `59`, `scale`: `0.45`.

### C. Stan zapisu C# (`src/Cuy.Core/GameState.Companion.cs`)
Nowy plik partial klasy `GameState` (`src/Cuy.Core/GameState.cs:10`):
- `public bool CompanionEnabled { get; set; } = false;`
- `public string CompanionId { get; set; } = "garden_friend";`
- Stare zapisy (JSON bez tych pól) deserializują się z `CompanionEnabled == false` i `CompanionId == "garden_friend"`. Nie wymaga zmiany `GameState.CurrentVersion` (`3`).

### D. Komunikat i walidacja (`src/Cuy.Core/Input/Validation/CompanionMessages.cs`)
Klasa `public sealed class CompanionMessages : IMessageRuleSet`:
- `Rules`: `new MessageRule("companion.set", FieldRule.Bool("enabled", true), FieldRule.Id("id", false))`
  (typy `FieldRule.Bool` i `FieldRule.Id` z `src/Cuy.Core/Input/IMessageRuleSet.cs:64-68`).
- Pomocnik statyczny do sprawdzania znanego towarzysza:
  `public static bool IsKnownCompanion(string id, IEnumerable<string> knownIds = null)` — domyślnie akceptuje `"garden_friend"` (case-sensitive lub `Ordinal`), odrzuca puste/nieznane identyfikatory.
- Pomocnik `public static string ValidateSetPayload(JObject message, IEnumerable<string> knownIds = null)` — zwraca `null` dla poprawnego `{ type: "companion.set", enabled: bool, id?: string }` ze znanym `id` (lub gdy `id` pominięte), albo kod błędu (np. `"unknown_companion"`).

### E. Kontrakt (`docs/contracts/companion.md`)
- Klucz stanu w Home:
  `companion: { enabled: bool, id: string }` (domyślnie `{ enabled: false, id: "garden_friend" }`).
- Komunikat z Home do C#:
  `{ type: "companion.set", enabled: bool, id?: string }`
  - Walidacja: `CompanionMessages` (`enabled` wymagane typu `bool`, `id` opcjonalne typu `Id` `^[a-z0-9_:]+$` max 128 i z listy `assets/data/companions.json`).
  - Odpowiedź: odświeżenie stanu przez `HomeWindow.NotifyStateChanged()` (jak `docs/contracts/settings.md:38`).

## 5. Przypadki dla PK-T23

### JS (`tools/qa/ux-p131` NIE czytać! Niezależny test `tools/qa/ux-p141-companion-adv.js`)
1. `COM-garden-yes-room-no`: dla `garden` i `park` `entries().length === 1`; dla `salon`, `room`, `farm`, `market`, `pig:kuki` `entries().length === 0`.
2. `COM-never-overlaps-3-pigs`: przez 600 kroków (`dt=50`) z 3 świnkami w `garden` odległość towarzysza od każdej świnki w spoczynku i po spawnie spełnia `hypot(dx, dy) >= minPigGap` (lub z małą tolerancją ruchu `>= minPigGap - 2` gdy świnka wejdzie w niego, ale cel nigdy nie ląduje na śwince).
3. `COM-stays-in-strip-all-scenes`: w `garden` i `park` przez 500 kroków pozycja `(x, y)` mieści się w `walk = [8, 80, 248, 138]` i nie wchodzi w `blockers` (`isFree(x, y) === true`).
4. `COM-switch-off-removes-instantly`: przełączenie `setEnabled(false)` (lub `CanvasPig.setCompanion({ enabled: false })`) powoduje natychmiast `entries().length === 0` bez czekania na kolejny `step`.
5. `COM-draw-order-with-furniture`: w scenie z meblem o `y` mniejszym i większym od `companion.y` (Playwright / `CanvasPig` w `garden`), kolejność rysowania względem mebli zachowuje sortowanie po `y`. *(Jeśli `CanvasPig.setCompanion` jeszcze nie wpięte -> `SKIP`).*
6. `COM-perf-300-frames`: 300 kolejnych wywołań `step(16, ctx)` + `entries()` wykonuje się w `< 50 ms` bez wyjątków i bez wzrostu liczby wpisów (`<= 1`).
7. `COM-console-clean`: otwarcie Home w trybie mock (`seven`) i przełączenie do `garden` nie emituje błędów `console.error` ani `pageerror`.

### C# (`tests/Cuy.Core.Tests/CompanionAdversarialTests.cs`)
8. `COM-old-save-default-off`: deserializacja starego JSON zapisu (bez `CompanionEnabled`, `CompanionId`) daje `CompanionEnabled == false` i `CompanionId == "garden_friend"`.
9. `COM-message-fuzz-300`: 300 losowych/zepsutych ładunków JSON (`Random(42)`) dla `companion.set` (złe typy `enabled`, brak `enabled`, `id` ze znakami specjalnymi/za długie/>128) — `MessageValidator` nigdy nie rzuca wyjątku i odrzuca błędne komunikaty.
10. `COM-unknown-companion`: `CompanionMessages.IsKnownCompanion("dragon")` / `ValidateSetPayload` z nieznanym `id` odrzuca ładunek, a `"garden_friend"` akceptuje.
