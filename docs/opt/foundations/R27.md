# PK-R27 Foundations: Skins (`room_skin`), Stash Filters, Templates & Edit Drawer Anchors

Ground-truth specification for `PK-P6s`, `PK-P6a`, `PK-P6b`, `PK-PE2`, and `PK-T5`. Every path, line, and symbol was verified in the codebase.

## 1. Skórki end to end i co przestało działać

1. **Stan (`RoomsFeature.cs:117-126, 273-311`)**:
   - `state.rooms.layouts[roomId]` = `{ name, cols, rows, wallRows, wallpaper, floor, items }`.
   - `state.rooms.skins` = `{ wallpapers: SkinEntry[], floors: SkinEntry[] }`, gdzie `SkinEntry` = `{ id, name, icon, price, owned }` (`owned` = `bool`: `pet.GetItemCount(it.Id) > 0 || world.OwnedItems.ContainsKey(it.Id)`).
   - `RoomsFeature.cs:282-304` filtruje `ItemCatalogLoader.GetAll()` (`assets/data/items_decor.json`): tapety (`wallpaper_*` lub `icon == "wallpaper"`), podłogi (`floor_*` bez `floor_lamp*`).
   - Uwaga: `web/home/features/rooms/mock.js:46-47, 150` używał tablic stringów w `skins`, a `features/places/mock.js` nie obsługuje `room_skin`.
2. **Wiadomość `room_skin` i Core**:
   - Walidacja (`RoomsMessages.cs:33-36`): `new MessageRule("room_skin", FieldRule.Id("room"), FieldRule.Id("slot"), FieldRule.Id("itemId", required: false))` — klucz pokoju to `room`, `itemId` opcjonalne.
   - Obsługa (`RoomsFeature.cs:471-505`): `slot` = `"wallpaper"|"floor"`. Pusty `itemId` czyści `roomLayout.Wallpaper`/`Floor` (`WorldState.cs:122-123`) na `string.Empty` (toast `"Removed!"`). Niepusty sprawdza własność, ustawia skórkę i wysyła `"Skin applied!"` (albo `"Not ready yet"`).
3. **Co przestało działać po `PK-P40d`**:
   - Grep w `web/home/` (`index.html`, `app.js`, `features/index.json:1-18`): `"rooms"` nie jest ładowane; `RoomCustomize`/`customize.js` istnieje tylko w `features/rooms/customize.js:257` i `features/rooms/feature.js:355-358, 908-909`.
   - `#editDrawer` i `#editItemToolbar` (`edit-panel.js:1286-1352`) przejęły meble, ale **zmiana kupionej tapety i podłogi (`room_skin`), zmiana nazwy pokoju i warianty kolorów stały się nieosiągalne** (uwaga 27 dotyczy tapet i podłóg).

## 2. Kontrakt `edit-skins.js`

Plik: `web/home/features/places/edit-skins.js`. UMD jak `web/home/lib/lights.js:171-175`: `if (typeof module !== 'undefined' && module.exports) module.exports = api; root.EditSkins = api;`.

1. **Stałe**: `OUTDOOR_IDS = ['garden', 'park', 'farm', 'market']`; `TILE_BASE = (typeof window !== 'undefined' && window.chrome && window.chrome.webview) ? 'https://cuy.assets/' : '../../assets/'` (`customize.js:17`); `SKIN_COLORS` z `assets/data/style_palette.json` (`wallpaper_mint: '#c3c98a'`, `wallpaper_peach: '#f2b5a0'`, `wallpaper_sky: '#b9c9c4'`, `wallpaper_lilac: '#7a5a6b'`, `wallpaper_night: '#2b3c4e'`, `floor_wood_light: '#e3b27a'`, `floor_tiles_checker: '#d9c096'`, `floor_grass: '#6c8050'`, `floor_carpet_red: '#8c4237'` + wpisy z `customize.js:10-14`; bez `#ffffff`/`#000000`).
2. **Czyste API**:
   - `isIndoorRoom(state, roomId)`: `false` gdy `!roomId` lub `OUTDOOR_IDS.indexOf(roomId) >= 0`; inaczej `true` (`salon`, `dorm`, `pig:<id>`).
   - `listOwned(state, roomId)`:
     - Gdy `!isIndoorRoom(state, roomId)`: `{ visible: false, currentWallpaper: '', currentFloor: '', wallpapers: [], floors: [] }`.
     - Normalizuje `state.rooms.skins.wallpapers`/`floors`: obsługuje obiekty `{ id, name, icon, price, owned }` (`owned === true` lub `state.rooms.owned[id] > 0`) i stringi `id`.
     - Zwraca `{ visible: true, currentWallpaper: layout.wallpaper || '', currentFloor: layout.floor || '', wallpapers: [{ id, name, color }], floors: [{ id, name, color }] }`.
3. **API DOM**:
   - `build(container, ctx)` (`ctx = { state, roomId, send }`): czyści `container`. Gdy `!res.visible`, ustawia `container.hidden = true` i kończy. Gdy `res.visible`: `container.hidden = false`, wstrzykuje `<style id="editSkinsStyle">`. Gdy brak kupionych skórek, renderuje `<p class="edit-skins-empty">Buy wallpapers in the shop</p>`. Renderuje sekcje `Walls` (`data-slot="wallpaper"`) i `Floor` (`data-slot="floor"`), w każdej `"Default"` (`data-item=""`) + kupione skórki (`data-action="skin"`, `data-slot`, `data-item="${id}"`, `is-current`, `aria-pressed`, swatch z `background-color` + `background-image: url('${TILE_BASE}world/tiles/${id}.png')`). Klik wywołuje `ctx.send({ type: 'room_skin', room: ctx.roomId, slot, itemId })`.

## 3. Kontrakt `edit-filters.js`

Plik: `web/home/features/places/edit-filters.js`. UMD: `module.exports = api; root.EditFilters = api;`.

1. **Stałe**: `TABS = ['All', 'Furniture', 'Lights', 'Plants', 'Decor']`, `EMPTY_MESSAGE = 'No items match your filter'`, `DEFAULT_LIGHT_IDS` = klucze z `assets/data/lights.json` (`lamp_floor`, `lamp_mushroom`, `lamp_arc`, `lantern_paper`, `lamp_salt`, `lamp_lava`, `fireplace`, `candle`, `fairy_lights`, `window`, `torch`, `lamp_oil`, `lantern`, `lamp_street`, `brazier`) + `lamp_post`, `lantern_garden`.
2. **Czyste API (nie mutuje `items`)**:
   - `categorize(item, lightIds)`:
     - Jeśli `TABS.indexOf(item.category) > 0`, zwraca `item.category`.
     - `id = String((item && (item.id || item.itemId)) || '').toLowerCase()`.
     - **Lights**: `id.indexOf('lamp_') === 0` lub `lightSet.has(id)`.
     - **Plants**: prefiksy `plant_`, `flower_`, `tree_`, `flowerbed_`, `bush_` lub `['hanging_planter', 'hedge', 'arch_rose']`.
     - **Furniture**: `item.layer !== 'wall' && item.layer !== 'ground'` oraz (`['sofa_cosy', 'armchair', 'bookshelf', 'side_table', 'cushion_big', 'hay_bar_wood', 'cosy_nook', 'bench_wood', 'bench_park', 'pouf_boucle', 'stump_seat', 'picnic_blanket', 'gazebo', 'bridge_wood', 'fence_wood', 'fence_farm', 'gate_garden', 'pigloo_garden', 'sandbox_pig', 'hay_basket', 'toy_basket']` lub prefiks `sofa_`/`bench_`/`table_`/`chair_`/`bed_`/`fence_`).
     - **Decor**: reszta (`layer === 'wall'|'ground'`, `sig_*`, `mug_steam`, `rug_fringed`, `blanket_folded`, `statue_pig`, `signpost`, `scarecrow`, `watering_can`, `bird_bath`, `fountain`, `memory_corner`, `wheelbarrow`).
   - `tabs(items, lightIds)`: zwraca `[{ id, label, count }]` dla `TABS`; suma 4 kategorii === `All.count === items.length`.
   - `filterItems(items, { tab, query }, lightIds)`: filtruje po `tab` (domyślnie `'All'`) i `query.trim().toLowerCase()` po `name` lub `id`.
3. **API DOM**: `build(container, { items, tab, query, onChange })` wstrzykuje `<style id="editFiltersStyle">`, renderuje `.edit-drawer-tabs` (`role="tablist"`, przyciski `role="tab"`, `data-tab`, `aria-selected`, `Tab (N)`) i `<input type="search" id="editDrawerSearch" class="edit-drawer-search">`. `ArrowLeft`/`ArrowRight` przełączają zakładkę, `Enter` w szukajce robi `preventDefault()`, `input` woła `onChange({ tab, query })`.

## 4. Kontrakt `edit-templates.js`

Plik: `web/home/features/places/edit-templates.js`. UMD: `module.exports = api; root.EditTemplates = api;`.

1. **Dane**: `DEFAULT_THEMES` z `assets/data/pig_rooms.json:113-179` (`kuki`, `ned`, `james`, `glen`, `racuch`), nadpisywane przez `state.rooms.themes`.
2. **Czyste API**:
   - `themes(state)`: zwraca `[{ id, name, mood, wallpaper, floor }]`.
   - `plan(themeId, state, roomId)`:
     - Outdoor (`garden`/`park`/`farm`/`market`) lub brak `roomId`: `{ refused: 'Templates are only for indoor rooms' }`.
     - Nieznany `themeId`: `{ refused: 'Unknown template' }`.
     - Brak własności `theme.wallpaper`/`theme.floor` (w `state.rooms.skins` lub `state.rooms.owned`): `{ refused: 'Buy ' + skinName + ' in the shop' }`.
     - Już ustawione w `state.rooms.layouts[roomId]`: `{ messages: [], noop: true }`.
     - Sukces: `{ messages: [ { type: 'room_skin', room: roomId, slot: 'wallpaper', itemId: theme.wallpaper }, { type: 'room_skin', room: roomId, slot: 'floor', itemId: theme.floor } ] }`.
3. **API DOM**: `build(container, { state, roomId, send })`: dla dworu czyści kontener; renderuje przyciski `[data-theme]`, blokuje je przy `refused` (`disabled`, `title`) lub `noop` (`disabled`, `aria-pressed="true"`), klik wysyła `res.messages` po kolei.

5. **`.edit-hint` i kursor**: `.edit-hint` widoczny tylko przy `_isOpen === true`; `cursor: grab` nad ruchomymi obiektami w Edit.
6. **Układ `420x640` / `400x620` (`edit-panel.css:48-68`)**: obecnie `.edit-drawer` ma `bottom: 0; max-height: 220px; z-index: 100`, więc **zasłania `.actions-section` i `#btnMore` (`index.html:231`)**.
