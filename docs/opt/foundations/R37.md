## 2. Skok i prędkości: pomiary i luki

Pomiary w kodzie (`canvas-pig.js`, `actions.json`, `Balance.cs`):
- **Skok `popcorn`**: `ANIM_DEFS.popcorn` (`canvas-pig.js:218`) ma 12 klatek przy 14 fps (~857 ms). `drawPig` (`canvas-pig.js:3725-3727`) odejmuje `airY = this.pigAirY || 0` od `pigY`, ale `idleTimer` (`canvas-pig.js:3197`) wywołuje jedynie `playAnim('popcorn', 1500)` bez ustawiania `pigAirY` -> **luka**: skok nie podnosi świnki w osi Y w canvasie (brak łuku).
- **Prędkość w Home**: `CanvasPig.update` (`canvas-pig.js:3076`) ma wpisane na sztywno `const speed = (70 * dt) / 1000` (`70 px/s`) dla każdego ruchu (`walk`, `run`, `follow`) i każdego etapu (`baby`, `adult`, `senior`). `SLOW_ANIMS` (`canvas-pig.js:271`) zwalnia tylko FPS klatek sprite'a, nie prędkość ruchu.
- **Prędkość na pulpicie**: `Balance.cs:1-144` nie definiuje prędkości ruchu. `actions.json:82-116` podaje dla `walk`: `distance_px: [20, 120]`, `duration_s: [2, 5]` (efektywnie ~10–60 px/s), dla `zoomies`: `duration_s: 4, moves: true` bez `distance_px`. Rzeczywista prędkość pikseli w `FormPet.cs` jest `UNVERIFIED` (poza listą dozwolonych plików).
- **Zmiana kierunku**: `canvas-pig.js:3089,3137` przełącza `this.facing = dx >= 0 ? 1 : -1` skokowo w jednej klatce (brak płynnego obrotu).

| Animacja | Skok pionowy (px) dziś -> docelowo | Prędkość (px/s) dziś -> docelowo | Płynna zmiana kierunku |
|---|---|---|---|
| `walk` (`canvas-pig.js:216,3076`) | `0` -> `0` | `70` -> `70 * stageMul` | Nie (skok `facing +/-1`) |
| `run` / `zoomies` (`217`) | `0` -> `0` | `70` -> `135 * stageMul` | Nie (skok `facing +/-1`) |

| `sleep` / `doze` / `sleep_house` / `sleep_together` | `0` -> `0` | `0` -> `0` | Nie |

## 3. Kontrakt `rest-spots.js`

UMD (`window.RestSpots` / `module.exports`). Czysty moduł bez DOM i bez odczytu plików (sceny i przedmioty podawane w argumentach).

```js
RestSpots.pick({ kind, scene, things, pigPos, taken, rng })
```
Parametry:
- `kind`: `'sleep' | 'nap' | 'sleep_together'` (domyślnie `'sleep'`).
- `scene`: `{ id, kind, walk: [x0, y0, x1, y1], blockers, isFree: (x, y) => boolean, tilePx }`. Jeśli `scene.walk` nie istnieje lub jest puste -> zwraca `null`.
- `things`: tablica umieszczonych obiektów `[{ id, uid, itemId, x, y, w, h, flip, comfort }]`.
- `pigPos`: `{ x, y }` w pikselach sceny (opcjonalne, do wyboru najbliższego miejsca przy remisie).
- `taken`: tablica zajętych punktów `[{ gx, gy, thingId }]` (opcjonalna; unika zajętych miejsc dla drugiej świnki).
- `rng`: `() => [0, 1)` (domyślnie `Math.random`).

Zwraca `null` albo obiekt:
```js
{ gx, gy, anim, faceLeft, spotType, thingId, pair: null | { gx, gy, anim, faceLeft } }
```
(`gx, gy` w pikselach sceny wewnątrz `scene.walk`, z `scene.isFree(gx, gy) === true`; `faceLeft`: boolean).

Reguły wyboru:
1. **Priorytet typów** dla `'sleep'`/`'nap'`: `house` > `bed` > `cushion` > `floor` (kąt sceny).
   - `house` (`pigloo_garden`, `sig_james_hideout`, `cosy_nook`, `willow_tunnel`, `tunnel_playground`): `anim = 'sleep_house'` (dla `nap` może użyć `'doze'` lub `'sleep_house'`; dla `'sleep'` zawsze `'sleep_house'`), punkt `(gx, gy)` wewnątrz obrysu domku z lekkim przesunięciem Y (`y - 1` do `y`) dla poprawnego Y-sortowania (nos wystaje z wejścia). Jeśli domek jest już w `taken`, zostaje pominięty.
   - `bed` (`sig_glen_knit_bed`, `sofa_cosy`, `armchair`): `anim = (kind === 'nap' ? 'doze' : 'sleep')`, punkt na środku obiektu.
   - `cushion` (`cushion_big`, `pouf_boucle`, `sig_kuki_blanket`, `sig_racuch_hop_pad`, `picnic_blanket`, `rug_fringed`, `blanket_folded`): `anim = (kind === 'nap' ? 'doze' : 'sleep')`.
   - `floor` (fallback gdy brak mebli lub wszystkie zajęte): skanuje rogi obszaru `scene.walk` (lewy-górny, prawy-górny z marginesem `12 px` od krawędzi) szukając wolnego punktu przez `scene.isFree(gx, gy)`; jeśli brak wolnych komórek -> zwraca `null`.
2. **`sleep_together`**: preferuje szerokie `bed`/`cushion` lub wolny `floor`; wymaga dwóch punktów `(gx, gy)` i `pair: { gx: gx2, gy: gy2, anim: 'sleep_together', faceLeft: !faceLeft }` oddalonych o `20 px` w poziomie, oba w granicach `scene.walk`, oba przechodzą `scene.isFree` i nie kolidują z `taken`. Jeśli brak miejsca na parę -> zwraca `null`.
3. **Kolizje i granice**: każdy zwracany punkt musi spełniać `x0 <= gx <= x1 && y0 <= gy <= y1` oraz `scene.isFree(gx, gy) === true` (gdy `isFree` dostarczone). Złe/puste wejście nigdy nie rzuca wyjątku (zwraca `null`).

## 4. Kontrakt `pig-motion.js` i sekcja `motion` danych

UMD (`window.PigMotion` / `module.exports`). Czysty moduł bez DOM; liczby pobierane z parametru `cfg` (wbudowana kopia domyślna poniżej, w produkcji z `assets/data/home_behavior.json` sekcja `motion`).

Sekcja `motion` w `assets/data/home_behavior.json`:
```json
"motion": {
  "hop": { "popcornHeightPx": 10, "popcornDurationMs": 857, "popcornPeakFrac": 0.5 },
  "speeds": { "walk": 70, "run": 135, "follow": 85 },
  "stageSpeedMul": { "baby": 1.1, "junior": 1.15, "adult": 1.0, "senior": 0.72, "legend": 0.72 },
  "particles": { "maxActive": 24, "zzzIntervalMs": 900, "heartIntervalMs": 700, "sweatIntervalMs": 1100 },
  "bubbles": {
    "popcorn": "Popcorn!", "wheek": "Wheek!", "sleep": "Zzz...", "doze": "Zzz...",
    "sleep_house": "Zzz...", "sleep_together": "Zzz...", "drink": "Sip sip",
    "happy": "Happy!", "front_happy": "Happy!", "purr_pet": "Purr...",
    "beg": "Wheek?", "eat": "Crunch!", "sad": "...", "sick": "*sniffle*",
    "shiver": "Brr...", "heat_flop": "Phew..."
  }
}
```

### API `PigMotion`
- `PigMotion.offsetY(anim, tMs, cfg)`:
  - Zwraca nieujemną wysokość uniesienia w pikselach (`>= 0`); `drawPig` (`canvas-pig.js:3727`) odejmuje ją od `pigY`.
  - Dla `anim === 'popcorn'` i `0 < tMs < dur` (`dur = cfg.hop.popcornDurationMs`): `p = tMs / dur`, zwraca `Math.max(0, 4 * H * p * (1 - p))` (szczyt `H = popcornHeightPx = 10` w `p = 0.5`, dokładnie `0` dla `tMs <= 0` i `tMs >= dur`). Dla innych animacji / błędnego `tMs` -> `0`.
- `PigMotion.speed(anim, stage, cfg)`:
  - Mapuje `'run'`/`'zoomies'` -> `speeds.run` (`135`), `'follow'` -> `speeds.follow` (`85`), `'walk'` -> `speeds.walk` (`70`), pozostałe -> `0`.
  - Mnoży przez `stageSpeedMul[stage] ?? 1.0`. Dla nieznanego `stage` przyjmuje `1.0`.
- `PigMotion.particles(anim, tMs, rng, cfg, currentCount)`:
  - Zwraca tablicę nowych cząstek `[{ type, dx, dy, vx, vy, life }]` (`0` lub `1` na krok wg interwału lub stanu):
    - `zzz`: wyłącznie dla `'sleep'|'doze'|'sleep_house'|'sleep_together'`.
    - `heart`: dla `'happy'|'front_happy'|'purr_pet'|'nose_touch'|'groom_other'`.
    - `sweat`: dla `'heat_flop'|'run'`.
  - Szanuje limit `maxActive` (`24`): jeśli `currentCount >= maxActive`, zwraca `[]`. Losowe przesunięcia `dx, vx` liczone z `rng` (domyślnie `Math.random`).
- `PigMotion.bubble(anim, cfg)`:
  - Zwraca tekst z `cfg.bubbles[anim]` lub `null` dla nieznanych/cichych animacji.

## 5. Przypadki dla PK-T15

- `RM-house-nose-only`: scena z `sig_james_hideout`/`pigloo_garden` -> `RestSpots.pick({kind:'sleep'})` wybiera domek, `anim === 'sleep_house'`, `(gx, gy)` w obrysie domku.
- `RM-bed-and-cushion`: brak domku, jest `armchair` + `cushion_big` -> wybiera `armchair` (`bed`); po zajęciu przez 1. świnkę 2. wybiera `cushion_big`.
- `RM-no-spot-fallback-floor`: pusta scena z `walk` -> wybiera kąt podłogi, `anim === 'sleep'`, `isFree(gx, gy) === true`; scena bez wolnych komórek -> `null`.
- `RM-spot-not-on-blocked-cell`: wszystkie 7 scen (`salon..market`) z blokerami -> żaden wybrany punkt nie łamie `isFree` ani granic `walk`.
- `RM-two-pigs-sleep-together`: `kind: 'sleep_together'` zwraca punkt główny i `pair`, oddalone >= 18 px, oba `isFree`, bez nakładania.
- `RM-hop-above-and-returns`: `PigMotion.offsetY('popcorn', 0) === 0`, w połowie `=== 10`, po zakończeniu `=== 0`, nigdy `< 0`.
- `RM-hop-inside-scene`: na płótnie przy górnej krawędzi `walk` `pigY - offsetY >= 0` (nie wychodzi poza scenę).
- `RM-stage-speed`: `speed('walk','baby') > speed('walk','adult') > speed('walk','senior')`, `speed('run','adult') > speed('walk','adult')`.
- `RM-zzz-only-while-asleep`: `particles('walk'|'idle'|'popcorn')` nie emituje `'zzz'`; `'sleep'`/`'sleep_house'`/`'doze'` emituje `'zzz'`.
- `RM-particles-cap`: symulacja 5 min snu utrzymuje liczbę aktywnych cząstek `<= 24`.
- `RM-wake-leaves-spot`: po pobudzeniu/usunięciu z domku `enforceFreePigs` nie zostawia świnki w zablokowanej komórce.
- `RM-edit-moves-house-while-sleeping`: zmiana `things` (przesunięcie/usunięcie domku) w trybie Edit nie rzuca wyjątku i bezpiecznie przestawia/budzi świnkę.
