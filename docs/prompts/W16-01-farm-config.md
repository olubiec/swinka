Goal: Core loads the farm numbers and the 15 crops from `assets/data/farm.json` and refuses unsafe foods.
Depends on: W15 merged.
Facts: Pattern: AGENTS.md 'Data tables' (`EconomyConfig`: `Current`, `Load(string)`, `LoadDefault()`, errors via `ItemCatalog.ErrorLogger`). File keys: `start_plots`, `plot_packs[{plots,cost}]`, `orchard_slots[{cost}]`, `water{time_cut_percent,cans[]}`, `great_harvest{chance_percent,extra_yield}`, `overripe_never_spoils`, `starter_seeds`, `forbidden_foods[]`, `crops[]` (`id`,`item`,`kind` annual|perennial,`seed_item`,`seed_price`,`grow_minutes`,`yield`,`sell_price`,`unlock_harvests`,`max_stock` for perennial). Unknown fields are ignored. Design: docs/WORLD.md section 4. Test rules: use `RepoFile(...)` for repo files, inject tables and `Random`/clock instead of assigning statics (`Current`), keep tests deterministic.
Steps:
1. `CropDefinition` (sealed; `Id`, `ItemId`, `Kind` enum Annual/Perennial, `SeedItemId`, `SeedPrice`, `GrowMinutes`, `Yield`, `SellPrice`, `UnlockHarvests`, `MaxStock`) and `FarmConfig` (sealed) with `Current/Load/LoadDefault`, `StartPlots`, `PlotPacks`, `OrchardSlots` (costs), `WaterTimeCutPercent`, `Cans`, `GreatHarvestChancePercent`, `GreatHarvestExtraYield`, `StarterSeeds`, `ForbiddenFoods`, `Crops`, `Find(id)`, `TotalPlots` (start + packs).
2. Load rules: bad JSON gives code defaults (the three starter crops dandelion, cilantro, parsley) and logs; a crop whose item id is in `forbidden_foods` is skipped and logged; duplicate crop ids keep the first; `grow_minutes` outside 30-1440, `yield` outside 1-4, non-positive prices are clamped or the crop skipped (decide, log, document in the PR); perennial without `max_stock` gets `2 * yield`.
3. Tests: the real file loads 15 crops (11 annual, 4 perennial), 24 total plots, starter seeds, forbidden list contains onion and chocolate; every crop's `item` exists in `items.json`, `items_shop.json` or `items_farm.json` (read them with `ItemCatalog` or JSON) and every seed item exists with the same price; selling price times 1.15 is below the buy price times 0.85 for every crop; annual unlock thresholds are non-decreasing in file order; a crop with a forbidden item is skipped; broken JSON gives defaults; unknown fields are ignored.
