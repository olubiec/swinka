Goal: Fix the bug "More -> Care calendar -> Weight, leave, press More: the Weight panel opens instead of the More menu", and make every feature window behave the same way. Add a Back button from a feature to the More menu.
Depends on: nothing.

## Diagnosis already done (verify it, then fix it)
- `window.CuyHome.openFeature` in `web/home/app.js` renders a feature into the ONE shared element `elements.modalBody` and remembers `currentFeatureId`. `closeModal()` calls `closeFeature()`, which calls `feat.close()` if the feature has one.
- Features `calendar`, `diary`, `settings`, `shop` have NO `close()`. `calendar` keeps `containerNode` (= `modalBody`) after the window closed. The next state push calls `calendar.onState`, which sees `containerNode`, finds no `#fcContent` (the More menu is there) and calls `render()`: the Weight panel overwrites the More menu. The same pattern can hit any feature whose `onState` re-renders into a stored container.
- Also in `closeFeature` the line `elements.modalBackdrop.classList.remove('active')` sits INSIDE the `if (this.currentFeatureId)` block (bad indent / bad scope); `closeModal` already removes `active`. Move it so the behaviour is the same for every case.
- `openMoreModal()` has no way back: a feature opened from More replaces the More menu.
