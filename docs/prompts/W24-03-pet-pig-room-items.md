Goal: A pet can recolour an item, rename a room, list unplaced items and move an item between rooms.
Depends on: W23 merged.
Facts: Behind `PigRoomsActive`. Uses `PlacedItem.Variant` (0..VariantCount-1), `RoomLayout.Name` and `UnlockedVariants` (W23-02) and `HomeEconomyConfig` (W23-07, planned names). Only items with `recolor: true` in `world_items.json` have variants; variant 0 is always allowed; variants 1-3 need the key `<itemId>:<variant>` in `UnlockedVariants`; `UnlockVariant(itemId, variant)` pays `HomeEconomyConfig.VariantPrice(itemPrice)` (ceil of price * percent / 100, minimum `min_price`, 0 for free items), once; `SetVariant` returns false for a locked variant. Rename: trim, max `MaxNameLen`, no control characters, empty string resets to null (default name); the name is plain text and is escaped by the page. Storage: `OwnedItems[item] - placed anywhere` for items that are not `repeatable`; `StorageList()` returns id and free count. Transfer: move a placed item from room A to room B in one step (remove from A, `RoomLayoutOps.Place` in B at the given cell with the same variant; if B refuses the placement nothing changes). After each placement in a pig room call the `pig_room_items` counter, and when a pig room reaches 6 items count `pig_rooms_furnished` once per room (use a `HashSet` in `WorldState.PigRoomsEnsured`? no: keep a private set keyed by the counter value rebuilt from the layouts). Test rules: use `RepoFile(...)` for repo files, inject tables and `Random`/clock instead of assigning statics (`Current`), keep tests deterministic.
