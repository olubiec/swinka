Goal: A pure helper merges pigs' rooms into the shared bedroom and restores them, never destroying an item.
Depends on: W25 merged. Sub-wave W26a: no dependency on other tasks of the wave.
Facts: Design: docs/PIG_ROOMS.md section 6. Move in: for each resident pig, copy its layout to `Parked[pigId]` (snapshot), set `RoomShare[pigId] = 'dorm'`, then place the items of all residents into the `dorm` layout by deterministic first-fit (floor items by layer then by comfort descending, then wall items); items that do not fit stay in `OwnedItems` but unplaced (storage). Wallpaper and floor of the dorm: those of the first resident (the player changes them later). The pig's own room entry stays but is hidden while shared. Move out: restore `Parked[pigId]` as the pig's layout for every item that is still owned and not placed in the dorm; items bought while sharing stay in the dorm or go to storage (the dorm layout loses only the items that went back). `RoomShare` entry removed, `Parked` entry removed. Items are never deleted; only `Place` and `Remove` operations on layouts change. Test rules: use `RepoFile(...)` for repo files, inject tables and `Random`/clock instead of assigning statics (`Current`), keep tests deterministic.
Steps:
1. `static MoveInResult MoveIn(WorldState, IReadOnlyList<string> pigIds, PigRoomConfig, WorldItemCatalog, PlaceCatalog, Func<string> newUid)` (result: `Moved`, `ItemsStored` count, `TooMany`, `NeedTwo`, `AlreadyShared`), `static bool MoveOut(WorldState, string pigId, WorldItemCatalog, PlaceCatalog, Func<string> newUid)`, `static IReadOnlyList<string> Residents(WorldState)`.
2. Tests: two pigs with 8 items each move into a 16x8 dorm and every item is either placed or counted in storage (sum of placed + storage equals owned for each item id); a third pig can join; the sum of `OwnedItems` never changes; move out restores the original layout exactly when nothing changed (compare JSON of the layout); items placed in the dorm that belonged to a snapshot go back to their pig, new ones stay; moving out the last but one resident leaves a dorm with one resident (allowed: the dorm stays, with a note in the PR); a memorial pig can be a resident; `TooMany` over `MaxResidents`.
