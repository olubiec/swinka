## Steps
1. Read `docs/opt/foundations/R46.md` (sections 1, 3, 5) and take the object-to-item mapping from there. If a decision there is marked "default" use it. If the file is missing, stop with BLOCKED.
2. Tests FIRST in `tests/Cuy.Core.Tests/OutdoorSeedTests.cs` (inject tables, `ManualClock`, never assign statics): S1 `seed-creates-defaults` (empty state -> garden has the default instances with uids `fx:garden:<id>` and positions from the data), S2 `seed-once` (second call adds nothing), S3 `old-save-loads` (a `WorldState` without the new field loads and seeds), S4 `removed-stays-removed` (a decorative instance the player stashed is NOT seeded again), S5 `move-persists` (move, serialise with the save system, load: same X/Y), S6 `fixture-locked` (`Remove` of a `removable:false` instance returns `fixture_locked` and keeps it), S7 `flag-off-no-seed` (`Balance.OutdoorInstancesActive=false` -> nothing changes), S8 `data-valid` (every default has a known `itemId`, positions inside the scene `walk` area from `place_scenes.json`, unique ids).
3. Data: `assets/data/outdoor_defaults.json` (per scene a list `{id, itemId, x, y, flip, movable, removable}`), loader `OutdoorDefaults` in the `EconomyConfig` pattern (`Current` lazy `LoadDefault()`, `Load(string)`, errors to `ItemCatalog.ErrorLogger`). Add the missing ids to `assets/data/world_items.json` (price 0, `fixture: true` where R46 says so, footprint from R46) and entries in `assets/world/atlas.json` only for PNGs that already exist; objects without a PNG keep a data entry but `"art": "missing"` and are listed in the log (the artist order, see R47).
4. `OutdoorSeed.Seed`: for the place id adds the defaults to `WorldState.Rooms[placeId]` (create the layout if absent), marks `OutdoorSeeded`, idempotent, deterministic uids, never touches an existing item. New `WorldState.OutdoorSeeded` with a safe default (empty set; null-safe property like the others). Do not rename or remove any save field.
5. `RoomLayoutOps.Remove`: if the item is a fixture with `removable:false` return the `fixture_locked` error (add it to the existing result type the way other errors are done); everything else unchanged. `Move` of fixtures stays allowed.
6. Flag: `Balance.OutdoorInstancesActive` default false, set true in `GameSession.Open` next to the other world flags; call `OutdoorSeed.Seed` for garden, park, farm, market where the world state is created or loaded (grep where `LegacyDecorMigration` is invoked and call it beside, only when the flag is on).
7. Run the Weryfikacja line; fix until green. Log: the item mapping used, the list of ids with `art: missing`, the exact `fixture_locked` error shape.
