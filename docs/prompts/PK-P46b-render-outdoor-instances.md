## Steps
1. Read `docs/opt/foundations/R46.md` section 4 and `docs/opt/log/PK-P46a.md`. grep `placedThings`, `layoutFor`, `blockers`, `behindLine` in `scenes.js` and note the real lines.
2. Tests FIRST, `tools/qa/ux-p46-render.js` (Playwright via `tools/qa/lib/ux.js`, mock `seven`, mock state extended with seeded instances): D1 `clean-scene-draws-instances` (garden with `bg_clean:true` shows the bench instance at its saved x,y), D2 `unclean-scene-unchanged` (park with `bg_clean:false` draws no instances, uses static blockers), D3 `ysort` (an instance lower on screen draws over one higher), D4 `blocker-follows-instance` (move the bench instance in mock state -> `isFree` of its old cell becomes true, new cell false), D5 `pig-walks-around` (pig target behind a fountain instance gets a path that avoids its footprint), D6 `missing-art-skipped` (an instance whose atlas entry is missing is not drawn and does not throw), D7 `canvas-size-unchanged` (switching all five scenes keeps each scene size as in `place_scenes.json`), D8 `no-console-errors`.
3. `place_scenes.json`: add `"bg_clean": false` to every scene. `tools/qa/place-scenes-check.js`: the flag must be boolean; for `bg_clean:true` scenes there must be no static `blockers` left that duplicate an instance id (warn only).
4. `scenes.js`: `placedThings` returns outdoor instances (uid, itemId, x, y, flip, sprite from the atlas) for outdoor scene ids using `layoutFor`; `def()` builds `blockers` from instance footprints (`world_items.json` w/h x cell unit from R46 section 2) when the scene has `bg_clean:true`, else keeps the static list. Keep the existing signature `def(id, tod)`; the layout comes from the same state source as indoor rooms.
5. `mock.js`: extend the `seven` state with outdoor layouts for garden, park, farm, market copied from `assets/data/outdoor_defaults.json` (read it in the mock with a fetch-free copy of the few fields; do not duplicate more than ids and positions).
6. Run the Weryfikacja line; fix until green. Log: which canvas function draws the sprites, any canvas gap left for a later package.
