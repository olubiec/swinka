## Pliki i elementy (zweryfikowane w repo 8.11.2026; nie szukaj ich drugi raz)
- Line numbers below are from 8.11.2026, BEFORE waves P39 and P45 (they edit `canvas-pig.js`, `scenes.js`, `places/feature.js`, `index.html`). Find every function by name with grep, never by line.
- `web/home/features/places/feature.js` (edited before by PK-P38a, P39d, P40d, P43e: read their logs): `computeNeighbourScene(currentScene, direction, st)` (~102) returns the ring entry `{id,title,locked,unlockHint}` for `'left'|'right'` (handles the house exits and wraps around the ring, so a neighbour always exists when the ring has 2+ scenes). USE THIS, not `CuyScenes.neighbor` (that one takes a number and returns only an id string, no locked flag). Also `handlePigExit(ev)` (~196, walk-to-edge exit, sends `places.pigMove` at ~220), `bindCanvasExits()` (~227), `applyScene(sceneId, st)` (~275), `getPigLocations(st)` / `getFirstPigId(st)`, locked hint elements `#placesLockedHint` + `#placesHintText` (index.html; `applyScene` shows them ~336-341 for locked scenes).
- Pig visibility trap: `applyScene` step 3 sets `CanvasPig.setPigVisible(isAnyPigHere)` and `setExitsEnabled(...)` from STATE (`state.places.pigLocations[].scene`), so right after a mid-drag `applyScene` to a neighbour the pig would vanish, and so would any `onState` push (`updateStageNav` -> `applyScene`) during the drag. Add a module flag `dragCarry` (true from the first successful edge switch until `onDrop`/take_out) that forces `isAnyPigHere = true` and `exitsAllowed = false` while set.
- No toast helper is reachable (`showToast` is private to `app.js`): for a locked neighbour show the existing hint bar (`#placesLockedHint` with `Locked: <unlockHint>`) for 2 s and then restore it from the current scene (re-run the locked-state part of `applyScene` logic, do not duplicate its code if a small helper can be extracted inside this file).
- API from PK-P44a: `CanvasPig.setEdgeNeighbours({left,right})`, callbacks `CanvasPig.onEdgeHold({side})` and `CanvasPig.onDrop({x,y,scene})`, `CanvasPig.continueDrag(side)`.
- Message: `{type:'places.pigMove', pigId, to}` (server `PlacesFeature.cs` ~164; mock handler in `places/mock.js` ~100 rejects non-adjacent targets, the ring check there is fine). Pinned pigs: location `pinned` flag stays; `places.pigPin` is not sent.
- `setEdgeNeighbours` rule: on every `applyScene` set `{left: !!neighbourLeft, right: !!neighbourRight}` where neighbour = `computeNeighbourScene` result (locked ones count as present so that the hold gives the hint instead of pulling the pig out to the desktop).
