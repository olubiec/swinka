# Music credits

Music used by the game. Files are in `assets/music/`; sources are listed in `assets/music/tracks.json`.
Home background: `am_*` tracks (slots morning, day, evening, night) play one after another in random order. Game tracks `game_*` loop.
Every file was loudness-normalised (ffmpeg loudnorm) and re-encoded to Ogg Vorbis.
