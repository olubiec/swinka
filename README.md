# Świnka na pulpit

Pixelowa świnka morska na pulpit Windows: chodzi po pasku zadań i oknach, ma potrzeby jak w Pou,
rośnie w tempie prawdziwej świnki. Prezent, budowany z agentami AI w Antigravity.

| Co | Gdzie |
| --- | --- |
| Plan projektu, etapy i prompty | `PLAN.md` |
| Zasady dla agentów AI | `RULES.md` |
| Grafika (60 animacji × 7 wariantów, ikony) i dane gry | `assets/` (sprites, icons, sounds, data) |
| Skrypty, które rysują grafikę i liczą balans | `tools/art/` |
| Baza aplikacji: eSheep (C#, .NET Framework 4.8, MIT) | `src/Cuy/` (licencje: `THIRD_PARTY_NOTICES.md`) |

Następny krok: prompt A2 z `PLAN.md` (Gemini w Antigravity).
