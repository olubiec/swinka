# Świnka na pulpit

Pixelowa świnka morska na pulpit Windows: chodzi po pasku zadań i oknach, ma potrzeby jak w Pou,
rośnie w tempie prawdziwej świnki. Prezent, budowany z agentami AI w Antigravity.

| Co | Gdzie |
| --- | --- |
| Plan projektu, etapy i prompty | `PLAN.md` |
| Zasady dla agentów AI | `ZASADY.md` |
| Grafika (60 animacji × 7 wariantów, ikony) i dane gry | `swinka/` (opis w `swinka/CZYTAJ.md`, podgląd w `swinka/galeria.html`) |
| Skrypty, które rysują grafikę i liczą balans | `narzedzia/` |
| Baza aplikacji: eSheep (C#, .NET Framework 4.8, MIT) | `esheep/` (źródło w `esheep/ZRODLO.md`) |

Następny krok: prompt A2 z `PLAN.md` (Gemini w Antigravity).
